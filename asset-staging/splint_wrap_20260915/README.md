# 나무 막대·붕대 부목으로 재제작

## 사용자 지시와 참고

사용자는 이전 버클형 부목이 어색하다고 지적하고, 손목 아래 나무 막대를 받친 뒤 붕대로 감는 방식으로 교체하도록 요청했다. 새 기준은 [Gray Zone Warfare All Healing Animations, 31초 이후](https://www.youtube.com/watch?v=sjPpfdlupx4&t=31s)다. 브라우저에서 음소거·정지·프레임 이동으로 31·32·33·34·35·36·37초의 실제 화면을 확인했다. 타임코드 사이의 일부 지지대 종류 편집을 그대로 복사하지 않고 공통 배치·감기·마무리 동작을 사용한다.

- 31초: 시작 전 화면.
- 32~33초: 손목에서 전완 아래까지 지지대, 반대 손이 붕대 롤을 준비.
- 34~35초: 받치는 팔이 낮게 가로로 돌아오고, 반대 손이 넓은 붕대를 위로 넘김.
- 36~37초: 감긴 끝을 반대 손으로 누름.

게임에서는 기존 왼팔 치료에 맞춰 좌우를 반전하고 지지대는 사용자 요청대로 단순한 나무 막대 하나로 만든다. 영상의 현대식 포장·브랜드·장갑을 추가하지 않는다. 이전 버클형은 현재 채택본이 아니며 기존 `splint_20260915` 및 `exports/Splint_2026-09-15`에 보존한다.

## 제작과 연결

MacBook Blender 백그라운드에서 `source/build_wood_support.py`로 별도 원본과 `wood_support.glb`를 생성한다. 막대의 원본 크기는 32×4.4×1.2cm이며 부드러운 모서리와 내장 나뭇결을 갖는다. 게임에서 실제 팔 소매의 길이·테이퍼에 맞추고, 붕대는 소매뿐 아니라 막대의 아랫면까지 포함한 경로를 따라 쌓인다.

실제 양손·롤·연속 천의 7.2초 동작은 `godot-game/scripts/splint_use_visuals.gd`에 있다. 0~0.4초 장비 수납, 0.4~2.0초 팔 올리기·나무 받치기, 2.0~5.3초 세 번 감기, 5.3~6.25초 끝 눌러 고정, 6.25~7.2초 팔 내리기·장비 복귀다. 기존 붕대의 손 리그·장비 전환·메시 생성 보조만 재사용하며 기존 붕대 스크립트는 수정하지 않는다.

`F2 → 생존 → 부목 사용 · 왼팔 고정`은 실제 `begin_item_use()`로 시작한다. 7.2초 완료 전에 소비·골절 해소는 없다. F·F2·가방·공격으로 취소하면 소비·효과를 남기지 않는다. 별도 붕대 아이템을 추가 소비하지 않으며, 다른 팔다리 치료 및 일시정지·원정 복원 규칙을 유지한다. 완료 후 영구 장착은 기존처럼 없다.

## 검증

자동 검사·실제 렌더·수정 이력과 최종 파일 해시는 `output/validation_summary.json`에 기록한다. 이전 버클형의 통과 기록을 새 모션의 통과 근거로 사용하지 않는다. 실제 렌더는 창 없는 embedded Vulkan 경로만 사용하며 사용자 입력·커서·포커스를 조작하지 않는다.
