# 붕대 모션 참고

- 사용자 지정: https://www.youtube.com/watch?v=ctbwl1_u_yg (1–5초).
- 영상: Polydin Studio, First Person Healing Animation Pack, Bandage Interaction 01.
- 실제 Chrome 플레이어를 음소거·일시정지하고 30fps 프레임 이동으로 구간을 관찰했다. 영상은 내려받거나 프로젝트에 포함하지 않았다.
- 1초 무렵은 로고 전환. 약 1.7초부터 치료받는 왼팔을 올리며 손을 닫는다.
- 감는 오른팔이 왼팔 가까이 앞·뒤로 지나가며, 왼팔도 기울어지고 손목이 회전한다. 오른손이 멀리서 큰 원을 도는 동작과 다르다.
- 후반에는 잠깐 누르고 당긴 뒤 왼손 주먹을 앞에 남겼다가 복귀한다.
- 현재 게임 리그로 짧은 감기 두 번, 왼손 주먹과 팔 회전, 끝 누르기와 복귀를 재구성한다. 원본 에셋/리그 추출이나 프레임 그대로의 모션캡처는 아니다.
- 이전 사용자가 좋다고 평가한 감긴 천의 누적·팔 표면 부착을 보존한다. 의료 효과·소비 시점은 변경하지 않는다.
