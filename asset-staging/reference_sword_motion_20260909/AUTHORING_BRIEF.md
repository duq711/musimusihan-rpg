# Windows 제작 지시

참고: https://youtu.be/sU7jk2OQlgc (Hammerhead Animations). 참고 영상은 동작 분석용이며 납품 모델·텍스처로 사용하지 않는다. 사용자 손/검 원본으로 새 액션을 제작한다.

## 제작 대상

기존 `SwordHold_Static.blend`를 보존한 별도 파일에 `idle`, `run`, `takeoff`, `air`, `land`, `right_diagonal`, `left_reverse`, `overhead` 액션을 만든다. 기존 장갑과 검 파지는 강체로 유지하고 팔 소매는 원본에서 복사한 메시를 어깨/팔꿈치에 연결한다. 원본 메시를 덮어쓰지 않는다. 새 결과는 공식 Blender MCP 연결 검증 후 Windows Blender에서 생성·베이크·렌더한다.

## 관찰된 형태

- 대기·이동: 검이 화면 오른쪽에서 거의 수직. 손 중심은 화면 폭 약 80%, 높이 약 96%이며 방패는 왼쪽 아래에 잘려 보인다. 새 `idle` 기준 자세로 이 프레이밍을 맞춘다. 기존 `SOURCE_READY`는 메시 정규화 상수로 보존하며 그 자체를 새 대기 프레이밍으로 강제하지 않는다.
- 달리기: 검을 옆으로 눕히지 않고 세운 실루엣을 유지한다. 파지와 방패가 작게 상하 운동하고 손목 각도가 미세하게 뒤따른다. 단순 공통 사인파로 양손을 같은 방향/위상으로 움직이지 않는다. 실제 관찰 주기는 `reference_notes.md`를 따른다.
- 점프: 약 14.83–16.33초. 도약 때 두 팔이 잠깐 내려가고, 약 15.5–15.67초 높이 반등한 뒤, 착지 직전/직후 약 15.83–16.0초 아래로 압축되고 16.33초까지 정리된다. `takeoff`는 대비/상승, `air`는 높은 자세 유지, `land`는 아래 충격과 대기 복귀를 분리하여 물리적 착지 시점에 재생한다.
- 내려베기: 약 17.35–18.88초. 상단으로 크게 들어올린 준비, 빠른 전방/하방 통과, 아래쪽 잔여 궤적, 오른쪽 기본 자세 회수.
- 좌→우 베기: 약 19.30–20.75초. 손과 검을 왼쪽으로 보냈다가 반대 방향으로 크게 통과하고 오른쪽에서 회수.
- 우→좌 베기: 약 21.18–22.75초. 우측 상단 대비에서 왼쪽 아래로 큰 궤적. 양손이 잠시 화면 밖에 있는 프레임은 실제 영상에도 있으며 이를 억지로 작은 흔들림으로 축소하지 않는다.
- 방패: 대기·이동은 왼쪽 아래 유지. 공격에서 뒤로/아래로 내려 오른팔을 방해하지 않게 하고 회수 때 복귀. 별도의 가드·피격은 현재 게임 처리와 함께 쓸 수 있어야 한다.

위 시각은 실제 디코딩 프레임에서 관찰한 구간이며 게임 내 피해 이벤트를 의미하지 않는다. 화면에서 보이지 않는 자세·3D 깊이는 제작자의 재구성이다. 영상 유사성의 수치 점수나 정확한 원본 리깅 복원은 주장하지 않는다.

## 전달 계약

`INTEGRATION_PLAN.md`, `delivery_requirements.json`, `motion_manifest.schema.json`에 따라 카메라 기준 절대 피벗 위치/쿼터니언을 120Hz 권장(최소 60Hz)으로 샘플한다. 모든 액션에 sword/shield 두 트랙을 작성한다. 추가 `idle`은 짧은 루프이며 각 공격과 착지의 최종 자세가 이 기준과 이어져야 한다. 카메라 자체는 고정하고 손/검 변환만 베이크한다.

현재 게임은 실제 전투 단계와 타격 체크포인트에 맞춰 제작 클립을 재샘플한다. `timing.hit_seconds`는 active 시작 기준이다. 영상에는 적이 없으므로 이 값은 손과 칼날의 전방 통과로 정한 제작상의 타격 기준이다. `HandGrip=(0,-0.108,0.002)`, `BladeTip=(0,1.035,0)`를 기준으로 실제 칼날이 카메라 전방의 공격 공간을 통과하게 한다. 그림만 돌려 칼날이 플레이어 뒤를 치는 결과는 피한다.

필수 결과: 편집 가능한 `.blend`, 애니메이션 포함 `.glb`, `motion_manifest.json`, 재실행 스크립트, 원본/산출물 해시와 Windows 경로/Blender 버전·종료코드가 있는 보고서, 실제 새 모델 프리뷰와 프레임별 접촉/정규화 검증. 1인칭 16:9, 세 베기와 run-jump-land 연속 프리뷰를 만든다. 프리뷰는 낮은 샘플의 EEVEE 또는 Cycles GPU로 빠르게 반복한다. 화면을 띄우지 않고 background에서 실행한다.

새 .blend에서 액션이 실제 키프레임으로 존재해야 하며, JSON의 임의 숫자만 반환하는 것은 완료가 아니다. .blend 재오픈 후 대표 샘플 변환 일치, GLB 재가져오기 후 액션과 원본 파지 보존, 루프 이음새와 전후 단계 연속성까지 검증한다. 결과 파일은 OneDrive `CodexTransfer/reference_sword_motion_20260909/output/<iteration>/`에 복사하여 같은 사용자의 Mac 통합 작업으로 전달한다. 공개 링크를 만들지 않는다.
