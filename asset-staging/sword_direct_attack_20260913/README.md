# 현재 파지에서 검 공격 시작

2026-09-13 사용자 지시: 양손검을 휘두르기 전에 한 번 치켜드는 준비 동작을 없애고, 방패를 든 때와 같이 바로 공격한다.

`player.gd`는 실제 공격 입력을 받을 때의 검·오른팔 자세를 기록한다. 준비/차지 동안 그 자세를 유지하며, ACTIVE의 첫 0.10초 동안 현재 시각의 기존 베기와 같은 팔을 함께 연결한다. 두 끝점 모두 기존 시점·휴대 위치 보정을 포함한다. 0.10초부터는 기존 검 궤적과 관절을 그대로 사용한다. 방패 착용/수납 모두 같은 코드를 사용한다.

입력의 최소 준비 시간 0.22초, 차지 계산과 자동 발동, ACTIVE 접촉 0.145초·종료 0.30초, 피해·기력·공격 순환은 바꾸지 않았다. 따라서 이번 수정은 추가로 치켜드는 표시 동작을 제거하며 입력·전투 규칙 변경은 아니다. 기존 전체 모션 JSON과 손·검 원본 메시도 그대로다. 초기 contact 직선 보간안은 적용 과정에서 폐기했고 최종 동작에 사용하지 않는다.

기존 `motion_shield_stow` 시험은 실제 방패 수납/양손 파지, 2m 표적, 짧은 LMB 공격과 차지·기력·F2 초기화를 연결한다. 실제 화면 비교는 `quick_cut_shield`와 `quick_cut` 범위를 사용한다. 양쪽 모두 클릭 직후 놓으며 종전 0.45초 홀드 영상과 구분한다.

- `baseline/`: 이번 변경 직전 파일
- `source_preservation.json`: 원본 모션/모델 보존
- `core_regressions.log`: 최초 구현 검사, 당시 검격 fixture 실패 포함
- `entry_connection_regressions.log`: 연결 수정 후 검사, 동일 검격 fixture 실패 포함
- `direct_entry_regressions.log`: 준비 고정·연결·팔·실제 표적·양손 회귀
- `shield_preview.log`, `two_hand_preview.log`: 실제 embedded/Vulkan 촬영 로그

검증 최종 결과와 실제 영상 위치는 `validation_summary.json`을 따른다. 이전 손 조형·베기 전체 미학 문제에 대한 완료 주장은 하지 않는다.
