# 왼팔 부목 에셋·착용 모션

2026-09-15 사용자 첨부 8단계 이미지를 형태와 동작 순서의 참고로 사용했다. 사진 안의 문구는 별도 작업 지시로 취급하지 않았다. ‘아르헨’은 사용자 정정에 따라 반영하지 않았다.

## 제작물

- `source/reference.png`: 제공 이미지 보존본.
- `source/build_splint.py`: Mac Blender 백그라운드 재현 스크립트.
- `output/wood_linen_splint.blend`: 편집 가능한 최종 원본.
- `../../godot-game/assets/3d/items/splint/wood_linen_splint.glb`: 게임에 연결된 에셋. 나무 레일 4개, 천 받침과 봉제선, 가죽 스트랩 3개, 철 버클·혀·리벳과 벨트 구멍. 재질 표면 결을 GLB에 내장한다.
- GLB의 `Tighten_0`·`Tighten_1`·`Tighten_2`: 개별 스트랩 고정 애니메이션. 원본 편집용이며 실제 게임에서는 같은 노드들을 결정적인 시간 값으로 제어한다.
- `../../godot-game/scripts/splint_use_visuals.gd`: 제공 손 리그로 재생하는 8.6초 양손 동작. 기존 붕대의 손·팔 구성과 장비 전환을 재사용한다.

## 연결·범위

`F2 → 생존 → 부목 사용 · 왼팔 고정`. 시험 가방에 3개를 준비하고 골절 상태의 왼팔에 실제 1개를 사용한다. 재선택·회복·F2와 원래 원정 복원은 공통 테스트룸 경로를 사용한다. 본편은 건강 화면에서 왼팔에 나무 부목을 사용하고 가방을 닫는다.

골절 해소와 1개 소비는 기존 사용 시점에 한 번 적용한다. HP 회복은 없다. 일시정지 중에는 동작이 정지하고 공격·방어·가방·F2로 중단할 수 있다. 동작 종료 후 영구 착용 상태는 저장하지 않는다. 다른 팔다리의 치료는 유지하지만 이 왼팔 모션을 재생하지 않는다. 기존 의상 소매를 유지하며 사진의 소매 걷어 올리기는 실제 메시 변형으로 구현하지 않았다.

## 검증과 수정 기록

Mac 실행 위치: `gimjin-yeob-ui-MacBookAir.local / Darwin / Blender 5.2.1 LTS`. UI를 띄우지 않은 백그라운드 제작. 기존 손과 에셋 원본은 수정하지 않았다. 수정 전 플레이어·테스트룸 파일은 `baseline/`, 1차 부목은 `output/iteration_01/`에 보존했다.

1차 자동 검사에서 패드에서 첫 스트랩으로 손이 이동할 때 10cm의 프레임 간 이동이 확인되어 보간을 추가했다. 재검사에서 최대 이동은 2.74cm, 손목 접합 오차는 1mm 미만이었다. 실제 1차 GPU 화면 23장에서 패드가 소매 안에 묻히고 손목 쪽 스트랩부터 시작하는 문제를 확인하여 패드 반지름과 고정 순서를 수정했다. 각 로그는 덮어쓰지 않고 보존했다.

최종 검증 결과와 파일 해시는 `output/validation_summary.json`을 따른다. 자동 동작 검사와 실제 픽셀 검토는 별도 근거다. `output/tests.log`는 첫 실패·시간 제한을 포함하는 이력이며 최종 전 항목 통과 로그로 해석하지 않는다.
