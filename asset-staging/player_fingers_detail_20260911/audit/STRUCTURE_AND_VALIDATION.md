# 손가락 디테일 구조 조사

2026-09-11 읽기 전용 조사. 새 디테일 모델의 제작·검증 완료를 뜻하지 않는다. 사용자의 최신 기준은 **한 이미지에 한 손가락의 한 면**, 총 10장(다섯 손가락 × 손등/손바닥면)이다. 종합 시트는 제작 비교 기준에 사용하지 않는다.

원본은 `../../player_hands_proportions_20260911/mac_output/iteration_01/bilateral_hands_proportions.blend`이며 SHA256은 `773f0fc72f979a06c642f2e8c4d628357bb3a0a69d8f02862aa81894c3c729a5`다. Mac Blender 5.2.1 LTS를 백그라운드 2스레드로 열어 조사했고, 저장하지 않았다. 조사 전후 원본 해시는 동일하다. 상세 수치는 `source_structure.json`, 실행 기록은 `inspect_structure.log`에 있다.

## 실제 수정 가능한 구조

- 양손 각각 9개 mesh: 연속 손 1개, 손톱 5개, WristCuff·Forearm·UpperArm 3개다.
- 손 mesh는 14,988정점 / 28,234삼각형이다. 처음 12,036정점은 피부와 장갑으로 재질이 나뉜 연속 표면이며, 뒤 2,952정점은 기존 장갑 장식이다. 피부만을 뜻하는 12,036정점 mesh가 별도로 있는 구조가 아니다.
- `Detailed_Skin`, `Detailed_Glove`, `Detailed_Trim` 면은 하나의 손 mesh에서 재질 슬롯으로 나뉜다. 피부/장갑 경계 정점은 여러 재질 면에 공유될 수 있으므로 정점의 재질을 단일값으로 가정하지 않는다. 왼손 피부 면 11,655개, 오른손 11,658개다.
- `RealismUV` 한 레이어가 활성 UV다. 기존 5개 재질은 모두 4K 공유 BaseColor·Normal·Roughness 이미지 3개를 연결한다. UV를 보존하면 장갑·봉제선의 기존 무늬를 유지하면서 피부의 세부 노멀만 갱신할 수 있다.
- 손에는 Basis와 `Joint_<thumb/index/middle/ring/little>_<0/1/2>` 15개 relative shape key가 있다. 전부 Basis를 참조하며 저장된 값은 0이다. 손톱·팔 부위에는 이 shape key가 없다.
- 각 손톱은 322정점이며 해당 `<digit>2` 본에만 가중치 1.0으로 고정돼 있다. 따라서 피부 조형과 손톱 높이를 따로 바꾸면 손톱의 들뜸이나 피부 관통을 새로 만들 수 있다.

국소 디테일을 추가할 때 가장 단순한 경로는 topology·UV·weights·본을 유지하면서 승인된 피부 정점에 작은 Basis 오프셋을 추가하고, 같은 오프셋을 15개 key 위치에도 더하는 것이다. 그러면 기존 relative corrective delta가 보존된다. 좌표에 따라 달라지는 비선형 변형을 사용한다면 Basis뿐 아니라 각 key의 절대 좌표도 같은 변형으로 처리해야 한다. remesh/subdivision은 필수 조건이 아니며, 필요하다면 weights·UV·15키 전부의 전송을 별도 제작·검증 범위로 명시해야 한다.

## 실제 표면 기준점

native Blender 좌표는 손가락 +Y, 손등 +Z, 팔 −Y다. `source_structure.json`의 `hands.<side>.landmarks.<digit>.<0/1/2>`에는 실제 본 축과 피부/장갑의 연속 표면을 가로지르는 평면 교차점으로 측정한 단면 중심·폭·깊이·손등/손바닥 표면점이 있다. 손톱 중심과 bounds도 같은 좌표계다. 단면 중심은 본의 head 위치를 그대로 대체한 값이 아니다.

왼손 중간마디 단면 예시(엄지는 끝마디 기준):

| 손가락 | 폭 mm | 깊이 mm |
|---|---:|---:|
| 엄지 | 20.699 | 22.763 |
| 검지 | 19.387 | 19.559 |
| 중지 | 18.813 | 18.705 |
| 약지 | 17.226 | 17.255 |
| 소지 | 16.290 | 15.511 |

이 값은 현재 모델의 측정값이며, 생성 이미지로부터 추정한 목표 치수가 아니다. 10장 비교는 같은 투영 방식·크기·손가락 축·중립 조명을 맞춘 실제 렌더로 수행한다. 생성 이미지의 왜곡이나 모순을 그대로 모델에 이식하지 않는다.

## 유지할 기능 계약

- 현재 16본의 이름·계층·rest·로컬 X 굽힘축과 wrist 기준점을 유지한다. 손목 native 위치는 `(0, -0.05625, 0)m`다. 손가락 비례는 직전 승인 모델을 기준으로 한다.
- 원래 장갑·봉제선·소매, WristCuff·Forearm·UpperArm 표면과 손목 연결의 기존 동작을 보존한다. 이번 손가락 작업을 위해 예전 맨손 모델의 weights 보정이나 metadata를 가져오지 않는다.
- Cuff metadata는 version 1, Godot native z 시작 `.014`, 끝 `.075`다. runtime은 실제 wrist pivot에 맞춘 팔 변형과 탄성 안쪽 압축을 사용한다. 기존 positive Jacobian·유한 면 방향·정상 normal/tangent·최소 안쪽 깊이 `.45` 검사를 유지한다.
- 손의 장비 접촉 오프셋과 기존 free/bow/chest 포즈·타이밍, 상세/그레이박스/원본 전환을 유지한다. 관절 한계는 손가락 90°/110°/80°, 엄지 60°/70°/80°다. key 값은 실제 굽힘각/한계의 0..1 비율이다.
- 테스트룸의 실제 player와 15개 슬라이더, 손등/손바닥/손목 옆면, F2·리셋·종료 시 원정·인벤토리·카메라/커서 복원을 유지한다. 손가락마다 별도 actor로 흉내 내는 시험을 추가하지 않는다.

## 독립 검증 전략과 새 디테일 판정의 구분

1. **원본 보존:** 원본 SHA와 새 산출물 분리. 변경하지 않기로 한 topology·UV·weights·16본·장갑·팔·Cuff는 정확 비교한다. 이번에는 새 피부/손톱 조형과 허용된 normal/roughness 수정까지 예전 정점·texture SHA와 같아야 한다고 요구하지 않는다.
2. **실제 디테일:** 손가락별 승인 마스크에서 실제 표면 변화량, 변경 정점 수, normal/roughness의 UV 영역별 변화와 시각 근거를 기록한다. 조명 변화만으로 디테일을 만들었다고 판정하지 않는다. 큰 비례·장갑색이 달라지면 요청 범위와 다시 대조한다.
3. **관절과 손톱:** 양손 30개 독립 마디와 실제 주먹/활/상자 포즈에서 weighted surface와 15개 corrective가 움직이는지 확인한다. 손톱의 neutral 및 최대 굽힘 실제 삼각형 내부까지 피부와 비교해 새로운 관통·들뜸을 확인한다. nail root 고정이나 vertex 검사만으로 면 내부 관통을 통과시키지 않는다.
4. **기존 locality:** pure-other digit weight가 전혀 없는 정점은 해당 key delta가 exact zero여야 한다. 현재 radial 40mm, delta 10µm..1.5mm, axial 14.2mm(중지1·약지1만 근거가 있는 15mm) 검사를 기본으로 유지한다. 새 보정 범위가 정당하게 달라질 때에만 실제 표면/의존 weights 근거로 해당 조건을 재평가한다.
5. **왕복·PBR:** 새 GLB의 16본·15키·weights·UV·형상 및 portable embedded PBR 연결을 editable과 대조한다. 8-weight skin과 기존 exporter의 tiny-weight pruning은 실제 원본 GLB named-weight 대응으로 구분한다. 새 tangent는 unit/normal 직교 및 UV 방향과 맞아야 한다. 새 노멀/거칠기 데이터는 실제 비평평한 유효 영역과 mip 경계를 확인한다.
6. **실제 기능과 외형:** 기존 관련 headless 7개와 창 없는 실제 GPU 18개 포즈는 회귀 기준으로 활용한다. 별도 손가락 10면 근접 비교를 새 이미지 10장과 대조하여 차이를 기록한다. 숫자 검증 PASS는 외형 유사성 PASS를 대신하지 않는다.

조사 단계에서는 새 모델이나 게임 시험을 실행하지 않았다. 위 전략 중 실제 새 변경 범위에 해당하는 검사만 수행하며, 동일 자료에 대한 불필요한 반복 실행은 피한다.
