# 정베기를 복원된 역베기에서 구성 — 2026-09-13

사용자의 최신 요청은 복원된 `left_reverse`를 유지하고 정베기만 유사한 모션으로 반대 방향을 따라가게 만드는 것이다. 이전 정베기 고정각 기준을 이번 요청으로 대체한다. 변경 전 게임·시험·문서 10개는 `baseline/`에 보존한다.

`author_forehand.py`는 Mac Blender에서 기존 역베기의 검·오른팔 포즈를 재사용한다. 준비·베기 0~0.80초는 `t = 1.42 - 원본 시각`으로 배치하고, 회수에서는 원본 준비의 정지 구간을 생략하여 원래 자세들을 따라 대기로 돌아온다. 손목·팔 포즈를 공간 대칭하거나 새로 풀지 않는다. 별도의 정베기 손목 준비는 제거했고, 정베기 진입은 타격 시점인 0.145초에 기존 궤적에 합류한다. 역베기·내려베기는 0.10초 연결을 유지한다. 공격 시간·차지·피해·기력·방패 판정은 유지한다.

후보 01은 v2 데이터의 방패·검 시각 동기 조건 때문에 로딩 검사를 실패했다. 후보 02는 원래 정베기 방패를 Godot의 실제 샘플러로 새 시각 격자에서 읽어 동기화한다. 방패를 거꾸로 재생하지 않는다. 일회성 제작 보조 `forehand_shield_resample_export_test.gd`는 실행 후 이 폴더에 보관했으며 자동 런타임 시험 목록에 남기지 않았다. `shield_samples.json`은 이 보조 도구의 원본 곡선 표본이다.

후보 02의 실제 화면에서는 진입과 회수에 손·검이 화면 밖에 머무르는 구간이 드러났다. 후보 03은 타격 전 연결을 연장하고 원본 역베기 준비의 긴 정지 구간을 회수에서 생략한다. 0.803333333초의 첫 회수 키는 원래 베기 끝의 이웃 시각·자세를 유지하여 베기 구간의 보간도 보존한다. 이후 1.42초까지 원본 역베기의 0.341666667→0초 자세를 이어 간다. `forehand_timeline.json`에 최종 141개 원본 포즈의 대응을 기록한다.

`preflight_02.log`의 진입·팔·촬영 구성 3종과 `regressions.log`의 기하·실제 시험룸·복귀·양손 파지·모션 통일·공격 종류 6종이 통과했다. 기존 `sword_clash` 자연 교차 시험은 변경 전과 같은 5개 assertion에서 실패한다. 이 실패를 통과로 표시하지 않으며 앞선 진단은 `../sword_edge_alignment_20260913/validation_summary.json`에 보존돼 있다.

`source_preservation.json`은 역베기를 포함한 다른 9개 클립과 원본 모델 보존 기록이다. `geometry_verification.json`은 같은 접촉 자세, 반대 진행 방향, 실제 검 끝·중간 궤적과 손목 연결 검사 결과다. 자동 기하 검사는 미학적 완성이나 사용자 승인을 대신하지 않는다. 실제 화면의 타격 전 회전과 회수 끝자세는 별도로 검토한다.

최종 후보 03의 관련 자동 검사 5종은 `final_regressions.log`에서 통과했다. 최종 기하 결과는 `geometry_final_verification.json`에 구분한다. 방패·양손 실제 촬영 총 364 PNG 중 역베기 182장은 변경 전과 모두 같았다. 정베기의 우→좌 진행·복귀와 보이는 메시를 검토했다. 원본 역베기의 회수 소실 22프레임에 비해 정베기는 15프레임이지만, 진입의 완전 소실 한 프레임은 남았다. `validation_summary.json`과 `visual_review.json`은 이 한계를 포함한다. 자연 검격 교차 시험은 `final_clash.log`의 별도 결과로 유지한다.
