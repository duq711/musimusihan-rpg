# 던전 모험가 — 팔·소매 정렬 수정본 (얼굴 미완료)

첨부 사진 같은 실사 얼굴은 아직 구현하지 못했습니다. 이번 수정에서 얼굴은 변경하지 않았습니다. 이 파일은 기존 손발 교정본의 팔이 소매 밖에 떠 보이는 위치 문제를 수정한 중간 작업물입니다.

## 이번 수정

- 팔 시작점을 소매 중심으로 옮겼습니다. 최대 이동량은 뒤쪽 6.3 cm, 위쪽 2.8 cm이며 손끝으로 갈수록 보정을 줄였습니다.
- 팔의 숨겨진 뿌리를 소매 안쪽으로 12 cm 연장했습니다. 소매 끝에서 팔이 잘려 보이지 않도록 했습니다.
- 머리·의상 면을 삭제하지 않았습니다. 얼굴 눈 교체 시험본은 더 부자연스러워 최종 파일에 반영하지 않았습니다.
- 내보낸 GLB를 다시 불러와 양쪽 소매 축 방향·위·옆·정면에서 기본 자세의 연결 위치를 확인했습니다.
- 제한된 팔 회전 시험에서는 소매가 찌그러지는 문제가 남았습니다. 애니메이션용 웨이트와 옷 변형 수정은 미완료입니다.

## 파일

- `dungeon_adventurer_repaired.blend`: Blender 편집용. 텍스처 포함. 캐릭터 정면이 보이도록 저장했습니다.
- `dungeon_adventurer_repaired.glb`: Godot 등에서 가져올 수 있는 스킨 메시.
- `preview.png`: 실제 모델의 정면 렌더.
- `validation_report.json`: 내보낸 GLB를 다시 불러와 확인한 구조와 기본 포즈 검사 기록.
- `godot_import_check.json`: 별도 임시 Godot 프로젝트에서 수행한 가져오기 검사 기록.

## 이전 교정 작업에서 유지한 내용

- 뭉치고 울퉁불퉁하던 손·발을 해부학적 기본 인체 메시로 교체했습니다.
- 손목 이음선을 없애기 위해 소매 안쪽부터 손끝까지 연결된 팔뚝·손을 사용했습니다.
- 다섯 손가락, 엄지, 발가락, 발볼, 뒤꿈치 형상을 정리했습니다.
- 발목을 원래 다리의 천 감싸개 안에 맞췄습니다.
- 얼굴의 겹친 정점 경계를 연결하고 표면을 부드럽게 정리했습니다. 얼굴 노멀의 과한 요철 표현도 줄였습니다.
- 잘못된 피부 투명 설정, 숨겨진 보조 면의 내보내기 문제를 수정했습니다.
- 기존 머리카락·수염·의상 디자인은 유지했습니다.
- 다운로드한 원본 GLB는 덮어쓰거나 삭제하지 않았습니다.

이번 GLB 검사 범위는 기본 자세의 양쪽 소매 연결, 정면·옆·상단 화면과 제한된 팔 회전입니다. 이전 검사에서는 후면·얼굴·손등·손바닥·발도 살펴봤으나, 그것만으로 소매 정렬 문제를 발견하지 못했습니다. 따라서 가져오기 성공이나 삼각형 수가 시각적 완성을 뜻하지 않습니다. 실제 게임 프로젝트는 변경하지 않았습니다.

## 아직 남은 부분

- 얼굴은 원본 표면 정리 수준입니다. 눈·코·턱의 정밀한 참조 매칭과 실사 머리카락·수염 재제작은 미완료입니다.
- 정상적인 눈꺼풀·안구 연결과 입술 형태를 재구축해야 하며, 단순 표면 평활화나 안구 삽입만으로 해결되지 않았습니다.
- 팔·손·발 피부가 얼굴보다 밝고 매끈합니다. 전신 재질의 일관성을 더 맞출 필요가 있습니다.
- 원본 소매 끝과 의상 일부는 다소 각지고 단순한 형태를 유지합니다.
- 상용 게임의 최종 캐릭터로 확정하기 전 팔꿈치·손가락·발목 변형, 애니메이션, LOD와 엔진 조명을 추가 검증해야 합니다.

## Blender에서 보기

캐릭터를 가리지 않도록 리그·조명·카메라는 뷰포트에서 숨겼습니다. 리그 편집 시 Outliner에서 `Dungeon_Adventurer_Rigify`를 표시하면 됩니다. Rigify UI 스크립트는 보존하되 자동 실행하지 않도록 저장했습니다. 전역 Python 자동 실행 허용을 켤 필요가 없습니다.
