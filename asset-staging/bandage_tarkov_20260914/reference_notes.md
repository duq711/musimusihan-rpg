# 붕대 모션 · 새 사용자 참고 영상

사용자 지정: https://www.youtube.com/watch?v=Q9hG7zeQ3xM&t=50s
영상: Ultimate Weapon Games, All Healing and Medical Animation - Escape from Tarkov [2022] | 4k.

Chrome 실제 영상에서 60fps 프레임 이동으로 확인했다. 영상/게임 에셋은 내려받거나 가져오지 않았다.

- 50~51초: Grizzly 의료 가방에서 물품을 꺼내는 준비.
- 약 52초: 양손으로 붕대를 펼치고 양쪽으로 당김.
- 약 53초: 왼팔이 화면 하단을 가로지르며 왼손은 오른쪽 화면 밖으로 향함.
- 53.5, 54.5, 55.5초: 오른손이 붕대를 쥐고 왼팔 위로 올라오는 약 1초 주기의 세 번 감기.
- 각 반복 사이에 오른손이 아래로 내려가 대부분 화면 밖으로 가려짐.
- 56~56.5초: 아래쪽으로 마무리하고 팔을 내림.

게임 반영: 단독 붕대의 준비/펼치기, 낮은 왼팔 배치, 세 번 감기, 아래로 당기기와 복귀. Grizzly 가방/현대식 포장 브랜드는 이 게임의 붕대 물품에 추가하지 않는다. 현재 손 리그로 재구성한 동작이며 원본 프레임과 동일한 리타겟은 아니다. 누적 붕대와 치료 효과/소비 시점은 유지한다.
