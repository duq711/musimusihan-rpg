# 긴 손잡이 · 비스듬한 1인칭 파지

첫 번째 참고 사진의 긴 손잡이 비율과 두 번째 게임 화면의 비스듬한 검 면을 반영한 정적 수정본입니다.

- 손잡이 가죽 부분을 약 29cm로 늘려, 가드 바로 아래를 쥔 손 밑에 여유 길이를 남겼습니다.
- 손과 접촉하는 위쪽 손잡이의 두께는 유지하고 끝 장식은 아래로 옮겼습니다.
- 칼날의 넓은 면과 가드가 비스듬히 보이도록 파지 방향을 조정했습니다. 칼날 축은 세로에 가까운 약한 기울기입니다.
- 손·손가락을 늘려 손잡이에 맞추지 않았습니다. 손과 팔을 포함한 정적 자세를 함께 회전했습니다.

`compare.html`에서 네 방향의 생성 참고 이미지와 실제 모델 렌더를 비교할 수 있습니다. `references`에는 각 방향을 따로 생성한 PNG가, `renders`에는 같은 모델을 배치한 정지 렌더가 있습니다.

`model/SwordHold_Static.blend`는 텍스처를 포함한 Blender 원본입니다. `model/SwordHold_Static.glb`는 텍스처를 내장한 Godot용 파일입니다. GLB 씬을 Camera3D 자식으로 배치하고 위치·회전은0, 크기는1로 시작합니다. 단위는 미터이고 Godot 기준 X오른쪽, Y위, −Z정면입니다. 기준 세로시야각은76도입니다.

애니메이션, 스켈레톤, 스킨 변형은 없습니다. 공격이나 검 꺼내기 동작을 추가한 파일이 아닙니다.

생성 참고는 native `image_gen.imagegen`으로 제작했습니다. 실제 프롬프트는 `prompts.json`, 손잡이 치수·형상 보존과 가져오기 검증은 `verification`에 기록했습니다. 생성 이미지의 깊은 봉제선과 주름은 3D 모델보다 세밀하며, 그 차이는 비교 화면에 그대로 표시됩니다.
