# 잔향의 성소: 검은 성물실

Godot 4.7로 만든 Steam PC용 실시간 1인칭 다크 판타지 RPG 수직 슬라이스입니다. 필요한 UI 배경과 글꼴을 프로젝트에 포함했으며, 게임 시작 직후에는 직접 걸어 다니며 생활 기능을 사용할 수 있는 3D 은신처에 들어갑니다.

현재 월드·적·무기·방패·횃불·상자·함정·귀환문은 AI 생성 실사 텍스처와 Godot 절차형 GLB로 교체되어 있습니다. 적 2종도 빌보드 이미지가 아니라 앞·옆·뒤가 모두 존재하는 실제 3D 메시입니다. 특히 ‘굶주린 성소지기’는 공식 BodyParts3D 해부 데이터를 사용한 `anatomical_skeleton_cc_by_4.glb` 기반의 무장 없는 202파트·513,164 삼각형 골격입니다. 12쌍의 갈비뼈·24개 척추·완전한 손과 발·빈 안와를 갖추고 골반·어깨·팔꿈치·손목·고관절·무릎·발목 피벗으로 움직입니다. 데스크톱은 Forward+와 TAA·SSAO·SSIL·glow를 기본 사용하며, 생성 프롬프트와 무료 재현 방식은 [`ASSET_PIPELINE.md`](ASSET_PIPELINE.md)에 정리했습니다.

### 테스트룸

은신처 폐허는 여덟 방 각각의 목표 그림과 실제 1인칭 화면을 비교합니다. 내장 ImageGen 목표는 `assets/ai/hideout_ruins/concept_<방 ID>.png`, Blender 원본은 `../asset-staging/hideout_ruins_blender/hideout_ruins_kit.blend`, 실제 모델은 `assets/3d/hideout_ruins/`에 보존합니다. `scripts/hideout_ruin_views.gd`의 같은 카메라 목록으로 시험 항목과 화면 촬영을 연결합니다. `HIDEOUT_RUIN_QA_ITERATION=review_01 GODOT_PREVIEW_TIMEOUT_SECONDS=300 ./tests/run_embedded_preview.sh hideout_ruin_preview.gd`는 방별 실제 화면을 `artifacts/visual_qa/hideout_ruins/review_01/`에 각각 저장하며 새 반복 이름을 사용해야 합니다. 자세한 방 목록은 [TEST_ROOM.md](TEST_ROOM.md), 실행 조건은 [숨김 렌더링 안내](tests/EMBEDDED_RENDERING.md)를 참고하세요.

`GODOT_TEST_TIMEOUT_SECONDS=300 ./tests/run_headless_tests.sh hideout_ruin_masonry hideout_ruin_materials hideout_ruin_closures hideout_ruin_preview hideout_ruin_test_room hideout_3d test_room_session`으로 실제 방 진입·장식·시점·생활 기능·복귀와 상태 보존을 검증합니다. 돌 표면의 실제 형상 변화와 원본 보존, 재질·셰이더 연결, 여덟 목표 이미지와 일곱 Blender 모델, 지붕 구멍 9개와 원래 천장 충돌체 보존도 확인합니다. 예배당 출입구와 공방 배수문 위의 의도하지 않은 사각 틈은 석재로 메우며, `hideout_ruin_closures`로 실제 보강 형상과 기존 충돌체 보존을 검사합니다. `hideout_ruin_preview`의 헤드리스 검증은 촬영 장면·카메라·원정과 커서의 보존을 확인하며, 실제 픽셀 비교에는 위 숨김 렌더러 촬영을 사용합니다.

연금술은 `테스트룸 → 장면 → 연금술`의 제조·절구·증류·품질 시험과 원본 카탈로그의 처방별 항목에서 바로 시작할 수 있습니다. 본편에서는 은신처 작업실의 대장간 맞은편 연금대에 다가가 `E`를 누릅니다. 중개인에게 처방에 적힌 액체·약초와 빈 약병 2개를 먼저 구입하세요. 약품은 상급 2병, 보통·미약 1병이 나오며 가방에서 실제 회복·지혈·수분 회복에 사용할 수 있습니다. `술 증류`를 선택하면 판매용 증류주 두 처방으로 전환합니다.

`Space` 풀무, `R` 솥 높이, `T` 모래시계, `G` 절구 한 번, `H` 젓기, `B` 병입을 사용합니다. 도구를 직접 클릭하거나 오른쪽 버튼으로도 작업할 수 있고, 작업대 위의 시점 버튼으로 절구·솥·증류기를 가까이 봅니다. `조제서 크게 펼치기`로 전 과정을 읽고, 완성 후 결과와 오류 사유를 확인한 뒤 `같은 처방으로 다시 만들기`로 재시도합니다. `Esc`로 닫으면 현재 제조와 모래시계가 멈추며 같은 은신처에서 다시 열면 이어집니다. 폐기·장면 이동·시험 `F2` 복귀 시 미완성 배합은 사라지고 사용한 재료는 반환되지 않습니다.

상세 규칙과 참고 시연 비교는 [ALCHEMY.md](ALCHEMY.md), 시험 절차는 [TEST_ROOM.md](TEST_ROOM.md)를 참고하세요. 자동 검증은 `./tests/run_headless_tests.sh alchemy_system alchemy_overlay alchemy_visual alchemy_test_room`으로 실행합니다.

술을 만들어 돈을 벌려면 `은신처 작업실 연금대 E → 술 증류 → 화롯불 브랜디 / 달쑥 압생트`를 선택하고 조제서대로 재료를 넣어 달입니다. 솥을 올려 끓임을 멈춘 뒤 `증류 시작`, 다시 솥을 내려 불을 유지하고 증류가 끝나면 `빈 병에 받기`를 누릅니다. 실제로 끓는 동안에만 증류가 진행되며, 증류 전에 직접 병입할 수 없습니다. 완성 술은 가방에 남는 판매품입니다. `Esc → M → 성소의 중개인 → 물건을 거래합니다 → 내 가방의 술 선택 → 판매`로 병당 값을 받습니다.

| 증류주 | 재료 | 정제 1병: 원가 / 판매 / 이익 | 특급 2병: 원가 / 총판매 / 이익 |
|---|---|---|---|
| 화롯불 브랜디 | 포도주 1병·핏뿌리 1줌·새벽잎 1줌·빈 병 | 12 / 36 / 24 크라운 | 14 / 120 / 106 크라운 |
| 달쑥 압생트 | 곡물 증류주 1병·달쑥 2줌·쓴박하 1줌·빈 병 | 19 / 51 / 32 크라운 | 21 / 168 / 147 크라운 |

### 검은 물길 동굴

`게임 시작 → 은신처에서 M → 검은 물길 동굴`로 들어갑니다. 메인 메뉴의 `테스트룸 → 장면 → 검은 물길 동굴 · 131m × 139m`에서도 같은 원정을 시험할 수 있습니다.

Godot의 1 단위를 1m로 사용하는 가로(X축) 131m, 세로(Z축) 139m의 동굴입니다. 불규칙한 바위 벽과 천장, 종유석, 젖은 암반과 물길, 나무 지지대가 있는 통로, 지하 예배당이 이어집니다. 가까운 횃불은 따뜻하게 비추고 통로 깊은 곳은 어둡게 남아 `F`로 휴대 횃불을 켜고 탐색하도록 구성했습니다. 여섯 적, 네 룬 함정, 다섯 전리품 상자는 기존 전투·조사·수색 기능과 연결됩니다.

전체 외곽은 X −65.5~65.5m, Z −69.5~69.5m입니다. 사용자가 제공한 폐광 지도의 비정형 외곽을 따라 18개 공동과 31개 굽은 경로를 연결했습니다. 남쪽 진입 갱도에서 시작해 연속 작업실, 거수의 무덤, 서쪽 두 침수 갱도, 감독관 작업실, 북쪽 호수, 거대한 암석섬을 품은 중앙 채석장, 동쪽 자재 창고와 다리, 승강기실, 남동쪽 긴 지하호수를 탐색하고 북동쪽 기둥 성소에서 귀환합니다. 외곽 크기는 암벽을 포함한 던전 부지이며 사각형 전체가 빈 바닥은 아닙니다.

### 은신처 대장간

은신처 작업대에 가까이 가서 `E`를 누르면 0.3초 작업 준비 후 실제 대장간을 엽니다. 장검이나 한손검 제작법을 선택해 철과 숯을 화로에 넣고, `Space` 또는 작업 화면을 아래로 당겨 풀무를 움직입니다. 마우스 풀무는 24픽셀 이상 아래로 당기거나 0.25초 이상 누른 뒤 놓습니다. 철이 700~1000°C가 되면 `E`로 모루에 옮깁니다.

모루에서는 `A`·`S`·`D`로 칼날의 뿌리·중앙·끝을 선택하고 `LMB`를 약 0.75초 눌렀다 놓아 두드립니다. 앞면의 세 구간을 펴고 `R`로 뒤집어 뒷면도 단조합니다. 철이 식으면 `F`로 화로에 돌려보내 다시 가열하고, 두 면이 모두 완성되면 적정 온도에서 `Q`로 물에 담금질합니다. 마지막으로 `완성품 가방에 넣기`를 눌러 검을 받고 일반 장비 화면에서 장착합니다. 과열이나 부정확한 타격은 품질을 낮추며 완성 품질은 실제 무기 피해에 반영됩니다.

손잡이 교체·칼날 보강·룬 작업은 목록에서 선택한 실제 검 한 자루에 적용됩니다. 가죽·균형 손잡이는 공격 기력 비용을 줄이고 강철·은 보강은 피해를 높입니다. 룬은 화면에서 `LMB`를 약 0.75초 눌렀다 놓는 천공을 세 차례 완료해 구멍을 만든 뒤 넣습니다. 검 한 자루에는 두 구멍까지 만들 수 있습니다. 청록 룬은 피해와 적중 회복을, 잿불 룬은 타격 피해를 높입니다. 재료가 없거나 단계가 맞지 않으면 이유를 표시하며, 재료 소비와 변경은 개별 검의 정보로 기록됩니다.

`Esc`로 닫으면 은신처에서 하던 작업을 유지하고 다시 작업대에서 이어갈 수 있습니다. `작업 포기`·다른 장면으로 이동·테스트룸 `F2` 복귀는 미완성 철을 정리하며 이미 투입한 재료를 돌려주지 않습니다. 완성한 검과 적용한 개조는 가방에 보존됩니다. 작업 화면에서는 은신처 이동과 생존 시간이 멈추고 대장간의 열과 작업만 진행합니다.

천공 진행은 검 자체에 남으므로 화면을 닫거나 장면을 옮겨도 같은 검을 다시 선택해 이어갈 수 있습니다. 구멍 하나를 처음 팔 때 강철 부속 1개를 쓰고 후속 천공은 중복 소비하지 않습니다.

제작 품질·개조·천공 진행이 있는 검은 상점의 같은 종류 묶음 판매에서 보호합니다. 일반 검과 함께 보유해도 일반 검만 판매하며, 상점에 판매 가능 수량과 보호 수량을 표시합니다.

테스트룸의 `장면` 탭에는 `대장간 · 화로부터 검 완성`, `대장간 · 손잡이 교체`, `대장간 · 칼날 보강`, `대장간 · 구멍 파기와 룬 삽입`이 있습니다. 실제 은신처와 같은 제작 화면으로 연결되며, 제작 재료도 물품 탭과 보급 상자에 원본 카탈로그에서 자동 등록됩니다. 가득 찬 시험 가방은 끝의 시험용 스택 일부를 보급품으로 교체할 수 있습니다. 원래 원정의 물품과 강화 정보는 건드리지 않습니다.

`./tests/run_headless_tests.sh smithing_system blacksmith_test_room test_room_session`으로 제작·강화의 실제 효과와 반복 입장, F2 복귀, 초기화 및 원래 원정 복원을 확인합니다. 헤드리스 검증은 실제 화면의 픽셀 품질이나 참고 영상과의 시각적 유사도를 보증하지 않습니다.

실제 대장간 화면은 `BLACKSMITH_QA_ITERATION=iteration_01 ./tests/run_embedded_preview.sh blacksmith_preview.gd`로 창 없이 촬영합니다. 공방·화로와 풀무·모루·담금질·손잡이·칼날·천공·룬 삽입·완성 검 장착의 9장은 `artifacts/visual_qa/blacksmith/<반복 이름>/`에 저장되며, 실제 제작 화면과 격리된 가방을 사용합니다. 기존 폴더를 덮어쓰지 않고 원본 해시·커서·원정 보존과 뷰포트 내부 버튼 클릭 결과를 기록합니다. 상세 조건은 [숨김 렌더링 안내](tests/EMBEDDED_RENDERING.md)를 따릅니다.

생성 목표 이미지와 실제 게임의 반복 비교, 최종 작업 화면, 검증 범위는 [대장간 화면 검증 기록](artifacts/visual_qa/blacksmith/REVIEW.md)에 정리했습니다.

### 1인칭 모션 화면 검증

2026-09-07 개별 자세 개정: 실제 좌우 손 모델의 잘못된 배정과 손가락 원본 관절 회전을 지우던 오류를 수정했습니다. 검·방패를 함께 장착한 베기는 준비 후 145ms에 타격하고 300ms 동안 베며, 적의 검과 부딪히면 충돌한 자세에서 회수합니다. 검 단독의 55ms 타격·160ms 베기와 적의 공격 시각은 유지합니다. 준비 자세는 손과 칼자루 끝장식이 화면에 들어오도록 조정했습니다.

손가락 마디 길이와 파지 중심을 맞춰 네 손가락이 같은 쪽에서 손잡이를 감싸게 하고, 검을 거둘 때 손목이 과하게 꺾이지 않도록 조정했습니다. 손목 뒤쪽의 긴 피부·장갑 끝도 소매 안으로 들어가도록 줄였습니다. 새 생성 참고는 `../asset-staging/sword_shield_single_pose/references/`에 한 파일당 한 자세·한 방향으로 보존합니다. 같은 폴더의 `build_review.py <촬영 이름>`으로 만드는 검토 화면은 이미지 하나 또는 실제 게임 MP4 하나만 표시합니다. MP4는 실제 촬영 원본을 30fps로 인코딩한 영상이며 AI 생성 영상이 아닙니다. 이전 여러 자세 시트와 좌우 교정 이전 촬영은 과거 기록으로 보존하며 현재 품질의 완료 근거로 사용하지 않습니다.

검·방패의 양손 파지와 팔 동작을 새로 제작했습니다. 기본 `LMB` 공격은 우측 대각 베기 → 좌측 역베기 → 상단 내려베기로 순환하며, `RMB`는 방패를 올리고 놓으면 내립니다. 실제 공격을 방패로 막으면 팔꿈치가 접히며 방패가 뒤로 밀린 후 가드 자세로 돌아옵니다. 검 손잡이는 손가락별 관절로 감싸고, 방패 손은 실제 뒤쪽 손잡이를 쥔 채 팔 고정 끈을 따라 움직입니다. 손 피부·관절을 유지하면서 전용 가죽 토시와 두 고정 끈·천 소매도 교체했습니다.

### 상자 맨손 열기

닫힌 상자는 손이 닿을 만큼 가까이 다가가야 열 수 있습니다. 멀면 조준 안내에 접근 메시지가 나옵니다. 여는 도중 `E`를 다시 누르거나 시선을 돌리면 취소됩니다.

닫힌 상자를 바라보고 `E`를 누르면 무기를 잠시 넣고 맨손으로 잠금을 만지고 뚜껑을 여는 동작이 1.2초 조사 진행에 맞춰 이어집니다. 이는 장착 해제가 아니므로 가방에 빈칸이 없어도 물품이나 장비 슬롯을 바꾸지 않습니다. 상자 수색 화면이 열린 동안에도 무기는 숨겨져 있고 화면을 닫거나 여는 동작을 취소하면 원래 장비 표시로 돌아옵니다. 이미 연 상자는 기존 규칙대로 바로 수색하며 물품을 새로 생성하지 않습니다.

테스트룸의 같은 상자 항목을 다시 선택하면 이전 상자와 다른 시험 대상을 정리하고 원본 카탈로그의 닫힌 보급 상자를 새로 만듭니다. `I`에서 무기를 바꾼 뒤 `F2`로 같은 항목을 선택해 비교하세요. 무기 없는 상태도 가능하며 특정 무기를 강제로 장착하지 않습니다. `F2`·회복·대상 재생성·다른 시험으로 이동 시 진행 중인 맨손 동작은 정리되고, 시험 종료 시 원래 원정의 물품·장착 상태가 복원됩니다.

### 던전 야영

적과 거리를 벌리고 평평한 바닥에 멈춘 뒤 `C`를 누르면 모닥불과 야영 계획이 열립니다. 기본 가방에는 `휴대 야영 도구`(`camp_kit`) 1개가 있으며 상인과 던전 입구에서도 구할 수 있습니다. 설치 시 플레이어 주위 8m 안에 적이 없고 전방에 충분한 바닥과 빈 공간이 필요합니다. 설치 예정 위치 1.5m 안에 미해제 룬 함정이 있어도 설치할 수 없습니다. 은신처·공중·이동 중·공격이나 상호작용 중에는 설치할 수 없습니다.

계획을 보며 행동을 고르는 동안은 세계가 일시정지됩니다. 실제 휴식을 시작하면 시간과 적이 다시 움직이고, 선택한 활동에 맞춰 생존 시간이 흐릅니다. 야영의 온기는 3이며 첫 행동을 시작할 때 도구 1개를 소비합니다. 같은 야영 안에서는 도구를 추가로 사용하지 않습니다.

| 행동 | 실제 대기 / 생존 시간 | 완료 효과 | 시작 비용 |
|---|---|---|---|
| 경계 휴식 | 8초 / 1분 | 체력 +20, 기력 +70, 스트레스 −18 | 온기 1 |
| 식사 휴식 | 14초 / 3분 | 체력 +45, 기력 최대, 식량·물 회복, 스트레스 −30 | 온기 2, 식량 1, 물 1 |
| 응급처치 | 6초 / 30초 | 체력 +18, 출혈 해소, 스트레스 −6 | 온기 1, 붕대 1 |

첫 행동에는 표의 비용과 별도로 야영 도구 1개가 필요합니다. 효과는 각 활동을 완료해야 적용되며, 생존 시간과 상태이상 남은 시간은 진행한 만큼 반영됩니다. 온기·필요 물품이 부족하거나 회복할 상태가 없으면 시작하지 않습니다. 응급처치는 골절과 저주를 직접 해제하지 않습니다.

`Esc` 또는 `C`로 떠날 수 있습니다. 적이 6m 안으로 접근하거나 피격·사망·이동·인벤토리 열기·장면 전환·창 포커스 해제가 일어나면 휴식을 중단합니다. 이미 사용한 도구·식량·물·붕대·온기는 반환되지 않으며, 완료 보상도 받지 않습니다. 계획만 보고 떠나면 도구는 소모되지 않습니다. 온기가 부족하면 야영을 정리하고 새 도구로 다시 설치해야 합니다.

### 은신처 화롯불 요리

은신처 가운데 화롯불 위에 매달린 냄비를 바라보고 `E`를 누르면 0.3초 준비 후 조리 화면을 엽니다. 고기는 꼬치에 굽고, 수프와 스튜는 냄비에 끓입니다. 조리법을 고르면 실제 가방의 재료를 소비하며, 각각 8·10·14초 후 완성 즉시 먹고 체력·기력·포만감·수분을 회복하고 스트레스를 낮춥니다. 세 조리법의 재료와 효과는 아래 야영 요리 표와 같습니다.

은신처에서는 이미 설치된 화롯불을 사용하므로 야영 도구나 온기를 소비하지 않습니다. 불이 꺼져 있으면 먼저 화롯불에 `E`로 불씨를 살려야 합니다. 조리 화면을 연 동안 이동과 평상시 생존 시간은 멈추며, 조리 중에는 선택한 조리법의 생존 시간만 진행됩니다. 재료가 부족하면 시작할 수 없고, 완성 음식을 가방에 새로 넣지 않아 가득 찬 가방에서도 먹을 수 있습니다.

`Esc`로 조리 화면을 닫습니다. 조리 중 닫거나 장면 이동·테스트룸 `F2` 복귀로 중단하면 이미 사용한 재료와 경과한 생존 시간은 유지되고 식사 효과는 받지 않습니다. 다시 열면 새 요리를 선택할 수 있습니다. `테스트룸 → 장면 → 은신처 · 화롯불 조리와 식사`는 같은 실제 냄비·조리 화면과 원본 조리법 재료를 준비하며, 재선택·초기화·종료는 기존 시험 세션 격리·복원 규칙을 따릅니다.

`./tests/run_headless_tests.sh hideout_cooking_controller hideout_cooking_test_room hideout_cooking_visual cooking_system cooking_hud test_room test_room_session`으로 실제 조리와 식사, 중앙 냄비 상호작용, 불·재료 조건, 중단·반복 복귀·원정 복원을 검증합니다. 실제 화면은 `HIDEOUT_COOKING_QA_ITERATION=<새 이름> ./tests/run_embedded_preview.sh hideout_cooking_preview.gd`로 촬영합니다. 중앙 화롯불의 조리 기구와 실제 조리 화면 6장을 별도 반복 폴더에 저장하며, 숨김 렌더러와 입력·커서 보존 조건은 [숨김 렌더링 안내](tests/EMBEDDED_RENDERING.md)를 따릅니다. 헤드리스 결과는 화면 픽셀 품질 검증을 대신하지 않습니다.

### 야영 요리

안전한 바닥에서 `C`로 야영을 열고 `요리` 탭에서 조리법을 선택합니다. 계획 중에는 시간이 멈추고, 조리를 시작하면 실제 세계가 움직입니다. 필요한 재료와 온기는 시작 즉시 소비되며, 같은 야영의 첫 활동이라면 야영 도구 1개도 필요합니다. 완성하면 그 자리에서 자동으로 먹어 회복하며, 별도의 완성 음식 아이템을 가방에 저장하지 않습니다.

| 조리법 | 재료 / 온기 | 조리 시간 / 생존 시간 | 완료 후 식사 효과 |
|---|---|---|---|
| 모닥불 고기구이 | 생고기 1 / 온기 1 | 8초 / 60초 | 체력 +18, 기력 +35, 포만감 +40, 스트레스 −12 |
| 따뜻한 버섯수프 | 식용 버섯 2, 물 1 / 온기 1 | 10초 / 90초 | 체력 +12, 기력 +30, 포만감 +30, 수분 +45, 스트레스 −16 |
| 고기·버섯 스튜 | 생고기 1, 식용 버섯 1, 물 1 / 온기 2 | 14초 / 120초 | 체력 +35, 기력 +65, 포만감 +65, 수분 +35, 스트레스 −24 |

조리 중에도 정해진 생존 시간이 진행되므로 실제 포만감·수분 변화에는 그동안의 소모가 포함됩니다. 모든 회복은 최대 수치까지만 적용됩니다. 온기나 재료가 부족하면 시작하지 않으며, `Esc`·`C`·`F2`, 이동·피격·적 접근 등으로 중단하면 이미 사용한 재료와 온기는 반환하지 않고 식사 효과도 주지 않습니다. 같은 야영에서는 도구를 다시 쓰지 않지만, 온기가 부족하면 정리한 뒤 새 도구로 야영을 설치해야 합니다. 기존 `식사 휴식`은 조리와 별개로 식량·물을 사용하는 활동입니다.

`손질한 생고기`와 `식용 버섯`은 기본 가방에 각각 1개·2개가 있습니다. 던전 입구 보급 상자에는 생고기 2개·식용 버섯 3개·물 2개가 제공되며, 상인의 초기 재고는 생고기 6개(개당 10크라운)·식용 버섯 8개(개당 5크라운)입니다. 조리법·재료·효과의 원본은 [`CampCookingCatalog`](scripts/camp_cooking_catalog.gd)입니다. 테스트룸 요리 시험은 이 목록 전체에 필요한 재료를 합산하고 각 재료를 1개씩 더 보급합니다. 세 요리는 총 온기 4를 사용하므로 모두 비교하려면 야영 두 번이 필요합니다. 시험 가방이 가득 찬 경우에만 마지막 시험용 스택을 필요한 만큼 교체하고 알리며, 원래 원정의 물품은 바뀌지 않습니다.

### 사슬철퇴

기본 가방의 `사슬철퇴`(`chain_flail`)를 `I`에서 무기 슬롯에 장착하세요. `LMB`는 근접 타격으로 피해 32, 기력 18을 소모합니다. 타격은 시작 0.2초 뒤 한 번 발생하고 전체 동작은 0.65초입니다.

`RMB`를 누르면 화면 오른쪽에서 사슬과 철구를 회전시키고, 놓으면 조준 방향으로 철구를 던집니다. 짧게 클릭해도 최소 0.35초 회전한 뒤 투척하므로 회전 동작이 생략되지 않습니다. 1.2초에 최대 힘이 되며, 회전 속도는 초당 3~5회, 최대 투척 피해 60·사거리 14m·속도 26m/s입니다. 기력은 회전 시작 시 24를 한 번만 소모하며, 계속 회전하거나 던지고 회수할 때 추가 비용은 없습니다.

철구는 실제 적이나 벽에 맞거나 최대 거리에 도달하면 사슬을 따라 자동으로 돌아옵니다. 적에게 주는 피해는 나갈 때 한 번뿐이고 돌아오는 동안에는 피해를 주지 않습니다. 회수 속도는 22m/s이며, 돌아온 뒤 0.25초의 준비 시간이 있습니다. 철구가 돌아오기 전에는 다른 철퇴 공격을 시작할 수 없고 화살·철퇴 아이템은 소모되지 않습니다. 철퇴를 장착한 동안 `RMB`는 방패 대신 회전 공격입니다.

회전·타격·비행 도중 인벤토리나 일시정지 메뉴를 열거나, 무기를 바꾸거나, 피격되거나, 창이 포커스를 잃으면 공격을 취소하고 철구를 복원합니다. 이미 소모한 기력은 돌려주지 않습니다. 안전 지역에서는 사용할 수 없습니다. 테스트룸의 같은 항목을 다시 선택하거나 회복 버튼을 누르면 동작과 준비 시간이 초기화됩니다.

### 활과 화살

`사냥꾼의 활`(`hunting_bow`)을 무기 슬롯에 장착하고 가방에 `나무 화살`(`wooden_arrow`)을 가지고 있으면 원거리 사격을 할 수 있습니다. 화살은 30개까지 한 스택에 담기며, 발사할 때마다 1개를 소모합니다. `LMB`를 당기는 정도에 따라 기본 피해는 18~46으로 증가합니다. 즉시 놓은 화살의 기본 피해는 18, 0.5초 당기면 32, 끝까지 당긴 1초에 최대 피해 46이며, 더 오래 유지해도 피해는 늘어나지 않습니다. 머리에 맞으면 피해가 1.5배이며 발사 후에는 0.55초의 준비 시간이 있습니다. 화살은 실제 공간을 날아가며 중력의 영향을 받고, 벽이나 적에 부딪히면 박힌 뒤 잠시 후 사라집니다.

0.1초 이하로 짧게 당기고 놓으면 화살이 앞으로 날아가지 않고 발사 위치 바로 아래로 떨어집니다. 초기 낙하 속도는 1m/s, 중력은 9.8m/s²이며 화살 1개는 그대로 소모됩니다. 0.1초를 넘겨 당길수록 추진 속도가 0~42m/s로 증가하고 중력은 9.8~5m/s²로 줄어들어 더 멀리 날아갑니다. 0.5초 당김은 약 18.7m/s, 완전 당김은 42m/s입니다. 아주 약한 화살은 목표에 닿기 전에 바닥에 떨어질 수 있습니다.

활을 당기거나 완전히 당긴 채 유지하는 동안 기력이 초당 22씩 소모됩니다. 따라서 0.5초에 11, 1초에 22, 2초 유지 시 44가 소모되며, 발사 순간에는 별도 기력 비용이 없습니다. 당기는 도중 기력이 0이 되면 그 순간까지 당긴 힘으로 화살 1개를 자동 발사합니다. 완전 당김이었다면 피해 46의 최대 사격, 덜 당겼다면 그만큼 약한 사격이며, 0.1초 이하에 고갈되면 발밑으로 떨어집니다. 이후 `LMB`를 놓아도 다시 발사하지 않습니다. 기력이 조금이라도 남아 있으면 당기기와 수동 발사가 가능하고, 당기는 중에는 기력이 재생되지 않습니다. HUD에서 현재 기본 피해와 지속 기력 소모를 확인할 수 있습니다.

0.1초를 넘겨 약하게 당긴 사격은 발사 방향이 조준 방향 주변으로 무작위로 크게 흩어지고 활·화면의 순간 반동도 큽니다. 더 오래 당길수록 흩어짐과 반동이 줄어들며, 최대 1초를 채우면 발사 방향이 조준 방향과 정확히 일치합니다. 최대 흩어짐 각도는 `12° × (1 − 당김 비율)²`로, 당김 시작에는 12°, 0.5초 당기기는 3°, 1초 당기기는 0°입니다. 단, 0.1초 이하의 발밑 낙하는 조준 방향 대신 바로 아래로 떨어집니다. 대기 중 조준선은 작게 표시되며, `LMB`를 눌러 활을 당기는 순간 네 방향 조준선이 크게 벌어집니다. 당길수록 간격과 선 길이가 계속 줄어들고, 끝까지 당기면 기존 작은 조준선 모양으로 모여 그대로 유지됩니다. 중앙 조준점은 유지되며 취소하면 작은 대기 조준선으로 돌아갑니다. 반동은 잠깐 흔들렸다 돌아오는 시각 효과로 조준 방향을 영구적으로 바꾸지 않습니다. 완전히 당겨도 기존 중력에 따른 낙하는 유지되므로 먼 거리에서는 탄도를 고려해야 합니다.

사냥활은 양손 무기이므로 장착 중에는 방패로 가드할 수 없습니다. `RMB`는 시위를 안전하게 내려놓으며, 인벤토리·일시정지·테스트룸 메뉴를 열거나 무기를 바꾸거나 게임 창이 포커스를 잃어도 화살을 소비하지 않고 당기기를 취소합니다. 취소 전에 이미 소모한 기력은 반환되지 않으며, 일시정지 중에는 소모·재생이 멈춥니다. 기본 가방의 활과 화살 12개로 시작할 수 있으며, 던전 입구 보급 상자에는 활과 화살 18개가 들어 있습니다. 상인에게서도 추가로 구할 수 있습니다. 화살을 인벤토리에서 직접 사용하거나 발사한 화살을 다시 줍는 기능은 없습니다.

### 원정 생존 상태

- 던전이 실제 플레이 중인 `RUNNING` 상태일 때만 포만감과 수분이 실시간으로 감소합니다. 포만감은 100에서 0까지 약 90분, 수분은 약 60분이 걸립니다.
- 일시정지, 인벤토리, 로딩, 은신처와 상점에서는 포만감·수분 시간이 흐르지 않습니다.
- 감소 속도에는 출혈 `+0.60`, 골절 `+0.35`, 저주 `+0.50`이 가산되며, 여러 상태가 겹쳐도 최종 배율은 `2.25배`를 넘지 않습니다.
- 검지기의 공격은 출혈, 성소지기의 공격은 골절을 일으키며, 함정 실패는 저주 또는 출혈을 남길 수 있습니다.
- `마른 순례자 식량`은 포만감 `+32`, `끓인 빗물병`은 수분 `+38`을 회복합니다. 새 원정에는 각각 1개가 기본 지급되며 상인에게 추가로 구매할 수 있습니다.
- 붕대를 사용하면 출혈 상태도 해소됩니다.

### 스트레스와 지각 연출

스트레스는 원정에서 유지되는 0~100 수치입니다. 40 미만은 `안정`, 40부터 `불안`, 60부터 `동요`, 80부터 `극심`입니다. 60 이상에서는 속삭임·가까운 발소리 환청이, 80 이상에서는 잠깐 나타나는 실루엣 환영도 발생합니다. 해당 구간에 들어가 약 2초 뒤부터 실제 연출이 시작되며, 높은 수치일수록 발생 간격이 짧아집니다. 환영은 충돌·체력·공격·전리품이 없는 시각 연출이고 환청도 실제 적을 생성하지 않습니다.

실제 피해의 35%(한 번에 최대 12)가 스트레스로 더해집니다. 탐험 중 횃불 소등은 초당 0.09, 체력 30% 이하는 0.07, 포만감·수분 25 이하는 각각 0.04, 상태이상은 각각 0.035, 살아 있는 적이 8m 안에 있으면 0.06씩 더해지며 시간 누적은 초당 최대 0.4입니다. 밝고 건강하며 주변 위협이 없는 상태에서는 저절로 증가하지 않습니다.

안전 지역에서는 초당 0.35씩 줄어들며 야영 완료 시 휴식 18·식사 30·응급처치 6을 줄입니다. 중단한 야영은 스트레스 감소 보상을 주지 않습니다. 메뉴·인벤토리·야영·장면 전환·사망·창 포커스 상실 시 일시 연출은 정리되며, 정상 탐험으로 돌아오면 현재 수치에 따라 다시 발생할 수 있습니다. 새 원정은 스트레스 0으로 시작합니다. 테스트룸의 회복 버튼은 스트레스를 0으로 만들고 연출도 즉시 정리합니다.
