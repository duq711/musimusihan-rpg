# 모험가 — 머리 파츠 교체본

사용자가 제공한 파츠 분리본의 붉은 머리 `model_part1` / `mesh_1`을 제거하고, `adventurer-head-ultra-4k.glb`의 머리와 목도리로 교체했습니다.

## 결과 파일

- `adventurer_head_replaced.glb`: 외부 3D 도구에 전달할 교체본. 머리 텍스처 내장.
- `adventurer_head_replaced.blend`: 파츠를 개별 편집할 수 있는 Blender 파일.
- `preview.png`: 실제 최종 GLB를 다시 불러온 정면 렌더.
- `replacement_report.json`: 교체 대상과 다른 파츠의 형상 보존 기록.
- `validation_report.json`: 최종 GLB 재가져오기 검사 기록.

## 변경 범위

- 기존 붉은 머리/목 파츠만 제거했습니다. 나머지 9개 파츠의 정점 위치, 면 구조, 배치, 파츠 구분색은 보존했습니다.
- 새 머리는 균일 배율과 위치만 조정했습니다. 얼굴과 머리카락 형상, UV, 원본 텍스처를 유지했습니다.
- 새 모델에 포함된 목도리의 아래쪽 가장자리만 옷 안으로 들어가도록 다듬었습니다. 몸과 머리는 편집 가능한 별도 파츠이며, 하나의 연속된 표면으로 용접한 것은 아닙니다.
- 분리본 몸에 원래 노멀 데이터가 없어 부드러운 음영을 적용했습니다. 이는 저장 시 정점 중복을 줄이기 위한 것으로 몸의 형상이나 삼각형 수를 변경하지 않습니다.
- 다운로드 폴더의 원본 두 파일은 변경하거나 삭제하지 않았습니다.

## 현재 규격과 제한

- 전체 4,650,718 triangles: 몸 1,621,378 + 새 머리 3,029,340. 고해상도 원본 디테일을 유지했으며 게임용 LOD 최적화본이 아닙니다.
- 10개 메시 파츠. 두 입력 파일에 리그/애니메이션이 없어 결과도 리깅되지 않은 정적 모델입니다.
- 머리 색상·노멀 4096×4096, 금속/거칠기 2048×2048. 입력 머리의 내장 이미지를 사용합니다.
- 몸은 분리본에 있던 노랑·분홍·파랑 등의 파츠 구분색입니다. 이 파일에는 원래 피부·의상 사진 텍스처가 없으므로 복원하지 않았습니다.
- 분리본의 월드 크기를 유지했습니다. 키는 약 0.12 단위(Blender 미터 설정에서 12 cm)입니다. 실제 게임 투입 시 캐릭터 크기를 맞추는 별도 조정이 필요합니다.
- 머리 교체 작업만 수행했습니다. 분리본에 기존부터 있던 손발 형태, 파츠 중복, 의상 품질은 이번 수정 범위에 포함하지 않았습니다.

Blender는 캐릭터 정면의 재질 보기 상태로 저장했습니다. 조명·카메라는 편집 화면에서 숨겼으며 자동 실행 스크립트는 없습니다.
