# 마지막 역베기 변경 복원 — 2026-09-13

사용자가 마지막 좌우 대칭 역베기를 거절했다. `../sword_reverse_match_20260913/baseline/`에서 승인된 기본 베기와 변경 전 역베기·런타임 연결·관련 검사·테스트룸 안내를 정확히 복원했다. 거절된 버전은 `rejected/`에 별도로 보존한다.

검 방향뿐 아니라 손목 회전·팔 준비 동작까지 대칭화한 것이 요청 의도를 벗어났다. 기존 기술 검사는 기하·연결 조건을 확인했을 뿐 자연스러운 모션으로 받아들여진다는 근거가 아니었다. 이번에는 새로운 모션을 제작하지 않았다.

관련 자동 검사 4종 통과. Mac의 실제 Vulkan/embedded 렌더러로 양손 기본·역베기를 다시 촬영했고, 각각 91장씩 총 182 PNG가 변경 전 `edge_aligned_final_two_hand` 촬영과 바이트 단위로 일치했다. 이전 방패/양손 촬영의 각 78개 소스 파일도 모두 현재와 일치한다. 원정·가방·커서 보존과 현재 촬영 소스 일치를 확인했다. 세부 기록은 `validation_summary.json`, 게임 파일 해시는 `rollback_sources.json`에 있다.
