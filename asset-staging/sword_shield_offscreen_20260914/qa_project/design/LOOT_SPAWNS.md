# 장소에 맞는 루팅 상자 — 2026-09-12

사용자 확정 요구는 **상자가 있을 법한 위치에 배치하고, 같은 자리라도 맵 입장마다 있거나 없게 하는 것**이다. 고정 후보 자리를 허용했다. 무작위 좌표를 뽑는 대신 맵 디자이너가 검수한 보관 자리를 추첨한다.

2026-09-12 후속 정정: **은신처는 던전이 아니며 무작위 루팅 생성에서 제외한다.** 적용 대상은 던전인 검은 성물실(`main.tscn`)과 폐광(`cave_dungeon.tscn`)이다. 은신처(`hideout.tscn`)의 고정 개인 보관함과 생활 소품은 별도이며, 루팅 후보나 입장별 추첨을 연결하지 않는다.

현재 구현값은 성물실 6곳·폐광 5곳 중 입장마다 2~4곳 점유다. 모든 후보는 나올 수도, 비어 있을 수도 있으며 최소 한 곳은 빈다. 직전 입장과 우연히 같은 조합이 나오는 것은 허용한다. 후보별 기본 확률과 최소·최대 수는 조정 가능한 제작값이며 사용자가 확정한 밸런스 수치가 아니다.

좌표·방향·접근 위치·기본 확률·내용물의 원본은 [`scripts/loot_spawn_catalog.gd`](../scripts/loot_spawn_catalog.gd)다. 폐광 좌표는 기존 `CaveLayout`의 Blender/Godot 공유 원본을 그대로 사용한다. 침수 갱도 통은 물길과 벽에 걸리지 않도록 북쪽에서 연다. 성물실의 기존 두 상자 보상을 여섯 후보에 나누었으므로 후보 추가로 보상이 중복 생성되지 않는다.

## 실제 게임 동작

- `game.gd`와 `cave_dungeon.gd`의 최초 상자 생성에서 독립 난수 생성기로 한 번 추첨한다. 해당 맵 인스턴스에서는 재생성 호출·가방·메뉴·상자 개폐로 점유를 다시 뽑지 않는다.
- 점유한 자리에만 실제 `DungeonLootChest`와 충돌·상호작용 범위를 만든다. 빈 자리에는 투명한 상자나 조사 판정이 남지 않는다.
- 제공 모델 4종의 실제 몸통·뚜껑·PBR 재질을 사용한다. 보물상자와 상자 1은 뒤 경첩으로 열리며, 통과 상자 2는 윗판을 들어 뒤쪽 테두리에 걸쳐 놓는다. 손 접점과 손바닥 방향은 실제 뚜껑 삼각형에서 계산하며 뚜껑 움직임을 따른다.
- 기존 1.2초 조사·맨손 전환·취소·순차 식별·가방 이동을 공유한다. 열린 상자 재조사로 내용물이 리필되지 않는다.
- 원정 영속 상태나 스냅샷 필드를 추가하지 않는다. 저장·종료 후 동일 원정의 재접속 규칙은 이번 작업에서 새로 결정하지 않는다.

## 재시험과 확장

테스트룸 `F2 → 기본 → 루팅 모델`의 네 항목에서 각 모델을 실제로 연다. `F2 → 장면 → 루팅 배치`의 성물실·폐광 항목으로 본편에 입장하고, F2로 돌아온 뒤 재입장해 점유 변화를 비교한다. 시험 가방은 원래 원정과 분리되며 종료·초기화 규칙은 기존 `TestRoomSandbox`를 따른다.

새 던전 맵은 카탈로그에 후보의 고유 ID·보관 이유·바닥 위치·방향·모델·내용물·앞쪽 접근 위치를 등록한다. 은신처는 등록하지 않는다. 문·주요 통행로·적·함정과 겹치지 않아야 하며, 모델 바닥·몸체뿐 아니라 열린 뚜껑과 플레이어가 설 자리, 실제 조사 시선까지 검증한다. 부유·물속·벽 안 후보를 무작위 이동으로 임시 회피하지 않는다.

은신처 제외 확인은 `F2 → 장면 → 3D 은신처 · 생활 기능`에서 실제 은신처에 들어가 수행한다. 재입장해도 무작위 루팅은 생기지 않고 개인 보관함은 유지되어야 한다. `./tests/run_headless_tests.sh hideout_loot_exclusion`으로 실제 두 차례 진입·F2 복귀·시험 격리·종료 복원까지 검사한다.

검증 명령:

```sh
./tests/run_headless_tests.sh loot_spawn loot_container_models test_room test_room_session
LOOT_SPAWN_QA_ITERATION=<새 이름> GODOT_PREVIEW_TIMEOUT_SECONDS=360 ./tests/run_embedded_preview.sh loot_spawn_preview.gd
```

자동 검증은 맵별 256개 고정 시드와 일반 난수 호출, 전 후보의 지면·몸체·열린 뚜껑·접근 공간·시선·마른 지면, 실제 루팅과 F2 반복·초기화·종료 복원을 검사한다. 숨김 실제 Vulkan 프리뷰는 모델 8장·손 동작 8장·후보 자리의 있음/없음 22장을 저장한다. 헤드리스 결과와 실제 이미지 검토는 구분한다.

원본 ZIP·4K 텍스처·파생 Blender 파일·에셋 자체 검증은 [제작 기록](../../asset-staging/loot_containers_20260912/README.md)에 보존한다. 게임 통합 검수는 `artifacts/visual_qa/loot_spawns/`의 최종 검토 기록을 따른다.
