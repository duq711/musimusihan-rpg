# 침수된 순례자 납골당 · 3D 은신처

## 플레이 공간

은신처는 `hideout.tscn` 안에서 런타임에 조립되는 1인칭 3D 인테리어입니다. 남쪽의 무너진 예배당 계단에서 들어와 중앙 저수 홀을 거친 뒤, 네 개의 생활·복구 구역과 두 개의 봉인 구역으로 갈라집니다.

| 구역 ID | 현재 역할 | 이후 확장 |
|---|---|---|
| `entrance` | 진흙 매트, 빗물 양동이, 젖은 망토, 지상 위장문 | 폐허 예배당 야외 청크 연결 |
| `central` | 얕은 물, 마른 보행로, 화로, 냄비, 부서진 성인상 | 동료 집결지와 휴식 허브 |
| `sleep` | 침상 휴식·회복, 개인 보관함, 세면 대야 | 개인실과 저장 기능 강화 |
| `storage` | 거의 빈 선반, 상자와 술통 | 식량·약초·전리품 저장고 |
| `workshop` | 사용할 수 없는 작업대, 무기 걸이 | 대장장이 영입 후 제작·수리 |
| `flooded_store` | 고장 난 배수와 침수 흔적 | 배수 후 지하 재배실 |
| `ossuary` | 철창 너머 벽감과 봉인 룬 | 은신처 2단계 연금술·의식실 |
| `drain` | 쇠사슬로 묶인 배수문 | 늪지대 또는 도시 하수도 지름길 |

## 오픈월드 연결 계약

`World/OpenWorldAnchors` 아래에 독립된 스폰·출구 마커가 있습니다.

- `Spawn_NewGame`
- `Spawn_FromMerchant`
- `Spawn_FromDungeon`
- `WorldExit_ChapelRuins`
- `WorldExit_Drainage`

각 마커는 `target_world_id`와 `target_spawn_id` 메타데이터를 가집니다. 현재는 기존 전체 화면 이동 지도로 장면을 바꾸지만, 이후 월드 스트리머가 동일한 ID를 읽어 외부 청크를 불러오도록 교체할 수 있습니다.

각 방은 `hideout_stream_region` 그룹에 속하는 별도 `Region_*` 노드입니다. 큰 벽에는 박스 오클루더가 있고, 작은 소품과 반복 장식에는 표시 거리가 설정되어 있습니다. 그림자를 만드는 고정 광원은 중앙 화로와 입구 채광 위주로 제한했습니다.

## 상호작용

- `LMB`: 계단 위 지상 입구를 클릭해 원정 이동 지도 열기
- `E`: 침상, 보관함, 화로, 냄비, 세면 대야, 작업대와 봉인문 사용·조사
- `I`: 어디서든 현재 원정 인벤토리를 열고 마법서 사용
- `F`: 휴대한 횃불 켜기·끄기
- `M`: 원정 이동 지도 열기·닫기
- `Esc`: 일시정지 또는 열린 화면 닫기. 원정 지도를 닫으면 조작 포커스가 게임으로 돌아가 이후 `Space`는 점프만 수행

은신처의 플레이어는 `DungeonPlayer.safe_zone_mode`를 사용합니다. 이동·횃불·상호작용은 유지하지만 검과 방패는 집어넣고 공격과 가드는 받지 않습니다.

## 마법 장비와 학습

인벤토리에서 마법서를 `학습`하면 해당 주문을 영구적으로 익힙니다. 습득 기록은 은신처·상점·던전 사이의 장면 이동과 사망 후 재원정에도 유지되며, 타이틀 화면의 `새 게임`에서만 초기화됩니다. `weathered_staff`를 무기 슬롯에 장착해야 시전할 수 있고, 던전에서 `1`~`5`로 주문을 선택한 뒤 `LMB`를 누릅니다.

- `1` `fire_bolt`: 기력 22
- `2` `water_bolt`: 기력 14
- `3` `ice_shard`: 기력 18
- `4` `stone_shard`: 기력 26
- `5` `healing_light`: 기력 28을 소모해 체력 32 회복

풍화된 지팡이와 다섯 마법서는 현재 상점에서 구매하거나 던전의 두 상자에서 획득할 수 있습니다. 입구 보급 상자는 지팡이·물·돌 마법서, 심층 성물 상자는 불·얼음·치유 마법서를 제공합니다.

## 원정 생존 규칙

포만감과 수분은 던전의 `RUNNING` 상태에서만 실시간으로 감소합니다. 포만감 100은 약 90분, 수분 100은 약 60분에 걸쳐 0이 됩니다. 일시정지·인벤토리·로딩 중에는 감소하지 않으며, 안전 구역인 은신처와 상점에서도 완전히 멈춥니다.

출혈은 감소 속도에 `+0.60`, 골절은 `+0.35`, 저주는 `+0.50`을 가산합니다. 상태가 중첩되어도 최종 소모 배율의 상한은 `2.25배`입니다. 검지기는 출혈, 성소지기는 골절을 일으키며, 함정은 저주 또는 출혈을 남깁니다. 붕대를 사용하면 출혈 상태도 함께 해소됩니다.

새 원정에는 포만감 `+32`인 `마른 순례자 식량`과 수분 `+38`인 `끓인 빗물병`이 각각 1개씩 기본 지급됩니다. 두 보급품은 상인에게 추가 구매할 수 있으며, 은신처와 상점에 머무는 동안에는 생존 시간이 소모되지 않습니다.
