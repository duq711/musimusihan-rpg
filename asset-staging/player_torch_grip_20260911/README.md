# 횃불 전용 파지 수정

사용자가 지적한 왼손의 둥근 덩어리·돌출된 피부·부족한 자루 접촉을 실제 게임 fixture에서 재현하고 MacBook Blender 5.2.1 LTS의 백그라운드 작업으로 맞췄다.

## 진단

`godot-game/artifacts/visual_qa/torch_grip/baseline_01/part_ids.png`의 파란색은 손, 빨간색은 소매 끝이다. 큰 둥근 부분은 소매가 손을 가리는 것이었으며, 실제 메시도 손 본체 하나와 손톱 다섯 개였다. 이전 공통 파지는 이미 굽은 원본에 동일한 추가 굴곡을 적용해서 일부 손가락이 자루 안으로 들어가고 손바닥이 떨어져 있었다.

## 최종 적용

- `godot-game/scripts/torch_grip_pose.gd`에 실제 자루 기준 위치·회전과 각 마디의 각도, 엄지 지지를 저장한다. 원본은 이미 굽어 있으므로 엄지의 한 마디는 일부 편다. 일반 손가락 시험 슬라이더의 범위는 유지한다.
- `player.gd`는 횃불을 드는 역할에 이 자세를 적용하고, 원래 횃불 배치와 어깨·팔꿈치를 따라 소매를 맞춘다. 손 외형 전환·초기화·재점화 후 파지를 다시 적용한다.
- 기존 손 GLB의 메시·UV·가중치·텍스처, 다른 손과 무기의 자세, 횃불의 원래 크기와 배치는 보존한다.
- 테스트룸의 기존 `1인칭 모션 · 횃불과 보행`에 안내와 실제 파지 검사를 연결했다. WASD·Shift·F 및 F2 재시험으로 확인한다.

## Blender 원본

`mac_output/torch_grip_final.blend`의 `Torch_Grip_Authoring` 장면에서 실제 손 리그와 자루를 함께 확인한다. 텍스처는 파일 안에 포함되어 있다. 이 파일의 소매는 제작용 기본 자세이고, 실제 게임에서는 어깨·팔꿈치에 맞춰 변형된다. `mac_output/torch_grip_pose.json`에 같은 각도와 접촉 기준이 있다. GPU 사진이 최종 게임의 소매 연결과 조명 검증 근거이다.

## 검증

`torch_grip_test.gd`는 실제 Godot 스키닝·보정 형상 결과 30,045정점과 실제 자루의 단면을 사용한다. 손가락 5개·손바닥·중간 마디 4개의 접촉 지점과 보행 중 손목 각도, 중복 왼손 방지, 보행 중 접촉 유지, 외형 전환·리셋·재점화와 테스트룸 원정 복원을 검사한다. `audit/native_contact_04.json`은 native 삼각형 중심·변 중점까지 포함한 202,502개의 접촉 검사를 기록한다. 재현용 독립 fitting 도구는 `tools/`에 보존한다.

최종 실행 결과와 파일 해시는 `validation_summary.json`을 따른다. 원래 사용자 OBJ·ZTL과 이전 양손 납품은 덮어쓰지 않았다. 수정 전과 각 중간 후보의 검증 기록은 최종 성공 근거와 구분한다.

## 2026-09-12 사용자 피드백 반영 · revision_04_final

이전 final_03은 손가락 가시성에 치우쳐 손목 방향과 파지가 부자연스러웠다. 현재 자세는 팔뚝 축과 손등 축의 연결을 기준으로 자루 주위 회전을 정했다(이전 +90도 대신 -55도). 네 손가락 뿌리의 모으는 회전과 중간 마디 접촉을 함께 맞췄다. 따라서 게임 카메라에서는 자루 뒤 손가락이 자연스럽게 가려진다. 정지·걷기·달리기에서 실제 손목 축 각도를 25도 이하로 검사하며, 실제 측정은 약 17~22도이다. 접촉 검사는 10개 영역으로 확장했다.

최종 다방향 화면은 `godot-game/artifacts/visual_qa/torch_grip/revision_04_final/`이다. `side.png`, `opposite.png`, `closeup.png`에서 손목 연결과 자루 접촉을 직접 확인했다. 검사는 저장된 자세와 샘플 표면에 대한 것이며 모든 가능한 애니메이션의 연속 충돌 증명은 아니다.
