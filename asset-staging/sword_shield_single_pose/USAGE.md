# 한 장씩 보는 검·방패 검토 화면

이 빌더는 기존 게임·테스트룸·촬영 하네스·APNG 검토 화면을 수정하지 않습니다. 새 결과는 이 폴더의 `reviews/<반복 이름>/`에만 씁니다.

최종 촬영과 영상 빌드를 마친 이름은 `single_pose_motion_03`입니다. 아래는 같은 원본으로 검토 자료를 다시 만드는 명령입니다. 검증 범위와 남은 차이는 [최종 기록](verification/final/REVIEW.md)에 있습니다.

```sh
/Users/duq711gmail.com/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 asset-staging/sword_shield_single_pose/build_review.py single_pose_motion_03 --review-stage final
```

`review.html`은 한 번에 큰 이미지 하나 또는 영상 하나만 표시합니다. 동작을 선택한 뒤 `실제 촬영`, `생성 참고`, `실제 영상` 탭과 방향을 바꿉니다. 방패는 올리기·방어 충격을 선택할 수 있습니다. 이미지에는 이전·다음 자세와 슬라이더, 영상에는 기본 재생 조작과 1×·0.5× 속도가 있습니다. 나란히 비교, 축소판 목록, 콜라주, 컨택트시트를 만들지 않습니다.

기본 출력은 화면과 `review_build.json`에 **중간 검토본**으로 표시합니다. 기존 `single_pose_motion_01`과 `single_pose_motion_02`는 중간 촬영 자료입니다. 새 최종 촬영을 마치고 직접 시각 검토한 뒤 그 반복을 포장할 때만 `--review-stage final`을 붙입니다. 이 표시는 촬영본의 구분이며 시각적 완성도를 자동 승인한다는 의미가 아닙니다.

`videos/`의 MP4 6개는 실제 촬영 PNG를 같은 순서와 원본 프레임 속도(현재 30fps)로 인코딩합니다. macOS에 설치된 Swift·AVFoundation을 사용하며 인코더를 내려받지 않습니다. 영상은 H.264 압축 결과이고 AI 생성 영상이 아닙니다. 원본 PNG는 보존합니다. 시간은 `0.000 / 1.133초`처럼 원본 타임라인을 소수점 세 자리로 표시하며, 0.5×에서도 원본 시간값을 사용합니다. 34프레임의 마지막 PNG 시각은 1.100초이고 마지막 프레임의 표시 시간을 포함한 MP4 길이는 1.133초입니다.

`verification/`은 처음·마지막 프레임과 manifest의 모든 주요 키프레임을 실제 MP4에서 디코딩해 원본과 비교합니다. 검격의 주요 순간은 **11번 프레임(0부터 번호, 30fps에서 0.367초)**이며 세 공격 모두 그 프레임에 실제 `active` 상태와 요청한 공격 종류가 있어야 합니다. 위·아래·좌·우 이미지도 manifest의 동일한 번호를 사용합니다. 방패는 실제 올림 진행값과 충격 잔여 시간을 사용해 올림·내림·유지·충격으로 표시합니다.

새 생성 참고는 이 폴더의 `references.json`에 명시적으로 등록합니다. 각 PNG는 한 자세·한 방향만 담아야 합니다. 기존 시트 이미지를 대신 연결하지 않습니다. 참고가 아직 없으면 화면에 준비되지 않았다고 표시합니다.

현재 AI 생성 참고는 26장입니다. 준비 5장과 세 검격 각각 7장이 등록되어 있으며, 방패 올리기·방어 충격에는 아직 생성 참고가 없습니다. 각 이미지는 자세·방향마다 AI로 독립 생성한 원본입니다. 동일한 3D 자세를 여러 카메라로 촬영한 결과가 아니므로 이미지끼리 세부 형상과 관절 각도가 완전히 같지는 않습니다. 실제 MP4 6개와 생성 참고 이미지는 서로 다른 자료입니다.

```json
{
  "references": [
    {
      "action": "right_diagonal",
      "direction": "pov",
      "pose": "windup",
      "label": "우측 대각 베기 준비",
      "image": "references/right_diagonal_pov_windup.png",
      "single_pose": true
    }
  ]
}
```

`action`: `ready`, `right_diagonal`, `left_reverse`, `overhead`, `shield_raise`, `block_impact`.

`direction`: `pov`, `front`, `back`, `top`, `bottom`, `left`, `right`. 참고 목록의 순서대로 자세를 보여 줍니다. 실제 촬영 방향은 원본 manifest에 존재하는 방향만 사용합니다. 현재 촬영 하네스는 동작마다 동일한 실제 1인칭 팔·검·방패를 주요 순간 4개에서 위·아래·왼쪽·오른쪽 외부 카메라로 촬영합니다. 방향은 플레이어 카메라의 축을 기준으로 하며, 각 카메라는 같은 순간의 같은 장착 모델을 어깨까지 봅니다. 외부 촬영에서는 별도 정적 전신·바닥·보관된 횃불을 숨깁니다. 대체 신체나 팔을 추가하지 않습니다. 외부 방향은 정지 이미지이고, 연속 영상은 1인칭에만 있습니다.

다른 매핑을 읽으려면 `--references <JSON 경로>`를 추가합니다. 참고를 연결한 후 같은 명령을 다시 실행하면 원본 프레임과 인코더가 그대로인 MP4는 검증 기록으로 확인해 재사용합니다. `review_build.json`에 사용한 원본 파일의 SHA와 보존 결과를 남깁니다.

브라우저에서 실제 재생하는 검증은 수행하지 않았습니다. 기존 확인 범위는 뷰어의 정적 로직과 별도 MP4 인코딩·디코딩 검사이며, 상세 기록은 [STATIC_REVIEW.md](STATIC_REVIEW.md)에 있습니다. 로컬 파일 열기의 보안 차단을 서버나 다른 브라우저로 우회하지 않습니다.
