# 소매 밖으로 들리던 손목 끝 정리

`source_proportioned_hands/`는 앞 단계의 손가락 길이 교정 모델을 그대로 보존합니다. `fit_wrist_tail.py`는 피부와 원래 장갑의 손목 뒤쪽 양수 Z 연장부만 줄이고 양손 GLB를 이 폴더에 생성합니다. 게임 파일 복사나 Godot 실행은 하지 않습니다.

머리 위 베기 준비 촬영에서 약 32° 벌어진 손축과 전완축을 실제 삼각형으로 비교했습니다. 크게 솟던 부분은 커프가 아닌 피부·장갑의 약 56mm 손목 끝이었습니다. 양수 Z에만 `z / (1 + 30.5z)`를 적용해 끝을 약 20.70mm로 줄였고, 원점에서 위치와 미분은 이어집니다. 단면 X/Y는 유지하며 법선과 접선은 변형에 맞춰 갱신합니다.

음수 Z의 손가락·손바닥과 독립 선정한 실제 피부 접촉 표본 17종 × 20개씩, 16개 뼈·inverse bind·가중치·UV·삼각형·재료·단단한 소매·커프는 보존합니다. `preservation_report.json`에 입력·출력 해시와 정점·표본별 보존 검증을 기록했습니다. 최종 게임 렌더와 기능 검증은 상위 폴더의 검증 기록을 따릅니다.
