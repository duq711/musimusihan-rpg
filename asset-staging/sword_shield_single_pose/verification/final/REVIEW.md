# 최종 적용·검증 기록

최종 적용 상태는 13차 수정이며 실제 촬영 이름은 `single_pose_motion_03`이다. [한 장씩 보는 검토 화면](../../reviews/single_pose_motion_03/review.html), [기계 판독 결과와 해시](status.json). 이전 01·02와 중간 검사 결과는 별도 보존했다.

- **기능 검사:** 동일한 최종 소스로 백그라운드 헤드리스 검사 17종 통과, 실패 0. 실제 양손 파지·표면 접촉·관통, 세 베기·방패 올리기·피격 반동, 검 단독 회귀, 테스트룸 F2 종료와 원정·인벤토리 복원을 포함한다. 기존 종료 시 ObjectDB 경고가 일부 있으나 검사 실패는 없다. [전체 원본 로그](single_pose_motion_13_final_tests.log).
- **실제 렌더:** 숨김 embedded Vulkan으로 여섯 동작을 120Hz 시뮬레이션하고 30fps로 촬영했다. 1인칭 34장과 외부 네 방향의 네 자세 16장을 동작마다 별도로 저장해 PNG 300장이 생성됐다. 원정·커서·인벤토리 보존, 촬영 중 소스 불변을 확인했다. 촬영이 소비한 78개 파일 해시가 현재 적용 파일과 모두 일치한다. [촬영 로그](single_pose_motion_03_capture.log), [원본 manifest](../../../../godot-game/artifacts/visual_qa/sword_shield_choreography/single_pose_motion_03/capture_manifest.json).
- **영상:** 준비, 우측 대각 베기, 좌측 역베기, 상단 내려베기, 방패 올리기, 방어 피격의 MP4 6개. 각각 1280×720, H.264, 34개 실제 프레임, 30fps, 1.133333초이며 음성은 없다. 전 프레임 타임스탬프와 원본 SHA를 확인하고 주요 시점 총 29장을 디코딩해 비교했다. 최대 체크포인트 평균 RGB 압축 오차는 1.596/255 미만이다. 원본 PNG와 MP4 픽셀이 동일하다고 주장하지 않는다. [인코딩 로그](single_pose_motion_03_video.log), [상세 인코딩·디코딩 기록](../../reviews/single_pose_motion_03/review_build.json).
- **생성 참고:** 26개의 독립 AI 이미지 원본. 준비 파지 5장과 세 베기 각각의 1인칭 3단계·외부 상하좌우 4장이다. 원본 하나에 한 자세와 한 방향만 있고, 콜라주 자르기나 좌우 반전으로 수를 늘리지 않았다. 방패 올리기와 방어 피격에는 실제 게임 촬영·영상이 있으며 별도 AI 참고는 등록하지 않았다.
- **시각 검토:** 최종 실제 상단 베기 준비·좌측 역베기·준비·피격과 디코딩 우측 베기 핵심 프레임을 직접 확인했다. 독립 검토에서도 큰 손목 돌출 감소, 손가락 배열과 장비 접촉 유지, 새로 생긴 큰 분리나 좌우 뒤집힘 없음이 확인됐다. 손가락 형태·재질은 참고보다 단순하고 일부 작은 소매 들림이 남아 있다. 완전한 외형 일치나 유사도 수치를 인증하지 않는다.
- **뷰어 검토 범위:** 한 번에 전체 이미지 하나 또는 실제 영상 하나만 표시하는 구조, 경로 누락 0, 자료 출처·시간·배속 연결을 정적으로 확인했다. 자동 로컬 페이지 열기가 브라우저 정책에 차단되어 브라우저 재생과 버튼 조작은 검증하지 않았다. 다른 주소·서버로 우회하지 않았다.

현재 제공된 도구로 AI 목표 영상을 생성할 수 없어 요청의 해당 부분은 완료하지 못했다. 제공 MP4는 실제 게임 촬영본이다. 외부 방향 촬영 역시 같은 실제 1인칭 팔·장비의 카메라 검사이며 별도 전신 애니메이션 영상이 아니다. 실행 중인 사용자 게임·편집기는 재시작하지 않았고 변경은 다음 게임 실행에 적용된다.

[모델 import 로그](single_pose_wrist_tail_13_import.log)와 각 원본 로그의 SHA는 `status.json`에 보존했다. 모델·소스·원본 이미지나 기존 중간 결과를 이 기록 작성 과정에서 변경하지 않았다.
