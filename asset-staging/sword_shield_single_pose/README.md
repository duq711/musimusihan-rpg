# 검·방패 개별 자세 참고와 실제 동작 검토

2026-09-07 사용자 요청: 한 장에 여러 자세를 배치하지 않고, 한 이미지에 한 자세·한 방향만 표시한다. 검은 오른손, 방패는 왼손에 쥔다.

`references.json`에 선택된 26장의 개별 원본을 등록했다. 준비 파지는 1인칭·위·아래·왼쪽·오른쪽 5장, 세 가지 베기는 각각 1인칭 준비·베는 순간·마무리 3장과 외부 위·아래·왼쪽·오른쪽 4장이다. 선택 이미지들은 ImageGen 원본을 그대로 복사했다. 이전 시트를 자르거나 반전해서 방향을 늘리지 않았다.

적용 상태는 [최종 단일 검토 화면](reviews/single_pose_motion_03/review.html)에서 확인한다. 검사 17종 통과, 실제 원본 PNG 300장, 실제 게임 MP4 6개, 현재 소스 78개와 촬영 해시 일치 기록은 [최종 검증 자료](verification/final/REVIEW.md)에 보존했다. `single_pose_motion_01`과 `02`는 이전 중간 촬영본이다.

- `generation_records.json`: 준비 파지 및 1인칭 단계별 정확한 생성 프롬프트와 원본 경로. `ready_left.png`, `ready_left_v2.png`는 방향·좌우 오류가 있어 선택 목록에서 제외했다.
- `external_generation_records.json`: 외부 방향 23회 생성 중 선택 12장과 제외 11장의 프롬프트·입력·원본·육안 검수·해시.
- `corrected_arms/`: 실제 좌우 손 모델을 바로잡은 재현 스크립트와 원본 보존·관절 회전 조사.
- `corrected_sword/`: 검날·가드·파지점·날끝을 유지한 한손 자루와 끝장식의 비례 교정.
- `glove_extension/`: 08까지 시험한 장갑 외피의 보존본. 손가락을 가려 최종 후보에서는 사용하지 않는다.
- `proportioned_hands/`: 원래 장갑 개구부를 복구하고 손가락 길이만 80%로 줄인 적용 모델 단계. 두께·폭·손바닥·소매 보존 보고서와 재현 스크립트.
- `wrist_tail_fit/`: 손가락·손바닥·관절은 보존하고 소매 밖으로 들리던 손목 뒤쪽 끝만 56.13→20.70mm로 줄인 최종 모델 단계.
- `padded_shield_grip/`: 손이 감싸는 중앙 105mm를 30×22mm 타원형으로 바꾼 실제 방패 손잡이. 장착 끝과 팔끈은 보존하고 해당 실밥만 새 표면에 맞췄다.
- `verification/baseline_05/`: 기능 검사 17종은 통과했지만 방패 손이 벌어져 보여 시각 검토에서 채택하지 않은 중간본 기록.
- `USAGE.md`: 실제 게임 원본을 한 장씩 보는 화면과 MP4로 묶는 방법.

각 이미지는 독립 생성한 자세 참고이므로 모든 방향의 얼굴·옷·손가락 각도가 동일한 3D 인물의 렌더처럼 정확하게 일치하지는 않는다. 게임에서는 같은 실제 팔·검·방패와 연속된 관절 동작을 사용한다. 외부 게임 촬영은 실제 1인칭 팔의 어깨까지 보여 주는 검사이며 별도 전신 애니메이션의 증거가 아니다.

현재 연결된 도구로는 AI 영상을 생성할 수 없다. `reviews/<촬영 이름>/videos/`의 영상은 실제 게임 화면을 30fps로 촬영해 인코딩한 MP4다. 이를 AI가 생성한 목표 영상이라고 표시하지 않는다. 이미지와의 완전한 외형 일치나 객관적 유사도 백분율도 주장하지 않는다.

브라우저 정책으로 새 로컬 검토 페이지를 자동으로 여는 작업은 차단되었다. 다른 주소나 서버로 우회하지 않았다. 페이지의 단일 표시 구조·자료 연결은 정적으로 검사하고, 실제 PNG와 MP4 프레임은 파일에서 직접 검증한다. 브라우저 재생·버튼 조작을 검증했다고 주장하지 않는다.
