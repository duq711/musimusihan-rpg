# 성소 테스트룸

메인 메뉴의 **테스트룸**을 선택하면 실제 게임 기능을 반복해서 시험할 수 있는 별도 3D 시험장으로 들어갑니다. 처음에는 시험 메뉴가 열리고 적 AI는 정지되어 있습니다. 시험용 기본 장비·사슬철퇴·사냥활·화살·지팡이, 모든 주문의 습득 상태, 9,999 크라운이 준비됩니다.

## 기본 사용법

- `시험장 들어가기` 또는 `F2`로 메뉴를 닫고 직접 조작합니다. 시험장 안에서 `F2`를 다시 누르면 시험 메뉴를 엽니다. `Esc`로도 시험 메뉴를 열고 닫을 수 있습니다.
- 인벤토리에 수량 선택 창이 열려 있으면 `F2`는 먼저 그 창을 닫습니다. 다시 누르면 인벤토리를 닫고 시험 메뉴로 돌아옵니다.
- `F2 → 생존` 탭 맨 위의 `수치 직접 조절`에서 체력·기력·포만감·수분·스트레스를 직접 바꿀 수 있습니다.
- 이동은 `WASD`, 달리기는 `Shift`, 점프는 `Space`, 공격·시전은 `LMB`, 방패는 `RMB`, 조사·상호작용은 `E`, 횃불은 `F`, 인벤토리는 `I`입니다.
- 사슬철퇴를 장착하면 `LMB`는 근접 타격, `RMB`는 오른쪽에서 사슬을 회전한 뒤 놓아 투척하는 공격입니다. 짧게 클릭해도 0.35초 회전 후 투척하며, 1.2초에 최대 힘이 됩니다. 철구는 자동 회수되고 아이템이나 화살은 소모되지 않습니다.
- 가방의 야영 도구에서 `설치`를 선택하고 바닥을 조준합니다. 초록은 설치 가능, 빨강은 불가이며 `LMB`로 확정할 때 도구 1개를 소비합니다. `F`/`Esc`로 미리보기를 취소하면 소비하지 않습니다. 설치한 텐트에 `E`로 앉아 요리·휴식을 고릅니다. `Esc`로 일어서면 야영지는 유지되고 `야영지 정리`로 제거합니다. 계획은 일시정지, 활동은 실제 세계 시간으로 진행되며 중단 시 사용한 보급은 반환하지 않습니다.
- 야영 화면의 `요리` 탭에서 실제 재료로 조리하면 완성 즉시 먹고 회복합니다. 별도의 완성 음식 아이템은 저장하지 않습니다.
- 은신처 중앙 화롯불 위의 매달린 냄비도 `E`로 조리할 수 있습니다. `장면 → 은신처 · 화롯불 조리와 식사`에서 실제 조리 화면과 재료를 준비합니다.
- 사냥활을 장착하면 `LMB`를 누르는 동안 최대 1초 시위를 당기고 놓으면 발사합니다. 0.1초 이하는 발밑에 바로 떨어지고, 더 당길수록 빠르고 멀리 날아갑니다. 기본 피해는 즉시 18 → 0.5초 32 → 완전 당김 46으로 증가합니다. 완전히 당기면 발사 방향이 조준 방향과 일치합니다. 당김·유지 중 기력이 초당 22씩 소모되며, 고갈 시 현재 당긴 힘으로 1발 자동 발사합니다. 수동·자동 발사 모두 화살 1개를 쓰며 발사 순간 추가 기력 비용은 없습니다. `RMB`는 방패 가드 대신 화살 소비 없이 당기기를 취소합니다.
- 적은 기본적으로 정지 표적입니다. `적 AI 켜기 / 끄기`로 전환하거나 근접·방패·골격 시험 항목을 선택하면 실제 적 AI와 대련할 수 있습니다.
- `체력 · 기력 회복`은 시험 캐릭터를 회복하고 스트레스를 0으로 낮춰 환영·환청도 정리합니다. `적 · 함정 · 상자 재생성`은 소모된 대상을 다시 준비합니다.
- `테스트룸 초기화`는 시험용 장비·지갑·마법과 시험장을 초기 상태로 되돌립니다. 원래 원정의 보존본은 유지합니다.
- `기본 → 성능 측정 켜기 / 끄기`는 실제 플레이를 재개하고 FPS·프레임 시간·GPU 시간을 표시합니다. 켠 상태에서 `F2 → 장면`으로 은신처·성소·폐광에 들어가면 해당 장면을 계속 측정합니다. 메뉴로 일시정지한 시간은 제외하며, 재선택·초기화·시험 종료로 끌 수 있습니다.
  창을 크게 키우면 3D 화면만 기본 1280×720 수준의 픽셀 수로 조절하고 글자와 HUD는 창 해상도를 유지합니다. 기본 크기에서는 원래 정밀도를 사용합니다. 60 FPS 달성 여부는 실제 수치로 확인합니다.
- `메인 메뉴로 나가기`로 시험을 끝냅니다. 시험용 장면에서도 `F2`로 테스트룸에 돌아온 뒤 종료할 수 있습니다.

성능 표시는 최근 최대 300프레임의 평균과 느린 프레임 기준을 사용합니다. `느린 5%`는 프레임 시간의 95백분위이며, 60 FPS에 필요한 프레임 시간은 약 16.67ms입니다. 실제 장면과 1인칭 장비 화면을 함께 계측하고, 장면을 바꾸면 준비 시간 이후 새 표본을 수집합니다. 화면 렌더러가 없는 헤드리스 검증에서는 FPS를 표시하지 않습니다. 자동 동작·원정 복원 검증은 `./tests/run_headless_tests.sh performance_ui test_room_session`, 실제 렌더링 측정 방법과 한계는 [EMBEDDED_RENDERING.md](tests/EMBEDDED_RENDERING.md)를 참고하세요.

은신처와 성물실에서는 벽·바닥의 세부 돌 모양을 그대로 표시하면서 속이 막힌 판재의 그림자만 단순화합니다. 아치와 기둥은 원래 삼각형을 한 번에 묶어 그림자를 그리므로 문과 통로의 개구부를 유지합니다. 성능 표시를 켜고 문턱·화덕·기둥 가까이에서 조명과 시점을 비교할 수 있습니다. 활과 철퇴 시험도 같은 실제 장비를 사용하며, 대기 중 모양이 같을 때의 반복 갱신만 생략합니다.

시험 메뉴를 열면 게임이 일시정지되어 적과 생존 시간이 진행되지 않습니다. `생존 시간 10분 진행`은 메뉴에서 의도적으로 시간을 진행시키는 시험 항목입니다.

## 수치 직접 조절

`F2`로 시험 메뉴를 열고 오른쪽 위 `수치 조절` 버튼을 누르거나, `생존` 탭 맨 위의 `현재 상태 직접 조절`을 사용합니다. 다섯 수치에 각각 슬라이더와 숫자 입력 칸이 있습니다. 작은 화면에서는 목록을 스크롤하여 조절하고, 메뉴 아래의 재개·회복·초기화·나가기 버튼은 그대로 사용할 수 있습니다.

| 수치 | 조절 범위 | 의미 |
|---|---|---|
| 총체력 | 1~440 | 시험 전용 비율 재설정. 부위 손상도 되돌리며 실제 일반 치료의 제한과 구분 |
| 기력 | 0~100 | 공격·달리기·활 당기기에 사용하는 기력 |
| 포만감 | 0~100 | 낮을수록 허기가 심함 |
| 수분 | 0~100 | 낮을수록 갈증이 심함 |
| 스트레스 | 0~100 | 높을수록 위험하며 60부터 환청, 80부터 환영도 발생 |

슬라이더를 움직이면 실제 시험 캐릭터와 원정 수치에 즉시 반영됩니다. 숫자를 직접 입력했다면 `Enter`를 누르거나 다른 입력 칸·버튼으로 포커스를 옮겨 확정하세요. 숫자를 입력하던 중 `F2`로 닫아도 값을 확정한 뒤 시험장으로 돌아옵니다. 메뉴가 열린 동안에는 시간이 멈추며, 닫으면 조절한 상태에서 생존 진행·기력 회복 등 정상 동작이 다시 시작됩니다. 환청·환영도 메뉴 안에서는 재생되지 않고 재개 후 현재 스트레스에 따라 발생합니다.

직접 조절은 현재 표적·위치·장비·보급을 다시 준비하지 않으며 상태이상도 해제하지 않습니다. 기존 시험 항목을 새로 선택하면 그 항목의 초기 설정이 적용되므로 `원하는 시험 항목 선택 → F2 → 생존에서 수치 조절 → F2 재개` 순서가 좋습니다. 예를 들어 `활 피해 · 기력 유지`를 먼저 선택한 뒤 기력을 11로 낮추면 기존 8m 표적·화살을 유지한 채 부분 당김 고갈 사격을 시험할 수 있습니다. 스트레스 시험을 먼저 선택하고 스트레스만 59·60·79·80으로 바꿔 경계를 비교할 수도 있습니다.

조절 결과는 별도 시험 세션 안에만 적용됩니다. 종료 시 원래 원정의 포만감·수분·스트레스 등 보존 상태를 복원하며, 직접 조절을 위해 새로운 영속 필드를 추가하지 않습니다.

## 시험 항목

### 부위별 체력 · 수술 · 고위 재생

`I`는 **장비·건강상태 통합 화면**을 바로 엽니다. 사용자 최신 참고의 왼쪽 갑옷 전신·성소 배경·황동 장식·명조체·붉은 체력 막대와 오른쪽 장비·소지품 구성을 따릅니다. 머리·흉부·복부·양팔·양다리 카드나 인물의 해당 부위를 누르면 왼쪽 안에 치료창이 열리고, 오른쪽 장비·가방은 계속 사용할 수 있습니다. `×` 또는 `Esc`는 치료창만 닫고 선택 부위를 유지하며, 다시 `Esc`를 누르면 가방을 닫습니다.

오른쪽은 실제 장비 7칸과 기존 가방 30칸을 표시합니다. 주머니 8칸(0~7), 허리 파우치 6칸(8~13), 배낭 16칸(14~29)은 같은 가방 목록의 표시 구역이며 추가 저장 용량이나 서로 다른 수납 제한을 만들지 않습니다. 아이템 우클릭·가방 아이템 두 번 클릭은 기존 이름표·장착·버리기 상세 창을 열고, 장비 두 번 클릭은 실제 해제입니다. `빠른 사용` 10칸은 보유 소비품을 가방 순서로 자동 배치하고 버튼 또는 `1~0`으로 사용합니다. 소비로 목록이 바뀌면 번호도 갱신됩니다. 이름표·폐기 창을 조작하는 동안 빠른 사용 키는 동작하지 않습니다. 상자는 기존 조사·이동 화면으로 열며, 통합 화면으로 이동한 경우 왼쪽 위 `상자 보관함으로`로 돌아갈 수 있습니다.

장착 장비 하단에 **허리 파우치·배낭** 슬롯이 있습니다. 가방의 교체품을 우클릭하거나 두 번 클릭해 상세 창을 열고 `장착하기`를 누르면 이전 장비는 가방으로 돌아갑니다. 이름표·개별 정보와 소지품은 유지되고, 가방이 꽉 찼어도 교체품이 비운 칸을 사용해 교체할 수 있습니다. 빈 칸 없는 상태의 장착 해제는 안내와 함께 거절됩니다. 기존 5슬롯 원정 데이터에서도 새 슬롯에 장착할 수 있으며 기존 장비를 덮어쓰지 않습니다. 이 변경은 교체 기능이며 가방별 수납량 차이는 추가하지 않습니다.

`F2 → 기본 → 허리 파우치·배낭 교체`는 기본 가죽 파우치·원정 배낭과 교체용 순례자의 파우치·방랑자의 배낭을 준비합니다. 같은 항목을 다시 선택하면 시험 장비와 교체품을 재준비하며 원래 원정은 보존합니다. 네 물품은 원본 카탈로그에서 `물품` 목록에도 자동 등록됩니다. 신규 교체 회귀 검사는 `./tests/run_headless_tests.sh storage_equipment health_panel_input health_panel_preview inventory_chest body_health_test_room`입니다. 프리뷰의 `12_storage_equipment_swapped`와 `13_backpack_details_small`은 실제 장착으로 교체한 상태입니다. 관련 자동 검사 7종과 실제 embedded Vulkan 1280×720·960×540 표시를 확인했습니다. [교체 검증 기록](artifacts/validation/storage_equipment_20260914/README.md) · [교체 후 화면](artifacts/visual_qa/body_health/storage_equipment_20260914_01/12_storage_equipment_swapped.png).

하단의 배고픔·갈증은 실제 포만감·수분 잔량, 기력·스트레스는 기존 원정 수치를 표시합니다. 막대 툴팁으로 의미를 확인할 수 있습니다. 이번 변경은 화면 재설계이며 새로운 피로·체온 시뮬레이션이나 참고 그림의 머리 55를 적용하는 체력 규칙 변경은 포함하지 않습니다.

`F2 → 생존`에서 다음 실제 시험을 선택합니다.

- **장비·건강 통합 · 7부위 치료**: 일곱 부위가 각각 다친 상태에서 실제 장비·치료품과 통합 화면을 엽니다. 부위를 클릭하고 보유 치료품을 사용하며 선택한 부위의 변화와 합계를 확인합니다.
- **회복 불가 부위 · 수술 후 치료**: 왼팔이 0인 상태입니다. 회복약 사용이 효과와 물품 소비 없이 거절되는지 확인한 뒤 야전 수술 도구로 정확히 1을 만들고 회복약을 사용합니다.
- **고위 회복마법 · 부위 복구**: 오른다리가 0인 상태와 지팡이·고위 재생을 준비합니다. 건강 탭에서 오른다리를 선택하고 가방을 닫은 뒤 `6 → LMB`로 1까지 복구합니다. 이후 일반 치료를 이어갑니다.

체력은 머리35·흉부85·복부70·양팔 각60·양다리 각65, 합440입니다. 머리·흉부0은 사망이고 나머지 부위0은 일반 치료로 복구할 수 없는 손상입니다. 건강 탭의 검은 부위와 회복 제한 안내를 확인합니다. 휴식·음식·침상도 손상 부위를 복구하지 않으며, 장소를 바꿔도 부위 상태가 이어집니다. 현재 근접 피해는 접근 방향에 따라 몸통·팔·머리에, 바닥 함정은 다리에 적용됩니다.

원본 상태이상 카탈로그의 **골절·출혈·저주·마비·중독** 항목은 실제 효과와 대응 치료품을 함께 준비합니다. 골절은 부목, 출혈은 붕대, 저주는 정화의 성염, 마비는 각성 약액, 중독은 해독약으로 치료합니다. 부위 체력 회복과 상태이상 치료는 별개의 동작입니다. 출혈·독의 지속 피해, 팔다리 손상·골절의 행동 불이익, 저주의 회복량 감소, 마비의 이동·공격 제한을 재개 후 비교합니다.

`F2 → 수치 조절`에는 부위 선택·피해10·선택 부위0·전체 부위 시험 회복이 있습니다. 머리나 흉부를0으로 만드는 버튼은 실제 사망을 발생시킵니다. 전체 회복과 총체력 슬라이더는 일반 치료 제한을 우회하는 **시험 전용 초기화**입니다. 재선택하면 치료품과 부상 상태를 다시 준비하고, F2·메뉴 동안 시간은 멈춥니다. 테스트룸 종료 시 원래 가방과 원정의 부위 체력·선택 부위·상태이상 위치를 복원합니다.

이번 UI 통합의 자동 검증은 `./tests/run_headless_tests.sh health_panel health_panel_input health_panel_preview item_detail_input inventory_chest body_health_test_room`입니다. 1280·960에서 좌우 실제 UI 좌표, 선택 부위 치료 0→1→17, 실제 장착·해제·빠른 사용·이름표·버리기, 상자 조사·이동 회귀와 테스트룸 격리·복원을 확인합니다. 체력·전투 규칙을 수정할 때는 기존 `body_health_core body_health_weapon_core body_health_routes test_room_status_controls test_room_session test_room` 범위도 실행합니다.

### 방패 완전 방어와 저스트 가드 스턴

`F2 → 기본 → 방패 · 저스트 가드`는 검·원형 방패를 실제로 다시 장착하고 체력·기력을 회복한 뒤 정면에 공격하는 검지기 한 명을 준비합니다. 이전 시험의 적·함정·상자는 정리합니다. 활·횃불 시험이나 방패 해제 후에도 같은 항목을 다시 선택하면 방패 대련을 시작할 수 있습니다.

- 기력이 남아 있을 때 공격 전에 `RMB`를 미리 누르고 유지하면 정면 좌우 55도 안의 적 공격 피해를 전부 막습니다. 일반 방어는 피격량의 1.18배만큼 기력을 0까지 소모합니다. 막다가 기력이 0이 되면 그 공격은 완전히 차단하고 즉시 방패를 내리며, 이후 공격은 정상적으로 피해를 줍니다.
- 공격이 닿기 직전 0.20초 안에 `RMB`를 누르면 피해를 전부 막으면서 공격한 적을 1.15초 스턴시킵니다. 기존 저스트 가드의 기력 8 회복도 유지합니다. 기력 0일 때는 가드를 시작·유지할 수 없으므로 저스트 가드와 기력 회복 보상도 발생하지 않습니다. 일반 방어에는 적 스턴 보상이 없습니다.
- `F2 → 생존 → 수치 직접 조절`에서 기력을 0으로 설정하고 메뉴를 닫아 `RMB`로 방패를 들 수 없는지 확인합니다. 기력을 낮은 양수로 설정하면 해당 타격을 막은 뒤 고갈과 동시에 방패가 내려가는지 비교할 수 있습니다. 기력이 회복된 뒤 `RMB`를 다시 눌러 가드를 시작합니다. 측면·후방 공격과 함정 등 환경 피해에는 정면 방패 방어가 적용되지 않습니다.

`검과 방패 · 막힘 충격`에서도 같은 방어 판정과 실제 방패 반동을 사용합니다. `F2` 회복 또는 방패 항목 재선택으로 반복하고, 초기화·시험 종료 시 기존 시험 세션 격리와 원래 원정·가방 복원을 유지합니다. 0.20초·1.15초·방어 각도·기력 비용은 현재 조정 가능한 전투 수치입니다.

자동 검증은 `./tests/run_headless_tests.sh shield_guard sword_clash first_person_motion_test_room test_room test_room_session`입니다. `shield_guard`는 실제 방어의 피해·기력·적 스턴, 기력 0의 가드 거절·막은 직후 고갈에 따른 해제·회복 후 재시도, 방향·환경 피해 예외, 방패 시험의 재장착·반복 선택·메뉴 정지·초기화와 원정 복원을 확인합니다.

`SWORD_SHIELD_QA_GUARD_HUD=1 SWORD_SHIELD_QA_ITERATION=<새 이름> ./tests/run_embedded_preview.sh sword_shield_preview.gd`는 기존 검·방패 촬영에 실제 HUD를 더해 일반 방어·기력 고갈·저스트 가드 안내를 창 없이 확인합니다. `guard.png`는 기력이 남은 정상 가드, `exhausted.png`는 기력 0의 방패 올리기 거절, `impact.png`는 저스트 가드이며 피해·기력·문구와 원정·커서 보존 결과를 매니페스트에 기록합니다. 이 자세 촬영은 적의 실제 스턴 시간을 검증하는 `shield_guard`를 대체하지 않습니다. 이전 기력 0 일반 가드의 촬영·검증 파일은 당시 규칙의 이력으로 보존하고 새 반복 폴더에 현재 규칙을 기록합니다.

### 아이템 상세·이름표·버리기

`F2 → 기본 → 아이템 상세 · 이름표 · 버리기`는 실제 가방에 장검·갑옷·붕대를 준비하고 장검 상세창을 엽니다. 아이템 우클릭, 가방 더블클릭 또는 `상세 보기`로 큰 이미지와 원본 설명을 확인합니다. 상세창의 기능은 이름표·버리기와 장착 가능한 물건의 장착하기입니다.

이름표를 저장하거나 비워서 제거하고 장착 후에도 같은 별칭과 강화 정보가 남는지 확인합니다. 버리기에서 수량을 지정한 뒤 가방을 닫고 바닥 보따리를 바라보며 `E`로 다시 줍습니다. 가방이 가득 차면 들어갈 수 있는 수량만 회수하고 나머지는 바닥에 남습니다. 미확인 상자 물품은 정체가 밝혀진 뒤 설명을 볼 수 있고, 상자 물품은 가방으로 가져오기 전까지 상세창에서 변경할 수 없습니다.

`Esc`는 이름표·수량 편집, 상세창, 가방 순서로 닫습니다. `F2`로 시험 메뉴에 복귀하여 재선택하면 시험용 가방을 재보급하고 이전 바닥 물품을 정리합니다. 초기화·다른 장면 이동·시험 종료에서도 바닥 물품을 정리하며 종료 시 원래 가방 객체와 이름표·강화·장비·원정 상태를 복원합니다.

자동 검증: `GODOT_TEST_TIMEOUT_SECONDS=300 ./tests/run_headless_tests.sh item_details item_metadata item_detail_input item_drop_test_room inventory_model inventory_chest smithing_system test_room_session`. `item_detail_input`은 1280×720·960×540의 독립 뷰포트에서 실제 GUI 이벤트 전달로 버튼 클릭·한글 입력·Enter·Esc·장착·버리기를 검증하며 OS 입력은 보내지 않습니다.

실제 화면은 `ITEM_DETAIL_QA_ITERATION=<새 이름> ./tests/run_embedded_preview.sh item_detail_preview.gd`로 창 없이 촬영합니다. `artifacts/visual_qa/item_details/<새 이름>/`에 검·갑옷·이름표 저장·버리기 수량·작은 화면의 실제 상세창과 원정·커서 보존 기록을 저장합니다. 하네스 자동 검증은 `./tests/run_headless_tests.sh item_detail_preview`입니다.

### 루팅 위치 재입장과 제공 상자 모델

[루팅 배치 설계와 후보 목록](design/LOOT_SPAWNS.md)에서 각 보관 장소의 이유와 현재 출현 정책을 확인할 수 있습니다.

무작위 루팅 생성은 던전에만 적용합니다. **은신처는 던전이 아니므로 제외**하며, 성물실 던전과 은신처는 별도의 장면입니다. `F2 → 장면 → 3D 은신처 · 생활 기능`에서는 루팅 상자가 생성되지 않고 기존 개인 보관함을 사용할 수 있어야 합니다. F2 복귀 후 재입장해도 같은 원칙을 유지합니다. `./tests/run_headless_tests.sh hideout_loot_exclusion`은 실제 은신처 두 차례 진입, 루팅 후보·실제 상자 부재, 개인 보관함 유지와 시험 원정의 격리·복원을 검사합니다.

`F2 → 장면 → 루팅 배치 · 성물실 재입장`과 `루팅 배치 · 폐광 재입장`은 실제 본편 맵을 새로 엽니다. 성물실의 벽가 보관 공간 6곳, 폐광의 기존 보급·유품·작업실·창고·봉헌 공간 5곳이 고정 후보입니다. 입장마다 이 중 2~4곳에만 상자가 생기며, 반드시 빈 자리를 남깁니다. 이 후보 수와 밀도는 현재 구현 조정값입니다. 같은 장소도 어떤 원정에서는 있고 다른 원정에서는 없으며, 확률 추첨이라 연속 입장의 결과가 우연히 같을 수 있습니다.

`WASD`로 이동해 작업·보관 공간의 상자와 빈 자리를 비교하고 `E`로 실제 상자를 조사·수색합니다. 같은 입장 안에서는 메뉴를 열거나 상자를 다시 조사해도 위치·내용물이 새로 추첨되지 않습니다. `F2`로 테스트룸에 돌아와 같은 항목을 다시 선택하면 새 입장으로 추첨합니다. 원정 중 내용물은 기존 물품 카탈로그·식별·이동 규칙을 사용합니다.

`F2 → 기본 → 루팅 모델`의 나무통·나무 상자 1·나무 상자 2·보물 상자는 제공된 네 에셋을 한 종류씩 실제 플레이어 앞에 준비합니다. 현재 가방과 장착 무기를 유지하고 적·함정을 정리하며, `E` 조사 후 수색 화면에서 붕대·물을 실제 시험 가방으로 옮길 수 있습니다. 여는 도중 `F2`를 누르면 미완성 동작을 취소하고 메뉴에서 시간이 멈춥니다. 같은 모델을 재선택하면 닫힌 상태와 새 내용물로 반복합니다. 기본 물품 보급 상자는 계속 원본 물품 카탈로그에서 자동 준비됩니다.

초기화는 시험 가방과 대상만 새로 준비하고, 본편 맵에서도 `F2`로 시험 메뉴에 돌아올 수 있습니다. 메인 메뉴로 종료하면 원래 가방 객체·장비·물품·생존 수치·크라운·상인 상태를 복원합니다. 배치용 영속 원정 필드는 추가하지 않습니다.

자동 검증은 `GODOT_TEST_TIMEOUT_SECONDS=600 ./tests/run_headless_tests.sh loot_spawn loot_container_models test_room test_room_session inventory_chest chest_hands cave_dungeon cave_flow`입니다. `loot_spawn`은 전체 후보의 지면 접촉·모델 몸체와 주변 충돌·플레이어 접근 공간, 실제 후보별 생성과 열기, 시드 재현·빈 자리 변화·입장 중 유지, 네 모델 시험·두 본편 맵 반복 입장·F2·초기화·종료 복원을 검사합니다. `loot_container_models`는 네 실제 모델의 표면·뚜껑·손 접점과 개봉을 별도로 검사합니다. 헤드리스 결과는 렌더 이미지 품질을 판정하지 않습니다.

### 은신처 연금술

`F2 → 장면`에서 다음 항목을 선택하면 실제 은신처 연금대가 열립니다. 완성 과정을 자동으로 대신하지 않으며, 원본 물품 카탈로그에서 가져온 네 액체·다섯 약초·빈 병을 시험 가방에 보급합니다. 가방이 가득 찼다면 안내에 따라 시험 가방 일부를 비워 재료와 결과물 공간을 확보합니다. 원래 원정의 가방에는 영향을 주지 않습니다.

| 항목 | 시험 내용 |
|---|---|
| 연금술 제조 | 포도주에 통뿌리 두 줌을 달이고 냉각한 뒤 빻은 박하를 넣는 실제 포도약 |
| 연금술 절구 | 새벽잎 두 줌을 함께 넣어 세 번 빻고 두 차례 나누어 달이는 봉합약 |
| 연금술 증류 | 증류주·달쑥·쇠꽃을 달이고 증류기로 정수를 모아 병입 |
| 연금술 품질 | 기름 처방에서 정상 분쇄와 덜 빻기, 과열·잘못된 투입을 비교 |
| 원본 카탈로그의 모든 처방 | `AlchemyCatalog.ordered_recipe_ids()`의 다섯 약품·두 증류주 처방이 자동 등록되며 각각 실제 작업대로 연결 |

조제서의 순서를 따르며 오른쪽 버튼 또는 작업대 도구를 클릭합니다. `Space` 풀무, `R` 솥 내리기·올리기, `T` 모래시계, `G` 빻기, `H` 젓기, `B` 병입입니다. 절구는 한 줌씩 넣고 세 번 찧어야 가루가 됩니다. 불을 켜도 솥을 올려두면 달여지지 않으며, 실제로 끓는 시간만 조제에 반영됩니다. 모래시계는 독립된 8초 타이머여서 뒤집기만 해서는 제조가 진행되지 않습니다. 증류도 실제로 끓는 동안에만 진행됩니다.

조제 결과에 상급·보통·미약·실패와 잘못된 단계가 표시됩니다. 상급 물약은 빈 병 두 개를 쓰고 실제 두 병이 지급되며, 보통·미약은 한 개를 씁니다. 완성품은 `Esc → I`로 실제 가방에서 사용합니다. `같은 처방으로 다시 만들기`로 보급이 남은 동안 반복할 수 있고, `F2` 복귀 후 재선택하면 재료를 보충합니다. 신규 재료와 품질별 물약 15종은 원본 물품 카탈로그를 통해 물품 탭·보급 상자에 자동 등록됩니다.

`Esc`는 작업대를 닫고 배합·온도·모래시계를 그대로 멈춥니다. 같은 은신처에서 다시 열면 이어지지만 `F2`, 장면 이동, 배합 폐기는 미완성 작업을 정리합니다. 시험 초기화 후에도 재시험할 수 있으며, 시험 종료 시 원래 인벤토리 참조·장비·물품·상인 재고·생존 수치가 복원됩니다. 연금술은 새로운 원정 영속 필드를 추가하지 않고 작업대의 임시 배합 상태만 사용합니다.

자동 검증: `./tests/run_headless_tests.sh alchemy_system alchemy_overlay alchemy_visual alchemy_test_room test_room_session`. 실제 숨김 렌더링: `ALCHEMY_QA_ITERATION=<새 이름> ./tests/run_embedded_preview.sh alchemy_preview.gd`. [상세 조제 안내](ALCHEMY.md)와 [렌더링 검증 조건](tests/EMBEDDED_RENDERING.md)을 참고하세요.

### 술 증류와 판매

`F2 → 장면 → 증류소 · 화롯불 브랜디 판매` 또는 `증류소 · 달쑥 압생트 판매`를 선택합니다. 실제 은신처 연금대의 `술 증류` 화면이 열리고 해당 처방이 선택됩니다. 원본 재료 카탈로그의 액체·약초·빈 병을 시험 가방에 보급하고, 가득 찬 가방은 시험용 스택 일부를 교체한 사실을 알린 뒤 완성품 공간을 확보합니다. 제조와 판매를 자동으로 대신하지 않으므로 직접 조제서를 따라 술을 만들어 보세요.

1. `술 증류`의 처방을 선택하고 표시된 바탕 액체와 약초를 투입합니다. 필요한 약초는 절구에서 세 번 빻아 넣고 정해진 횟수만큼 젓습니다.
2. 솥을 내려 실제로 끓이면서 처방의 달임 시간을 채웁니다. 솥을 올린 뒤 `증류 시작`으로 증류기를 연결합니다.
3. 솥을 다시 내려 풀무로 불을 유지합니다. 솥을 올려두거나 불이 충분하지 않으면 증류가 진행되지 않습니다. 증류가 끝나야 `빈 병에 받기`로 판매품을 만듭니다.
4. `Esc → M → 성소의 중개인 → 물건을 거래합니다`로 실제 거래 화면에 들어갑니다. 가방의 완성 술을 선택하고 `판매`를 누르면 한 병씩 사라지고 지갑에 표시된 크라운이 들어옵니다.

| 처방 | 정제 1병 원가 / 판매가 | 특급 2병 원가 / 총판매가 | 특급 제조 후 순이익 |
|---|---|---|---|
| 화롯불 브랜디 | 12 / 36 크라운 | 14 / 120 크라운 | 106 크라운 |
| 달쑥 압생트 | 19 / 51 크라운 | 21 / 168 크라운 | 147 크라운 |

원가는 필요한 액체·약초와 결과를 담을 빈 병까지 실제 중개인에게 구입했을 때의 금액입니다. 시험에서는 재료를 보급하므로 원가를 지불하는 흐름도 확인하려면 거래 화면에서 다음 제조분의 재료를 직접 구입하세요. 증류 재료는 유료로 계속 구입할 수 있습니다. 품질에 따라 특급 2병·정제 1병·미숙 1병이 나오며, 심하게 실패한 배합은 상품을 만들지 못합니다. 술은 회복약과 구별되는 판매 물품이고 6개 품질별 상품은 물품 탭과 시험 보급 상자에 원본 카탈로그에서 자동 등록됩니다.

`Esc`로 닫으면 배합·온도·모래시계가 멈추고 같은 은신처에서 다시 열어 이어갈 수 있습니다. `F2`, 장면 이동 또는 배합 폐기는 미완성 작업을 정리하며 투입한 재료는 돌려받지 못합니다. 작업대와 중개인 모두 `F2`로 같은 시험 가방을 유지한 채 시험 메뉴로 돌아옵니다. 재선택하면 재료를 보충하고 초기화하면 새 시험 가방으로 다시 시작합니다. 종료 시 원래 가방 참조·신호 연결·술과 재료·크라운·중첩 상인 재고·생존과 상태이상을 복원합니다.

F2 복귀 로딩 중에도 떠나는 장면을 일시정지해 포만감·수분·스트레스·상태이상 수치를 유지합니다. 로더만 계속 동작하며 테스트룸 메뉴로 돌아오면 같은 시험 가방을 이어 씁니다.

`F2 → 장면 → 은신처 · 화롯불 조리와 식사`를 선택하면 실제 은신처의 중앙 화롯불 앞에서 조리 화면이 열립니다. 체력 35·기력 20·포만감 15·수분 20·스트레스 55, 상태이상 없음으로 준비합니다. 원본 `CampCookingCatalog`의 모든 조리법을 한 번씩 만들 분량에 재료별 여분 1개를 더해 생고기 3개·식용 버섯 4개·물 3개를 보급합니다. 가방이 가득 찼을 때만 마지막 시험용 스택 일부를 필요한 재료로 교체하며 화면에 알립니다.

`모닥불 고기구이`, `따뜻한 버섯수프`, `고기·버섯 스튜` 버튼으로 직접 조리합니다. 화롯불에 설치된 꼬치와 냄비를 사용하므로 야영 도구와 온기는 소비하지 않습니다. 재료는 시작할 때 소비하고, 조리 시간 8·10·14초가 지나면 즉시 먹어 원본 조리법의 회복을 적용합니다. 완성 음식은 가방에 저장하지 않습니다. 은신처 조작은 조리 화면 안에서 계속 일시정지되며, 조리법에 정해진 생존 시간만 진행됩니다.

`Esc`로 닫고 중앙에 매달린 냄비를 향해 `E`를 누르면 0.3초 준비 후 같은 화면을 다시 엽니다. 화롯불을 껐다면 기존 화롯불 상호작용으로 먼저 불씨를 살리세요. 불이 꺼져 있거나 재료가 부족하면 조리를 시작할 수 없습니다. 조리 중 `Esc`·장면 전환·`F2`로 중단하면 사용한 재료와 경과한 시간은 유지하고 식사 효과는 주지 않습니다.

`F2`로 시험룸에 돌아오고 같은 항목을 다시 선택하면 재료와 시험 수치를 다시 준비합니다. 초기화하면 새 시험 가방으로 재시험할 수 있으며, 종료 시 원래 인벤토리 객체·물품·장비·생존 수치·스트레스·상태이상을 복원합니다. 재료 아이템은 기존 원본 물품 목록에 따라 물품 탭과 보급 상자에 자동 등록됩니다.

`./tests/run_headless_tests.sh hideout_cooking_controller hideout_cooking_test_room hideout_cooking_visual cooking_system cooking_hud test_room test_room_session`은 실제 냄비의 충돌 쿼리·준비 시간·조리 버튼, 세 식사의 정확한 재료 소비와 회복, 가득 찬 가방, 불·재료 부족, 중단·반복 복귀·초기화와 원정 복원을 확인합니다. 실제 화면은 `HIDEOUT_COOKING_QA_ITERATION=<새 이름> ./tests/run_embedded_preview.sh hideout_cooking_preview.gd`로 중앙 조리 기구와 조리 화면 6장을 촬영하며, [숨김 렌더링 조건](tests/EMBEDDED_RENDERING.md)을 따릅니다. 헤드리스 결과는 픽셀 품질을 보증하지 않습니다.

## 대장간 제작과 강화 시험

`F2 → 장면`의 대장간 네 항목은 실제 은신처 작업대로 이동해 해당 작업 화면을 엽니다.

| 항목 | 실제 시험 동작 |
|---|---|
| 대장간 · 화로부터 검 완성 | 철 투입 → 풀무로 가열 → 모루 망치질 → 물 담금질 → 완성 검 획득 |
| 대장간 · 손잡이 교체 | 준비한 검에 실제 손잡이 재료를 소비해 교체하고 공격 기력 비용 확인 |
| 대장간 · 칼날 보강 | 검날에 실제 보강재를 추가하고 근접 피해 변화 확인 |
| 대장간 · 구멍 파기와 룬 삽입 | 검에 구멍을 만든 뒤 룬 돌조각을 넣고 해당 검의 강화 정보 확인 |

제작과 강화 재료는 원본 카탈로그에 따라 준비하고 물품 탭·보급 상자에도 자동으로 나타납니다. 같은 시험을 다시 선택하면 재료를 다시 보급하며, 가득 찬 가방은 기존 야영 시험과 마찬가지로 끝의 시험용 스택을 제한적으로 교체합니다. 강화 시험에는 다시 작업할 수 있는 검을 준비합니다.

화로에서 `Space` 또는 마우스를 누른 채 아래로 당겨 풀무를 움직입니다. 700~1000°C에서 `E`로 모루에 옮기고 `A`·`S`·`D`로 뿌리·중앙·끝을 선택해 `LMB`를 약 0.75초 눌렀다 놓습니다. `R`로 뒤집어 양면을 두드리고 식으면 `F`로 재가열합니다. 양면을 완성한 적정 온도의 칼날은 `Q`로 담금질한 뒤 완성품 버튼으로 받습니다. 룬 화면도 약 0.75초 눌렀다 놓는 천공을 세 차례 완료한 뒤 조각을 넣습니다. 일반 작업대의 0.3초 조사도 같은 실제 제작 화면을 엽니다.

대장간에서 `Esc`로 닫으면 은신처 안의 미완성 단조를 유지합니다. `F2`는 작업 화면과 미완성 단조를 정리하고 일시정지된 시험장으로 돌아갑니다. 투입한 철과 숯은 반환하지 않습니다. 이미 완성한 물품·소비한 재료는 시험 가방에 유지되며 `테스트룸 초기화`로 새 시험 가방을 만듭니다. 진행 중인 룬 구멍은 검 자체에 기록되므로 해당 검을 다시 선택해 계속 팔 수 있고 이미 사용한 강철 부속은 중복 소비하지 않습니다. 종료 시 원래 인벤토리 객체·장비·개별 무기 강화 정보와 원정 수치를 복원합니다.

`./tests/run_headless_tests.sh smithing_system blacksmith_test_room test_room_session`은 실제 대장간 제작·강화, 원본 카탈로그 자동 등록, 가득 찬 가방 보급, F2 반복 복귀·초기화와 원정 복원을 확인합니다. 실제 그림과 입력 화면은 별도 실제 렌더러 검증 대상이며 헤드리스 통과를 화면 비교 완료로 간주하지 않습니다.

`BLACKSMITH_QA_ITERATION=iteration_01 ./tests/run_embedded_preview.sh blacksmith_preview.gd`는 실제 제작 화면의 8개 작업 상태와 완성한 검을 실제 플레이어가 장착한 모습까지 총 9장을 창 없이 촬영하며 `artifacts/visual_qa/blacksmith/<반복 이름>/`에 저장합니다. 실제 레시피 버튼은 격리 뷰포트에만 클릭 이벤트를 보내고 나머지 작업은 동일한 제작 함수로 실행합니다. 원정·커서·원본 해시 보존과 새 폴더 조건은 [숨김 렌더링 안내](tests/EMBEDDED_RENDERING.md)를 따릅니다.

## 아이템 사용 시간과 F 취소 · 2026-09-15

퀵 인벤토리나 가방의 약·음식·물·치료품·마법서 사용을 시작하면 중앙 원형 진행 표시, 소수 첫째 자리의 남은 초, 물품 이름과 `[F] 취소`가 나타납니다. 가방에서 시작한 사용은 가방을 닫고 게임 시간으로 진행합니다. 사용 중 `F`는 횃불 전환보다 취소를 우선합니다. 취소하면 아이템 수량과 효과는 바뀌지 않으며, 완료 순간 소지 여부·치료 가능 상태를 다시 검사한 뒤 한 개만 소비하고 효과를 적용합니다. 체력 0 부위에 일반 약을 쓰거나 이미 가득 찬 수치를 회복하려 하면 시작부터 거절합니다.

현재 사용 시간은 핏빛 회복약 6.6초, 그 외 일반 약·해독·정화·물 3초, 일반 식량 4초, 육포 8초, 마법서 5초, 붕대 5.35초, 부목 7.2초, 수술 12초입니다. 붕대·부목은 기존 왼팔 모션의 원본 길이를 사용합니다. 핏빛 회복약과 육포에는 각각 마시기와 먹기 손 모션이 연결됩니다. 그 외 물품의 전용 손 모션은 별도 범위입니다. 타이머 중에는 공격·주문·다른 퀵 슬롯 사용을 막고, 가방/F2/일시정지·야영·장면 전환·사망 등으로 사용이 중단되면 미완료 효과를 적용하지 않습니다. 마비 상태에서는 해당 마비 해제약 사용을 허용합니다. 완료 후와 사용 중이 아닐 때 F의 기존 횃불 조작은 유지합니다.

`F2 → 기본 → 아이템 사용 시간 · F 취소`는 부상과 보급품을 준비합니다. `4 약 / 5 붕대 / 6 식량 / 7 물`을 누르고 중간에 F로 취소하거나 끝까지 기다려 비교합니다. F2로 같은 항목을 재선택하면 수량·부상을 다시 준비하고 원래 원정은 보존합니다.
