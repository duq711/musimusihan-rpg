# 사용자가 제공한 모델 기반 양손

사용자가 제공한 `hand1.OBJ`와 `left_hand.ZTL`을 보존하고, OBJ의 실제 손 형상을 직접 경량화해 현재 플레이어의 양손으로 교체한다. 제공 원본의 손가락 비례와 엄지·손톱 방향을 기준으로 하며, 원본에서 약간 굽어 있는 기본 자세를 유지한다.

현재 통합 경로는 `left_hand_detailed.glb`, `right_hand_detailed.glb`이다. 일반 1인칭의 기본 `original` 프로파일과 `detailed` 프로파일은 이 새 스킨 양손을 공유한다. 전신·인벤토리가 사용하는 `gravebound_player.glb`에서는 기존 손 조각 22개를 제공 모델의 손 본체 2개와 손톱 10개로 교체하고 손 이외의 오브젝트 28개를 유지한다. 검 오른손과 방패 왼손의 별도 전용 파지 에셋은 기존 모델을 사용한다.

## 제작 사양

- 고밀도 원본은 손 본체 450,989정점이며 손톱을 합쳐 1,193,494삼각형이다. 게임용 한 손은 본체 45,000삼각형과 손톱 5개 각 600삼각형으로 총 48,000삼각형이다.
- 새 공유 UV와 4K `supplied_hand_basecolor.png`, `supplied_hand_normal.png`, `supplied_hand_roughness.png`를 사용한다. 법선 맵은 제공된 고밀도 형상에서 실제 베이크한다.
- 손 하나마다 실제 제공 형상의 관절 위치에 맞춘 16본과 새 `Joint_*` 보정 15개를 사용한다. 손톱은 해당 끝마디 본에 고정한다. 이전 모델의 정점별 보정을 복사하지 않는다.
- 오른손은 제공 왼손의 실제 메시를 반사하고 면 방향을 교정한 뒤 별도 오른손 리그를 만든다. UV는 대응하는 정점에 그대로 유지하며 음수 오브젝트 스케일을 사용하지 않는다.
- 기존 손목 연결부·팔뚝·위팔 소매를 새 손에 연결한다.

## 확인 방법과 상태

테스트룸 → 기본 → **캐릭터 그래픽 · 제공 모델 양손**에서 빈손·활·상자를 확인한다. **캐릭터 그래픽 · 손가락 마디별 관절**에서는 각 손의 15개 마디를 조절한다. `펴기`는 약간 굽은 원본의 기본 자세로 복원한다. 새 모델의 추가 굽힘 한도는 네 손가락의 뿌리·가운데·끝이 각각 60°·45°·45°, 엄지가 25°·35°·45°이며, 그레이박스는 기존 범위를 유지한다. 전신·인벤토리 손은 플레이어 외형 시험과 본편 `I`에서 비교한다.

현재 상태는 **검증 완료**다. 제공 모델 `iteration_05`의 독립 Blender 검사와 실제 화면 7개, Godot 헤드리스 8개가 통과했다. 새 양손의 Vulkan 화면 18장(관절 12장·상세 손 6장)을 촬영·검토했으며, 전신 5개 화면은 현재 전신 GLB와 SHA-256이 동일한 `supplied_hands_03`의 검토를 재사용했다. 실제 게임 연결, 관절·활·상자 동작, 손목·소매 연결과 원정·가방·커서 복원을 확인했다. 제작·검증 기록과 정확한 적용 파일 해시는 프로젝트 루트의 `asset-staging/player_supplied_hands_20260911/validation_summary.json`에 보존한다. 검 오른손·방패 왼손은 기존 전용 파지 에셋을 유지한다.
