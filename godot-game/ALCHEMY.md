# 성소의 수동 연금술

은신처 작업실에서 대장간 맞은편 연금대를 `E`로 조사합니다. 액체 붓기부터 병입까지 실제 도구·버튼으로 진행합니다. 처방을 선택했다고 재료가 자동 투입되거나 정해진 순서로 자동 제조되지는 않습니다.

## 참고한 실제 시연

[IGN의 Kingdom Come Deliverance 2 연금술 시연](https://www.youtube.com/watch?v=8yga2zCBnKs)을 브라우저에서 열어 5:55~6:45의 기본 액체 선택, 솥 높이와 풀무, 모래시계, 빻은 약초를 절구에서 붓기, 병입 화면을 직접 확인했습니다. 영상의 0:59 품질 요인 및 [게임 내 코덱스가 정리된 연금술 문서](https://kingdomcomedeliverance.wiki.gg/wiki/Alchemy)의 액체·재료·분쇄·가열·증류 구분도 참고했습니다.

조작과 판정 구조를 참고했으며, 성소의 약초명·처방·효과·시간 수치는 이 게임에 맞춰 새로 설계했습니다. 킹덤컴의 레시피·모델·음원을 가져오지 않았습니다.

| 참고 동작 | 이 프로젝트 구현 |
|---|---|
| 바탕 액체를 직접 선택·붓기 | 물·포도주·곡물 증류주·약용 기름의 별도 재고와 약액 색 |
| 약초 한 줌·통째/가루 구분 | 솥 또는 절구에 한 줌씩, 절구 최대 네 줌, 세 차례 분쇄, 중간의 거친 상태도 판정 |
| 풀무와 솥 높이 | 풀무는 불을 키우고 시간이 지나면 약해짐. 솥을 올리면 가열 중단·냉각 |
| 모래시계·끓이기 | 독립 8초 모래시계와 실제 끓는 누적 시간. 재료 투입 당시의 시간도 기록 |
| 냉각 후 나중에 약초 넣기 | 투입 순서·분쇄 형태·이전 끓임 시간·투입 온도 검사 |
| 직접 병입/증류 | 다른 마무리 판정. 증류는 끓는 동안에만 정수 축적, 미완료 수령 불가 |
| 조제 실수와 물약 품질 | 실제 배합 이력으로 상급·보통·미약·실패, 사유와 점수 공개 |

## 다섯 처방

| 처방 | 핵심 제조 과정 | 실제 효과 |
|---|---|---|
| 붉은 봉합약 | 물·통 핏뿌리 → 1회 달이기 → 빻은 새벽잎 두 줌 → 젓기 → 1회 달이기 → 냉각 | 체력 회복 |
| 잿불 포도약 | 포도주·통 핏뿌리 두 줌 → 2회 달이기 → 냉각 → 빻은 쓴박하 → 두 번 젓기 | 체력 회복 |
| 달쑥 지혈 정수 | 증류주·빻은 달쑥 두 줌·통 쇠꽃 → 젓기 → 1회 달이기 → 1.5회 증류 | 출혈 처치·회복 |
| 순례자의 냉침약 | 물·빻은 새벽잎·통 쓴박하 두 줌 → 두 번 젓기 → 차갑게 8초 우림 | 수분 회복 |
| 쇠꽃 봉합유 | 기름·빻은 쇠꽃 두 줌·통 핏뿌리 → 두 번 젓기 → 1회 달이기 → 냉각 | 출혈 처치·회복 |

정확한 목표 온도·순서는 게임 안 조제서와 `AlchemyCatalog`가 원본입니다. 상급은 해당 품질 물약 두 병, 보통·미약은 한 병을 만듭니다. 품질에 따라 효과량도 다릅니다. 실제 지급 수만큼 빈 병이 필요하므로 제조 전에 빈 병 두 개를 준비하세요. 재료·빈 병은 중개인에게 구입하고 물약은 기존 인벤토리에서 소비합니다.

## 조작과 반복

- `Space`: 풀무. 연속해서 지나치게 당기면 과열되므로 기포·온도와 경고를 살핍니다.
- `R`: 솥 올리기/내리기. 식힐 때는 솥을 올립니다.
- `T`: 모래시계를 뒤집습니다. 시간이 다 되면 필요에 따라 다시 뒤집습니다.
- `G`: 절구를 한 차례 찧습니다. 세 번 찧으면 가루가 됩니다.
- `H`: 약액을 한 번 젓습니다. 처방에 적힌 시점과 횟수를 따릅니다.
- `B`: 직접 약을 받거나 완료된 증류 정수를 병에 받습니다.
- 작업대의 액체병·절구·풀무·솥·모래시계·증류기·빈 병도 클릭할 수 있습니다.
- 붓기·분쇄·풀무·젓기·유리병·도구 연결에 각각 짧은 작업음이 있으며 게임 음량 설정을 따릅니다.
- `작업대 전체 / 절구 / 가마솥 / 증류기`로 시점을 바꿉니다. 조제서는 확대해서 읽을 수 있습니다.
- 결과 화면에서 품질과 실패 이유를 읽고 `같은 처방으로 다시 만들기`를 누릅니다.

실패 시 이미 쓴 액체와 약초는 반환되지 않습니다. 빈 병 부족이나 가방 용량 부족이면 성공한 약액과 빈 병은 보존되어 정리 후 다시 받을 수 있습니다. 한 배치의 중복 수령과 부분 지급을 막습니다. 제조 중 쓰지 않은 약초는 가방에 남습니다.

`Esc`로 잠깐 물러나면 온도·모래시계·제조 진행이 모두 멈춥니다. 같은 은신처에서 재개할 수 있지만 장면 이동·명시적인 폐기·시험 `F2` 복귀는 미완성 배합을 정리합니다. 상인에게 다녀올 때는 장면이 바뀌므로 재료를 제조 전에 준비해야 합니다.

## 검증과 구현 범위

`alchemy_system_test`는 다섯 처방의 실제 시간 진행·완성·물약 사용, 틀린 재료/순서/분쇄/시간/마무리와 과열, 독립 타이머, 냉각·증류, 가방 부족·빈 병 부족·중복/재진입 지급 방지를 검증합니다. `alchemy_overlay_test`는 물병 직접 클릭·키보드 타이머·실제 조제·닫기와 재개를, `alchemy_visual_test`는 실제 도구·용기·상태 연출을, `alchemy_test_room_test`는 은신처의 E 상호작용과 다섯 처방·품질 비교·F2·초기화·원정 복원을 검증합니다.

`alchemy_audio_test`는 실제 재생 없이 14개 작업음의 서로 다른 파형·길이·클리핑 방지·양 끝 무음을 검사합니다. 기본 연금술 검증은 `./tests/run_headless_tests.sh alchemy_system alchemy_audio alchemy_overlay alchemy_visual alchemy_test_room`입니다.

실제 화면은 숨김 Forward+/Vulkan 렌더러로 [artifacts/visual_qa/alchemy/](artifacts/visual_qa/alchemy/)에 반복 촬영합니다. 이 자료는 실제 본편 작업대 UI와 같은 모델·제조 함수의 결과이며, 사용자 데스크톱 캡처나 생성된 목표 이미지가 아닙니다. 각 반복에는 소스 해시·실제 상태·원정/커서 보존 결과를 기록합니다.

현재는 전용 작업대 화면과 도구에 맞춘 손동작을 사용합니다. 자유 시점의 도구 집기·내려놓기 전체, 킹덤컴 수준의 모든 손가락 접촉·전환 애니메이션, 약초 신선도·건조·숙련도·자동제조는 별도 기능이며 현재 지원한다고 표시하지 않습니다. 하드웨어 마우스나 OS 포커스는 숨김 검증의 대상이 아닙니다.
