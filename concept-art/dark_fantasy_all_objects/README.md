# 어두운 판타지 오브젝트 아트

플레이어 몸·손·팔을 제외한 실제 게임 오브젝트 126종을 대상으로 Codex 이미지 생성으로 6방향 컨셉 시트를 만들고, Godot의 실제 모델과 표면을 수정했습니다. 반복 배치는 같은 유형으로 묶었으며, 형태 변형과 실제 생성 위치는 원본 목록에 기록했습니다. 장비는 포함합니다.

[전체 컨셉·변경 전·현재 화면 비교](../../asset-staging/dark_fantasy_all_objects/review/index.html)에서 이름으로 검색하거나 종류를 고르고, 정면·후면·왼쪽·오른쪽·위·아래를 확인할 수 있습니다. 실제 장소 탭에는 은신처·성소·폐광의 같은 카메라 비교 10쌍이 있습니다.

게임에서는 **테스트룸 → F2 → 기본 → 어둠의 오브젝트 도감 · 6방향**으로 확인합니다. 실제 게임의 생성 함수를 사용하는 도감이며, 보는 동안 전투와 생존 시간은 멈춥니다. F2·Esc·복귀 버튼으로 돌아올 수 있고 시험 원정의 격리와 종료 시 복원을 유지합니다.

목재에는 낡은 판재와 결, 철물에는 어두운 단조 표면과 실제 띠·리벳, 천에는 거친 먹색 표면을 적용했습니다. 검·방패·횃불·지팡이, 활·화살·철퇴, 상자·통·침상·작업대·바이스와 취사 도구의 주요 형태를 보완했습니다. 적의 후드·갑옷·망토·두개골을 다듬고 과한 뼈의 황색을 낮췄습니다. 돌벽·판석·아치에는 입체 경계를 만들고, 동굴은 원본 지형과 표면 지도를 보존하면서 색·거칠기·투영을 조정했습니다. 불꽃·얼음·물·석재 마법과 시험용 표식도 포함합니다.

실제 촬영을 보며 밝은 철띠와 목재, 지나친 발광, 떠 보이는 불꽃, 황색 뼈, 늘어진 암석 밑면 무늬와 수면의 앞뒷면을 수정했습니다. 방 안 비교에서는 벽·바닥 접합부 누출과 천장 아래 빠진 석재를 추가로 확인하여 보완했습니다. 화덕의 기본 도형을 그을린 장작·열린 냄비·손잡이 달린 컵으로 바꾸고, 용기의 안팎 면 방향도 바로잡았습니다. 이전 반복 결과는 보존합니다.

컨셉 126장의 생성 원본과 프롬프트, 게임에 적용한 생성 표면 지도 7장의 출처는 [생성 기록](generation_manifest.json)에 있습니다. 실제 촬영은 사용자 화면을 캡처하지 않고 Godot Vulkan 렌더러에서 저장했습니다. 오브젝트별 실제 6방향은 756장이고, 방향별 비교판은 126장입니다. [최종 검증 기록](../../asset-staging/dark_fantasy_all_objects/review/final_audit.json)에는 이미지 해시, 촬영 당시와 현재 소스의 일치, 같은 카메라, 시험 결과와 비교 페이지 검증을 기록합니다.

미세한 조각·금속의 깊은 부식·천의 올풀림·자연스러운 목재 균열은 컨셉보다 단순합니다. 일부 생성 그림의 위·아래 시점과 방향 이름에는 원근 및 배치 차이가 있습니다. 실제 캡처는 고정된 여섯 직교 방향이며, 원래 단면인 바닥 문양과 얇은 수면은 측면·밑면에서 다르게 보입니다. 픽셀 단위의 일치나 수치화한 유사도는 주장하지 않습니다.

각 오브젝트의 관찰 내용과 남은 차이는 [광산·환경 59종](mine_final_review.json), [소품·건축 51종](props_final_review.json), [장비·수면·문양 7종](equipment_and_surfaces_final_review.json), [적·효과 9종](../../asset-staging/dark_fantasy_all_objects/review/vfx_review_final_03.json)에 보존합니다. 실제 방 안의 최종 확인은 [장소 10시점 검토](scene_final_review.json)에 있습니다.
