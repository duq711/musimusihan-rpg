# 부목 손 연기

검지가 먼저 풀리고 약지·소지가 뒤따라 다시 잡는 순서를 각 회전에 적용했습니다. 엄지·중지는 쥐는 힘을 유지하면서 조금씩 조절하고 받치는 왼손도 긴장·이완합니다. 손목에 작은 회전을 더하고 재파지에서 감는 속도를 늦춥니다. 마지막에는 검지·중지를 펴 붕대 윗면을 누르고 손을 뗍니다. 손동작이 보이도록 감는 위치를 손목 쪽으로 옮겼습니다.

검증: splint_motion 통과. 실제 관절 각도의 재파지 변화, 손목 연결, 판자 접촉, 사용 완료·취소·상태 복원 확인. Vulkan/embedded 235프레임 촬영 및 원정·커서·소스 보존. 모든 손가락 표면과 붕대의 접촉을 수치 검증한 것은 아닙니다.
