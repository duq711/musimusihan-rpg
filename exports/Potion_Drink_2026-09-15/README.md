# 물약 마시기

사용자 제공 realistic_potions.glb의 붉은 건강 물약 병·액체·마개를 선택해 기존 healing_draught(핏빛 회복약)에 연결했습니다. 원본 Downloads 파일은 보존했습니다. 나머지 물약 종류의 모션은 이번 범위가 아닙니다.

5.8초: 병 꺼내기 → 왼손으로 마개 열기 → 입구를 입 쪽으로 향하게 들어 네 번 삼키기 → 빈 병 내리기. 기존 양손 리그 사용, 파지점에 병을 맞추고 어깨는 몸에 연결합니다. 삼킬 때 손과 병이 작게 움직입니다. 새 음향 파일은 추가하지 않았습니다.

액체는 원본 메시를 기울어진 수면 평면으로 잘라 닫힌 수면을 구성합니다. 병 기울기에 따라 중력 방향을 환산하고 시간에 따른 작은 기울기 진동으로 출렁임을 표현합니다. 마시면서 채움 비율이 감소하고 끝에는 액체 메시가 사라집니다. 물리 유체 시뮬레이션은 아니며 원본 액체 형상과 볼록 수면 단면을 사용하는 시각 효과입니다.

완료 시 기존 회복량 32 및 소비 1회 적용. F 취소 시 소비·회복 없음. 테스트룸 F2 → 생존 → 물약 마시기 · 액체 출렁임. 반복 시 부상·보급 재준비.

검증: potion_motion, potion_test_room, timed_item_use, splint_motion 통과. 초기 timed_item_use 실패는 모션 노드 없는 단위 테스트 보호와 새 duration 경계 검증으로 수정 후 통과. 로그 tests_final.log/integration.log 참고. 최종 실제 Mac embedded Vulkan 195프레임 캡처 통과, 상태·커서·소스 보존 및 실제 시간 완료 확인. 원본 drink_02, GIF potion_drink.gif. 모든 손가락·병 표면 충돌의 수치 보장은 아닙니다.
