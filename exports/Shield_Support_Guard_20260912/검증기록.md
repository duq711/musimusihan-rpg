# 방패 지지 손과 검 내림

가드 중 검과 오른손은 아래로 내리고 검끝도 아래로 향하도록 변경했다. 방패는 정면 방향을 유지하면서 높이와 거리를 조절하여 손잡이를 쥔 왼손과 팔뚝이 화면 안에 보이게 했다. 낮은 대기 자세와 해제 복귀는 유지한다. 메시·재질·Blender 편집 파일은 변경하지 않았다.

- first_person_motion_test_room 통과: 실제 공격·가드·충격·해제·F2·초기화·원정 복원. 가드 시 왼손 파지점의 화면 내 위치 및 오른손/검끝 내림을 추가 검사했다.
- Vulkan 프리뷰 8장 통과: 대기, 걷기, 달리기, 올리기 중간, 완전 가드, 피격, 내리기 중간, 복귀. 가드·피격·중간 자세를 직접 열어 검토했다.
- 완전 가드 파지점은 화면 폭 60%, 높이 80% 부근이며 피격 시에도 화면 안에 남는다. 검과 오른손은 완전 가드 렌더에서 보이지 않는다. 중간 전환에서는 아래로 내려가는 검이 보인다.
- 이미지: godot-game/artifacts/visual_qa/shield_support_guard/. 실제 게임 코드·자산을 사용하는 독립 시험 화면이다. 사용자의 실행 중 게임 창을 재시작하지 않았다.
- 기존 전체 검 모션의 별도 오류를 이번 작업에서 해결했다고 보고하지 않는다.
