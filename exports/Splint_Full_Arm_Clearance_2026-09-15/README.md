# 부목 파지 복원 · 전체 팔 교차 보정

이전 수정의 관절 구 검사로는 팔뚝과 소매의 교차를 발견하지 못했습니다. 준비 구간의 손목 방향과 판자/붕대 파지를 이전 Prop_Grip 버전으로 복원했습니다. 감기 중에는 손목과 팔꿈치가 함께 바깥 궤도를 따라 회전합니다.

양팔의 실제 스킨 가중치를 적용한 장갑·소매 전체 정점을 투영해 분리 평면을 계산하며, 감기 구간에 최소 8mm 간격을 확보합니다. 준비에서 감기로 넘어가는 1.75–2초에는 보정을 점진 적용하므로 이 구간에 같은 수치 보장을 주장하지 않습니다. 물리 충돌 엔진이나 외부 에셋 수정은 아닙니다.

검증: splint_motion 통과. 감기 구간 전체 메시 분리, 판자 지지와 붕대 파지, 손목 연결, 연속성, 소비/취소와 상태 복원 검사. 최대 손 이동 0.0513m/60Hz, 손목 이음새 오차 0, 판자 접촉 오차 0.001m. 실제 embedded Vulkan 렌더 235프레임 촬영, 주요 시점 검토. 최종 원본 full_arm_clearance_02. 실행기는 종료 완료.
