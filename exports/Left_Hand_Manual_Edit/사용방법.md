# 왼손 직접 편집

`손_편집_열기.command`를 실행하면 Blender에서 편집 파일과 전용 패널을 함께 엽니다. 전용 패널을 불러오기 위해 별도의 Blender 창으로 열립니다. 전용 패널 없이 blend만 열었을 때도 Pose Mode에서 뼈를 직접 회전할 수 있습니다.

1. 3D 화면 오른쪽의 **손 편집** 탭을 사용합니다. 패널이 안 보이면 3D 화면 위에서 **N**을 누릅니다. 패널 내부를 스크롤하면 약지·새끼손가락도 나옵니다.
2. **검지·중지·약지·새끼**의 `뿌리 굽힘 → 중간 마디 → 끝마디` 값을 조금씩 조절합니다. 숫자를 좌우로 드래그하거나 더블클릭하여 각도를 입력합니다. `뿌리 방향`은 손가락을 벌리거나 모으는 조절입니다.
3. **엄지**는 먼저 `뿌리 방향`과 `엄지 비틀기`를 조절하고, 그다음 굽힘 값을 조절합니다. 한 번에 5~10도 정도씩 움직이며 확인하세요.
4. **손바닥 / 손등 / 엄지쪽 / 새끼쪽** 버튼은 손 자세를 바꾸지 않고 보는 방향만 바꿉니다. **자루 표시/숨김**으로 가려진 손가락을 확인할 수 있습니다. 자루와 소매는 선택을 잠가 실수로 움직이지 않게 했습니다.
5. 잘못 바꿨으면 **Ctrl+Z**로 실행 취소합니다. **시작 자세**는 이 파일을 준비할 때의 자세로, **원본 자세**는 추가 뼈 회전이 없는 원본 자세로 돌립니다.
6. **작업 저장** 버튼으로 저장합니다. 파일은 `왼손_횃불_직접편집.blend`입니다. 원본 에셋과 게임 파일을 직접 덮어쓰지 않습니다.

15개 마디의 회전과 피부 보정 형상은 연결되어 있습니다. 뼈 이름은 Godot 연결을 위해 유지했습니다. 뿌리/중간/끝마디는 각각 이름 끝의 0/1/2에 대응합니다.

이 파일은 사용자가 형태를 다듬는 작업용 사본이며, 앞선 자동 보정 결과를 최종 완성으로 승인한 파일이 아닙니다. 보이는 팔 소매는 제작용 연결 참고이고 게임에서는 별도 변형 코드가 팔꿈치에 맞춥니다. **Blender에서 저장해도 Godot에는 자동 적용되지 않습니다.** 편집이 끝나면 저장한 blend 파일을 기준으로 게임 반영·검증을 이어가야 합니다.

## 팔과 손 전체 이동
오른쪽 ‘손 편집’ 패널의 ‘팔·손 전체 이동 / 회전’에서 위치 X/Y/Z와 회전 X/Y/Z를 조절합니다. 손가락 자세와 소매의 연결을 유지한 채 전체가 함께 움직이며 횃불 자루는 고정됩니다.
‘팔 선택’ 후 마우스를 3D 화면 위로 옮기고 G로 이동, R로 회전할 수도 있습니다. X/Y/Z를 이어 누르면 축을 제한하고, Esc로 취소합니다. ‘팔 위치 복원’은 팔의 배치만 되돌리고 손가락 각도는 유지합니다.
‘팔뚝 표시’는 숨겨 둔 팔 소매를 켜거나 끕니다. 현재 기능은 전체 위치·회전 조절이며 팔꿈치 관절 IK는 아닙니다.
손가락 조절은 아래의 각도 숫자로 계속할 수 있습니다. ‘작업 저장’을 눌러 저장하세요.
