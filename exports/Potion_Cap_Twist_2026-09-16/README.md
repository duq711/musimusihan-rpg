# 물약 마개 돌려 열기 · 2026-09-16

## 적용된 동작

엄지와 검지가 작은 마개를 집고 첫 번째 회전을 합니다. 손가락을 잠깐 풀어 손목을 되돌린 뒤 다시 집고 두 번째로 돌립니다. 마개가 풀린 뒤에만 들어 빼며, 왼손은 마개를 잡은 채 화면 밖으로 빠집니다. 중지·약지·새끼손가락은 서로 다른 굽힘과 닫힘 시점을 사용합니다.

사용 시간은 6.6초입니다. 0.98–1.40초 첫 회전, 1.44–1.70초 다시 잡기, 1.70–2.14초 두 번째 회전, 2.17초 이후 빼기 순서입니다. 이후 입에 대고 네 번 마시는 동작과 액체 출렁임·감소가 이어집니다. 병·마개·양팔 원본 에셋은 보존했습니다.

[사용자가 지정한 참고 영상 19초](https://www.youtube.com/watch?v=kaJqMSBgi00&t=19s)를 숨김 브라우저에서 확인했습니다. 이 구간은 캔 뚜껑을 들어 여는 모습으로 보여, 손가락 접촉과 손목이 뒤따르는 타이밍을 참고했습니다. 두 차례 돌리고 다시 잡는 구성은 사용자의 병뚜껑 회전 요청에 맞춘 별도 연출입니다.

## 확인 방법

F2 → 생존 → **물약 마시기 · 액체 출렁임**. 실제 핏빛 회복약에 연결됩니다. 6.6초 완료 시 1개를 소비하고 회복하며, F 취소·F2 복귀·재선택·회복·초기화를 지원합니다.

## 산출물과 검증

- `cap_closeup.gif`: 뚜껑을 여는 0.5–2.8초 구간, 30fps.
- `potion_cap_twist.gif`: 전체 동작, 15fps 미리보기.
- `contact_sheet.jpg`: 잡기·회전·다시 잡기·빼기 주요 장면.
- `manifest.json`, `capture_01.log`: 실제 embedded/Vulkan 렌더 219프레임. 원정·가방·커서 및 소스 보존 확인.
- 최종 게임 소스는 `godot-game/artifacts/visual_qa/potion_drink/cap_twist_01/` 매니페스트의 모든 제작 소스 SHA256과 정확히 일치합니다.
- `tests_01.log`: 적용된 촬영 버전의 물약 동작·음용 위치·빈 병·소비·취소 검사 통과.
- `tests_diagnostic.log`: 강화한 마개 접촉·재파지 검사 통과. 실제 스킨의 엄지·검지 표면 두 점과 마개 외곽, 손목 복귀, 손가락 열고 닫기를 검사합니다. 이 검사는 별도 팔꿈치·지지 손 반동 후보를 포함한 상태에서 실행했습니다. 최종판의 마개·손가락·재파지 계산은 이 후보와 동일합니다.
- `test_room_verified.log`, `timed_use_verified.log`: 6.6초 사용 완료·F/F2 취소·재시험·원정과 가방 복원 검사 통과.

일부 분리 실행은 오류 출력 없이 시간 초과되어 로그를 보존했습니다. 단독 실행으로 재검사했으며 위 통과 로그가 그 결과입니다. 이후 지지 팔의 작은 추가 조정을 재촬영하려 했으나 자동 승인 검토가 통신 오류로 두 차례 거절했습니다. 해당 추가 조정은 `unrendered_support_arm_variant.gd`에만 보존하고, 최종판에는 이미 촬영·검토된 버전을 적용했습니다.

손 접촉 검사는 스킨 표면 표본과 마개의 원통 외곽 근사입니다. 모든 삼각형의 충돌 검사를 뜻하지 않습니다. 액체는 표면 메시 연출이며 유체 시뮬레이션은 아닙니다.
