# 판자와 붕대의 손 파지

고정 GRIP 오프셋 대신 현재 오른손 관절로 파지점을 계산합니다. 검지 말단이 판자 아랫면을 받치고 1.75초에 소매에 내려놓은 뒤 손을 뗍니다. 붕대 롤은 중지·약지·엄지 관절로 계산한 파지점에 연결해 손을 따라 움직입니다.

검증: splint_motion 통과. 운반 중 검지와 판자 접점 오차 및 롤의 파지점 추종 오차 1mm 미만 검사 추가. 손목·판자 소매 접촉·사용 완료·취소·상태 복원도 통과. 실제 Vulkan/embedded 235프레임, 원정·커서·소스 보존 확인. 모든 손가락 피부 표면의 충돌 검증은 아닙니다.
