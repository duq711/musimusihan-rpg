# 최신 참고 구도 적용

사용자의 반복된 DOOM 참고 화면 지시를 우선하여, 직전의 손을 화면 안에 보여 주는 구도에서 낮고 가까운 방패 윗테두리 구도로 변경했다. 방패 중심은 카메라 기준 (0,-0.55,-0.43), 각도는 (8°,0°,0°). 메시 크기·디자인·시야각은 유지했다. 손잡이를 잡는 실제 왼손은 삭제하지 않고 화면 아래에 있으며, 오른손 검도 완전 가드에서 아래로 내린다.

실제 렌더의 윗테두리 기준점: 가드 화면 폭 50.0%, 높이 71.45%; 피격 시 폭 46.5%, 높이 82.25%. 실제 원형 테두리의 넓은 호가 화면 아래에 보이며 중앙 시야가 열린다. 모서리에 작은 방패 전체를 표시하던 이전 구도와 다르다.

first_person_motion_test_room 통과. 실제 가드·피격·해제·공격·F2·원정 복원 유지. Vulkan 프리뷰 8장 통과. guard, impact, raise_half, returned 이미지를 직접 열어 검토했다. 결과는 godot-game/artifacts/visual_qa/shield_reference_framing/에 보존한다. 사용자 실행 중 게임 창은 재시작하지 않았으며 게임 코드·자산을 사용하는 독립 실제 렌더러 시험 화면이다.
