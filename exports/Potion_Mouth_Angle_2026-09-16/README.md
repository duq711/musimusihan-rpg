# 물약을 입으로 가져가는 각도 수정

첨부된 물병 음용 사진을 참고해 병목이 몸통 위에서 얼굴 쪽을 향하도록 구도를 수정했다. 카메라 기준 입구 목표를 `(0.015, 0.005, -0.075)`로 두고, 마시는 동안 회전 각도를 약 54도에서 77도로 늘린다. 작은 삼킴 동작을 더하며 입구는 고정한다. 오른손은 기존 병 몸통 파지를 유지한 채 병과 함께 회전한다.

기존 126~136도 회전과 입구 목표를 대체한다. 마개 열기, 손목 중심 구도, 병 원본, 액체 감소, 사용 시간과 소비·회복 로직은 유지한다. 액체 표현은 기존 메시 절단 효과이며 물리 유체 시뮬레이션은 아니다.

## 검증

- `tests_05.log`: `potion_motion` 통과. 손가락-마개 접촉·재파지, 오른손 파지, 입구 고정, 병목이 위쪽/얼굴 쪽을 향하는 조건, 액체 감소, 소비·회복·취소·상태 복원.
- `test_room_final.log`: `potion_test_room` 통과. 실제 사용·F/F2 취소·반복·회복·초기화·원정/가방/커서 복원.
- `capture_05.log`: 창·포커스·입력·소리 없이 embedded Vulkan으로 실제 모션 219프레임 촬영. 실행기가 검증 프로세스 종료까지 기다려 정상 종료했다.
- 음용 초반·중간·마지막 빈 병 프레임을 직접 확인했다. 최종 `manifest.json`에 기록된 8개 제작 소스 해시가 게임 파일과 일치하고 촬영 중 상태 보존·사용 완료 검사가 통과했다.

중간 후보 캡처와 로그는 비교 기록으로 보존하며 배포 영상은 `mouth_angle_05`에서 생성한다. 본 결과는 16:9 실제 렌더와 로컬 게임 코드 검증이며 OS 하드웨어 입력 검증은 포함하지 않는다.
