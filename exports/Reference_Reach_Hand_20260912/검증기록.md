# 발검 시작 손 자세 보정

첨부한 사진을 직접 열어 손 부분을 확인했다. 목표는 기존 캐릭터의 가죽 장갑을 유지하면서, 카메라에 넓게 보이는 손등·왼쪽 아래로 구부러진 네 손가락·아래로 벌린 엄지·오른쪽 아래로 이어지는 팔의 자세를 맞추는 것이다. 사진의 금속 갑옷 디자인을 교체 에셋으로 만들지는 않았다.

확인된 원인은 발검 시작에 기존 자유 손의 공통 자세와 방향을 사용하여 손의 옆면이 보이고, 카메라에서 멀어 손이 작으며 팔꿈치의 기본 곡선이 손목 축과 다른 방향을 향하는 것이었다.

수정: `godot-game/scripts/player.gd`의 꺼내기 시작 구간에서 카메라 거리와 위치, 손등 방향을 조정했다. 네 손가락의 세 마디를 각각 다른 값으로 굽히고 엄지는 거의 열린 상태로 유지했다. 이 손의 전완을 손목 축에 연결하고 위팔 0.34m/전완 0.26m 길이를 유지했다. 스케일 변형이나 공용 모델·재질 파일 변경은 없다. 이후 검을 쥔 손, 발검 궤적, 공격·가드 모션은 유지한다.

같은 테스트룸 `영상 참고 검·방패 꺼내기`에 반영했고 설명을 갱신했다. `reference_equipment_draw_test.gd`에는 카메라를 향하는 손등 방향, 전완과 손목의 연결 방향, 구간 전체의 두 팔 마디 길이 검사를 추가했다. 기존 장착 이벤트, 일시정지, 가방 변경, 공격·가드 전환, 재질 복원 검사와 테스트룸 반복·원정 복원 검사도 통과했다. 테스트룸 종료 시 기존 ObjectDB 2개 경고는 남는다.

검증은 Mac의 숨김 Vulkan 렌더와 헤드리스 검사로 수행했다. 현재 열려 있는 사용자 게임 창은 재시작하지 않았다. 렌더는 실제 프로젝트 모델·플레이어 코드를 사용하는 격리 시험 장면이며, 모든 동굴 조명 및 직접 조작 체감은 미확인이다. 서로 다른 손·장갑 모델이므로 사진과 픽셀 단위로 같다고 주장하지 않는다.

최종 실제 렌더: `godot-game/artifacts/visual_qa/reference_sword_motion/reach_hand_final/`. 60fps 109프레임의 발검 모션과 MP4 재디코딩 확인을 완료했다. `reaching_hand.png`는 손이 펼쳐진 실제 0.133초 프레임이며 `hand_comparison.jpg`는 첨부 사진·수정 전·수정 후 비교다. 원본 데이터와 원정·커서 상태 보존 검사가 통과했다.
