# 물약 마개 열기 양팔 높이

병과 양손 준비 위치를 `(0.06, -0.12, -0.25)`에서 `(0.06, -0.18, -0.30)`으로 조정했다. 카메라 기준 6cm 낮추고 5cm 멀리 두어 낮춘 병도 보이게 했다. 왼손 진입의 위쪽 오프셋을 10cm에서 3cm로, 마개를 들어 빼는 이동을 6.2cm에서 4cm로 줄였다.

왼팔꿈치를 몸 옆 아래에 두고 손목 회전과 분리해, 마개를 돌릴 때 소매가 카메라 쪽으로 솟지 않도록 했다. 손·팔 메시를 숨기거나 분리하지 않고 기존 연결된 리그를 사용한다. 음용 중 입 위치와 병 각도, 마개·병 파지, 액체 감소, 6.6초 사용과 소비·회복은 유지한다.
