# 검·방패 꺼내기 — 2026-09-12 Mac 제작

참고 영상 sU7jk2OQlgc의 실제 로컬 영상을 디코딩해 3.300–5.300초 구간을 확인했다. 관찰 자료는 `asset-staging/reference_equip_motion_20260912/reference_draw.jpg`에 보존했다. 오른손이 아래쪽 손잡이를 찾고, 화면 아래에서 검을 비스듬히 뽑아 수평에 가깝게 지나간 뒤 세우며 방패가 뒤따라 낮은 왼쪽 대기로 올라오는 순서를 반영했다. 보이지 않는 칼집의 실제 위치나 원본 뼈대를 복원한 것은 아니다.

## 적용

- Mac Blender 5.2.1에서 1.5초 `equip` 클립을 120Hz로 제작했다. 검·방패 및 오른팔 관절을 기존 모션 자료에 추가했으며 앞선 대기·걷기·달리기·점프·세 베기 9개 클립은 변경하지 않았다.
- 실제 가방의 검 장착 이벤트에 연결했다. 방패만 추가할 때는 방패만 들며, 다른 아이템 수량 변경으로는 동작이 재시작하지 않는다.
- 꺼내기 시작의 손 뻗기는 기존 관절 손을 사용한다. 이 구간에만 해당 오른손 인스턴스에 갈색 장갑 재질을 적용하며, 화면 아래에서 원래 검을 쥔 손으로 전환한 뒤 임시 재질은 복구한다. 기존 모델·공유 재질 파일을 수정하지 않았다.
- 공격과 가드는 발검을 중단하고 실제 직전 자세에서 기존 전투 동작으로 연결한다. 타격 시간·소모량·카메라 시야는 바꾸지 않았다.
- F2 → 기본 → `영상 참고 검·방패 꺼내기`에서 동일한 실제 동작을 반복한다. 원정 격리, 일시정지, 초기화·종료 후 원정 복원을 유지한다.

## 검사와 확인 범위

자동 검사 5종: `reference_equipment_draw`, `reference_sword_motion_test_room`, `reference_sword_motion`, `sword_shield_choreography`, `first_person_motion_test_room`. 검사 로그는 이 폴더에 보존했다. 방패 위팔의 꺼내기 중 최대 길이는 약 0.481m이며 손과 장비의 접촉·오른팔 0.34m/0.26m 길이 조건을 통과했다. 기존 테스트룸 종료 시 ObjectDB 2개 경고는 남아 있다.

실제 렌더는 Mac embedded Vulkan에서 현재 프로젝트의 플레이어·모델·전투 코드를 사용했다. 현재 열려 있는 게임 창은 재시작하거나 조작하지 않았다. 모든 던전 조명과 직접 조작 체감은 미확인이다. 참고 영상과 동작 순서·방향을 맞춘 제작물이며 원본 애니메이션의 프레임별 완전 일치를 주장하지 않는다.

최종 검토 영상: `godot-game/artifacts/visual_qa/reference_sword_motion/equip_verified/motion_review.mp4`. 실제 Vulkan 60fps 렌더 109프레임이며, 인코딩 후 109프레임을 다시 디코딩해 확인했다. 최종 동작별 이미지와 원본 비교 이미지를 직접 열어 확인했다. 캡처 중 원본 파일·원정·커서 상태 보존도 통과했다. 1차·2차 캡처는 별도 폴더에 보존하며 최종은 `equip_verified`다.
