# 검을 잡기 위한 손가락 준비 동작 · 2026-09-12

고정되어 있던 발검 준비 손가락을 실제 Skeleton3D 관절 애니메이션으로 변경했다. 처음 0.09초 동안 살짝 펴고, 0.105초부터 새끼·약지·중지·검지 순으로 감는다. 엄지는 0.185초부터 따라온다. 각 손가락은 뿌리·중간·끝마디가 차례로 이어지며 서로 다른 최종 각도를 사용한다. 원본 메시의 기본 굽힘에 추가되는 각도이므로 과도한 회전을 제한했다.

첫 렌더에서 손이 너무 빨리 내려가 감기는 과정이 잘 보이지 않았다. 내려가기 시작을 0.14초에서 0.20초로 늦추고 0.42초에는 화면 아래에 도달하도록 조정했다. 전체 1.5초 발검, 기존 무기를 쥔 손과 검의 연결, 공격·가드 전환은 유지한다.

변경 파일: scripts/player.gd, scripts/test_room_catalog.gd, tests/reference_equipment_draw_test.gd, README.md, TEST_ROOM.md. 기존 원본 메시, Blender 파일, 왼손/방패 자세, 모션 클립 데이터는 변경하지 않았다. baseline과 final에 수정 전/후 핵심 파일을 보존했다.

검사: reference_equipment_draw 및 reference_sword_motion_test_room 최종 2건 통과. 실제 손 관절의 펴짐·감김·순서·엄지 지연·일시정지·재생 속도 독립성을 검사했고 실제 장착 신호, 손-검 고정, 공격/가드 중단, F2 재시험 및 원정 복원 회귀도 통과했다. 기존 테스트룸 종료 시 ObjectDB 2건 경고는 남아 있다.

실제 Mac Apple M4 Vulkan Forward+ 렌더 109프레임 확인. 최종 산출물: godot-game/artifacts/visual_qa/reference_sword_motion/draw_finger_anticipation_final/. finger_sequence.jpg 및 draw_sequence.jpg를 직접 열어 초기 손가락 변화와 화면 밖에서 검 잡기로 이어지는 흐름을 확인했다. finger_motion_review.mp4는 정상 속도 109프레임 후 첫 29프레임을 4회씩 반복한 0.25배속 검수 구간이며 225프레임을 인코딩 후 다시 디코딩해 검증했다. 생성 이미지나 보간 프레임을 사용하지 않았다.

캡처 중 프로덕션 소스 변경 없음, 원정과 마우스 상태 보존, manifest failures 없음. 검증은 실제 플레이어 코드를 사용하는 별도 시험 장면으로 수행했다. 사용자가 열어 둔 게임 창 재시작 및 해당 창에서의 수동 조작은 미실행이다.

F2 → 기본 → 영상 참고 검·방패 꺼내기에서 재생한다.
