# 발검 손이 사라지는 지점의 우측 미세 조정

준비 손 경로의 시작점은 유지하고 목적지를 0.10m 오른쪽으로 당겼다. 이동 중 오른쪽 보정이 점진적으로 적용된다. 검을 쥔 초기 위치는 0.10m, 올라오는 첫 위치는 0.08m, 중간 위치는 0.03m 오른쪽으로 옮겨 기존 대기로 연결했다. 이동 시간, 위아래 경로, 손가락 동작, 다른 9클립 및 방패 트랙을 유지했다. Mac Blender 백그라운드 실행으로 별도 iteration_edge_inset 산출물을 만들었으며 수동 편집 원본은 보존했다.

자동 검사 3건 통과: reference_equipment_draw, reference_sword_motion_test_room, reference_sword_motion_data. 손바닥 화면 좌표 검사를 왼쪽 가장자리보다 조금 안쪽을 통과하는 기준으로 갱신했다. 기존 테스트룸 종료 ObjectDB 2건 경고는 남아 있다.

실제 Mac Vulkan 렌더 109프레임 통과. inset_comparison.jpg를 직접 열어 0.283/0.300/0.317초에 기존 위치보다 조금 오른쪽에서 손이 아래로 사라지는 모습을 확인했다. 특히 마지막 손끝이 기존에는 왼쪽 경계에서 잘렸고, 수정 후에는 조금 안쪽의 하단에 보인다. 실제 프레임만 사용한 정상+느린 검수 영상 285프레임 인코딩/디코딩 확인. 원정/커서 보존, 소스 변경 없음, failures 없음.

기존 사용자 게임 창 재시작 및 그 창에서의 수동 입력은 미실행이다. F2 → 기본 → 영상 참고 검·방패 꺼내기에서 확인한다.
