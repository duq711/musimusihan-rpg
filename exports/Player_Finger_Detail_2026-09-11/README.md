# 손가락별 독립 기준과 피부·손톱 디테일

이미지 한 장에는 손가락 하나의 한 면만 담는다. 엄지·검지·중지·약지·소지의 손톱 면(dorsal)과 지문 면(palmar), 총10장의 독립 이미지를 내장 `image_gen`으로 생성했다. `reference/individual/`에 원본 PNG, 정확한 생성 프롬프트 `prompts.json`, 생성 방식·원본 위치·SHA `generation_record.json`을 보존한다. 최초 합성 시트는 `reference/superseded/`에 이력으로만 남겼으며 현재 비교 기준으로 쓰지 않는다.

기존 `player_hands_proportions_20260911`의 장갑 손을 출발점으로 삼아, 다섯 손가락의 노출 피부를 국소 조형하고 세 4K PBR 맵에 피부결·마디 주름·지문 루프·손톱 세로결을 베이크했다. 마디·패드 조형의 최대 변위는 약 0.62mm다. 원래 장갑·소매·봉제선·전체 손 비례·16본의 기본 자세·가중치·UV는 보존한다. 이전 제작·납품 111개 파일은 `baseline/preserved_previous.json`의 SHA로 보호한다.

`iteration_08`에서는 엄지 손톱을 약 25.6mm에서 19.0mm로 줄이고, 실제 손가락 중심으로 약 1.1mm 이동했다. 손끝 간격은 약 4.37mm에서 3.10mm로 줄이고 아래 피부에 맞춰 손톱을 밀착시켰다. 그러나 다른 네 손가락과 같은 쪽을 향하던 엄지 손톱의 방향은 이 수정으로 해결되지 않았다.

`iteration_09`의 ±75° 회전은 기존 손톱 면의 약 20° 기울기와 합쳐져 다른 네 손톱 면에 대한 각도가 약 95.8°로 직각을 넘었다. 이 후보는 방향이 지나치게 돌아가 채택하지 않았다.

최신 사용자 지적에 따른 `iteration_10` 후보는 엄지의 실제 길이 축을 중심으로 피부와 손톱을 함께 돌린다. 왼손은 +60°, 오른손은 −60°를 적용해 엄지 지문 면이 손 안쪽을, 손톱 면이 바깥쪽을 향하도록 수정한다. 이 축 회전에 따른 정점 이동은 앞선 최대 약 0.62mm의 국소 조형과 별도로 측정한다. 15관절 보정 형상의 엄지 정점 벡터도 해당 회전에 맞춰 변환하며, 뼈의 기본 자세·가중치·UV와 나머지 네 손가락은 유지한다. 손톱의 322정점과 끝마디 고정 가중치, `iteration_08`의 세 4K 맵을 재사용한다.

## 실제 비교와 반복

각 면의 실제 Blender 렌더를 동일한 카메라·조명으로 생성한다. 수정 전10장은 `baseline/individual_renders/`, 후보별 수정 후10장은 각 `mac_output/iteration_*/individual/`에 따로 저장한다. 엄지 손톱은 추가 사선·옆면 실제 렌더로 들뜸을 확인한다. 합성 비교판을 사용하지 않는다.

`iteration_review.json`에는 저장 실패, 거친 피부 요철, 규칙적인 격자·마디 무늬, 손톱 들뜸을 발견하고 수정한 과정을 기록한다. 새 이미지가 메모리에만 있고 저장 파일에는 옛 packed 이미지가 남는 Blender 동작을 확인해, 새 PNG를 다시 읽어 pack하고 실제 파일 SHA·전체 픽셀을 대조하도록 고쳤다. 피부/장갑 UV 경계의 bake margin 번짐도 제거했다. 가까운 피부 seam 정점은 같은 변위를 공유하여 새 면 교차를 막는다.

현재 적용본은 `mac_output/iteration_10/`이다. 실제 엄지 손톱 면은 다른 네 손톱과 왼손 81.75°·오른손 81.67° 차이를 이룬다. 이 파일을 다시 열어 독립 Blender/GLB·PBR 픽셀·관절·80개 손톱 부착 검사를 통과했고, Godot 헤드리스 7개와 숨김 Vulkan 렌더 18장도 통과했다. 실제 렌더를 모두 직접 확인했으며 원정·가방·커서 복원도 유지된다. `validation_summary.json`은 검사 종합 기록, `package_verification.json`은 별도 납품 ZIP 검증 기록이다. 게임에서는 같은 상세 손과 15마디 테스트룸 항목을 사용한다.

## 산출물과 범위

납품 폴더에는 편집 가능한 양손 `.blend`, 좌우 `.glb`, 세4K 맵, 독립 기준10장과 프롬프트, 수정 전후 각각10장, 엄지 사선·옆면, 실제 게임 캡처와 검증 기록을 포함한다. 파일은 `exports/Player_Finger_Detail_2026-09-11/`에 별도 보존한다. `.blend`와 GLB는 텍스처를 내장한다.

생성 사진은 디테일 참고용이며 포토그래메트리 복원이 아니다. 기존 굽힘 자세와 게임용 메쉬 실루엣이 남고, 미세결은 대부분4K 법선·거칠기 맵으로 표현한다. 개별 사진의 모든 주름을 그대로 복제하거나 사진과 픽셀 단위로 일치한다고 주장하지 않는다. 손톱 부착 검사는8개 자세에서 실제 끝마디 피부를 대상으로 하며 주먹 전체의 모든 연속 충돌을 증명하는 검사는 아니다. 제작 도구는 이 프로젝트의 원본·검증 지원 스크립트를 함께 사용하는 재현용 소스이며, 납품된 모델 자체는 내장 텍스처로 독립적으로 열린다.

이 양손 작업에 이미 허용된 Mac Blender5.2.1 LTS 백그라운드 실행을 사용했다. localhost:9876 MCP 연결은 응답하지 않아 실제 설치된 Blender CLI로 진행했다. 창·포커스·커서·소리를 건드리는 인터랙티브 검증은 사용하지 않는다.
