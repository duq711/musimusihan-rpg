# 플레이어 손목 연결부 정리

2026-09-11. 기존 양손 디테일·마디별 관절 모델의 후속 제작본입니다. 실제 Blender 5.2.1 LTS를 Mac에서 백그라운드로 실행해 제작했습니다.

- `bilateral_hands_wrist_refined.blend`: 편집 가능한 양손 원본, 중립 검토 장면.
- `left_hand_wrist_refined.glb`, `right_hand_wrist_refined.glb`: 게임용 좌우 독립 모델. 각각 63,970삼각형·9메시·16본·15개 관절 교정 형상.
- `wrist_dorsum_before.png`, `wrist_dorsum_after.png`: 같은 카메라·조명·자세의 수정 전후 비교.
- `wrist_*.png`: 손등·손바닥·옆면 및 굽힘 확대 렌더. 실제 모델 렌더이며 이미지 생성이나 합성은 사용하지 않았습니다.
- `build_report.json`, `verification_report.json`: 제작 및 독립 Blender 검증 근거.
- `tools/`: 제작·검증·비교 렌더 Python 소스. 기존 프로젝트의 원본 경로를 입력으로 사용합니다.

손목의 벌어진 형태와 튀어나온 정점을 정리하고 전완 보호대의 끝을 짧게 맞췄습니다. 새 얇은 연결부는 두 끝을 둥글게 마무리했습니다. 기존 손가락·손톱·웨이트·16본 기준 자세와 전완 native z≥0.100m 영역은 그대로 보존했습니다. 손목 변경 정점은 왼손1,540개·오른손1,543개이며 기존 15개 교정 형상의 상대 변화량은 오차0입니다.

게임에서는 `WristCuff`의 `wrist_flex_version=1`, `.014–.075m` 메타데이터를 읽어 연결부의 손 쪽 끝을 고정하고 팔 쪽 끝은 실제 전완 변환에 붙입니다. 실제 손목 본을 팔 맞춤 기준으로 삼고 중심 경로와 단면을 함께 회전시킵니다. 큰 굽힘에서는 안쪽 면만 완만하게 눌리며 바깥 윤곽과 굽힘에 수직인 폭을 유지합니다. 표면 법선과 접선도 실제 변형에 맞춰 갱신합니다. 이 동적 팔 맞춤은 Godot 런타임 동작으로, GLB에 새 팔 애니메이션 클립을 베이크한 것은 아닙니다. Blender의 굽힘 이미지는 초기 단면 변형을 이용한 제작 과정의 형상 검토입니다. 최종 런타임은 실제 손목 기준점과 안쪽 탄성 변형을 추가했으며, Godot 캡처가 최종 게임 표시의 근거입니다.

테스트룸 → 기본 → **캐릭터 그래픽 · 손가락 마디별 관절**에서 **손목 옆면**을 선택해 확인합니다. 15개 마디 조절과 손등·손바닥 보기, 실제 상세 손의 활·상자 동작에도 같은 모델을 사용합니다. 기존 게임 외형 선택 방식과 이전 원본 납품본은 보존합니다.

재질은 형태 검토용 중립 회색 5종입니다. 새 컬러 텍스처·노멀맵 베이크는 이번 범위에 포함하지 않습니다. 최종 Godot 검사와 실제 렌더 근거는 `validation_summary.json`, `validation/`, `godot_preview/`에 기록합니다.

최종 검증: 관련 자동 검사 **7개 통과**, 실제 Godot 화면 **16장 검토**, GPU 위치 오차0m·잘못된 법선/접선/접힘0. 원정·인벤토리·커서 복원과 원본328개 해시 보존을 확인했습니다. 상세 결과 및 비실패 경고는 `validation_summary.json`에 있습니다. `runtime_snapshot/`은 기존 Godot 프로젝트에 연결된 수정 파일의 보존본으로 독립 실행 프로젝트는 아닙니다.
