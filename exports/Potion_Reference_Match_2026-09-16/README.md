# 물약 입 위치와 참고 구도 재수정

이전 결과의 입구 목표는 눈높이에 가까웠다. 참고 이미지처럼 큰 병 몸통이 화면 아래 중앙에 남도록 입구를 시점보다 15cm 아래·3.5cm 앞에 고정했다. 병을 기울이며 손목을 병 축 기준 약 20도 함께 돌려 옆면을 감싸는 파지를 유지한다. 오른손은 기존 병 몸통 파지를 사용하며 소매를 연속 연결하고 팔꿈치는 화면 밖으로 보낸다.

기울기는 약 125~134도로 변하고 네 번의 작은 삼킴 움직임이 더해진다. 마개 열기·액체 감소·6.6초 사용 시간·완료 시 소비와 회복은 유지한다. 액체는 기존 메시 절단 표현이며 유체 시뮬레이션은 아니다.

## 확인

- `final_motion_test.log`: 실제 카메라 기준 병 입구가 눈·코 아래이고 화면 하단 밖에 있는지, 병 바닥이 입구 위인지 확인. 기존 파지·마개 접촉·재파지·입구 고정·액체 감소·소비·회복·취소·원정 복원 검사 통과.
- `final_test_room.log`: 카탈로그와 실제 물약 동작, F/F2 취소·반복·회복·초기화·원정/가방/커서 복원 통과.
- `final_capture.log`: embedded Vulkan에서 본편 219프레임 실제 렌더 통과. 창·OS 포커스·입력·소리를 사용하지 않았고 실행기는 시작한 검증 프로세스 종료까지 기다려 정상 종료했다.
- `manifest.json`: 진단 모드가 아닌 본편 모드, 촬영 중 소스·상태 보존, 실제 완료 검사 통과. 8개 제작 소스 해시가 최종 게임 파일과 일치한다.
- 열기·입으로 가져가기·음용 초/중/후반·빈 병 프레임을 직접 검토했다.

`study*.jpg`와 `reference_study_*`는 손·병 자세를 고르기 위한 진단 자료다. 최종 영상과 구분해 보존한다. 변경 전 코드·프리뷰·시험은 `before*.gd`에 보존했다.
