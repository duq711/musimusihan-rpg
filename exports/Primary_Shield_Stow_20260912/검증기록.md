# 주무장 1번 방패 수납 · 2026-09-13 검증

구현 범위는 사용자의 우선 지시인 검·방패를 든 상태에서 1번으로 방패를 수납하는 동작이다. 전체 주무장 1개/부무장 2개 및 비무장→주무장 꺼내기 입력 연결은 기획에 기록했으며 아직 구현하지 않았다. 검만 든 상태에서 추가 1번은 변화가 없고, 실제 장비 재장착 및 테스트룸 재선택으로 방패 준비 상태를 복원한다.

primary_weapon 기본 물리키 1을 등록하고 검을 든 상태에서 기존 주문 선택보다 먼저 처리한다. 안전지역·메뉴·상자·사망·야영·함정·공격 중 요청을 막으며 꺼내는 도중과 수납 후 연타는 재생을 재시작하지 않는다. 0.55초 동안 실제 방패와 손잡이를 쥔 왼손을 왼쪽/뒤쪽으로 이동하고 회전시킨 뒤 숨긴다. 기존 검을 든 자세와 검 공격은 유지한다.

방패 물품/인스턴스는 인벤토리에 남아 있으며, 손에 들지 않은 상태는 별도 플레이어 상태로 관리한다. 수납 시작과 동시에 방패 가드를 해제한다. 실제 공격을 받은 시험에서 방패가 장착 목록에 있어도 완전 방어 대신 기존 검 방어의 피해 4/20이 적용됨을 검증했다. 기존 검 방어 피격 안내의 방패 문구도 무기로 정정했다. 방패를 내렸다고 횃불을 자동으로 꺼내지 않으며 명시적인 F 입력은 기존대로 사용할 수 있다.

F2 → 기본 → 주무장 1번 · 방패 수납을 같은 실제 플레이어 동작에 연결했다. 각 장비 시험 시작 시 수납 상태를 복원하여 다른 시험에 숨김 상태가 남지 않게 한다. 반복·정지·초기화·원정 복원 시험 포함.

자동 검사 고유 4종 통과: primary_shield_stow, reference_equipment_draw, reference_sword_motion_test_room, shield_guard. 확장된 shield_guard에서 실제 수납 방패의 피격 판정을 추가 확인했다. 기존 테스트룸 종료 ObjectDB 2건 경고는 남아 있다.

실제 Mac Vulkan Forward+ 렌더 61프레임 캡처 완료. 최종 shield_stow_sequence.jpg를 직접 열어 0~0.20초에 방패 테두리가 왼쪽으로 빠지고 0.27초 이후 검만 남는 흐름을 확인했다. 손잡이 접촉/왼손 동행은 실제 리그 좌표 검사로 확인했다. 최종 캡처는 원정/커서 보존, 소스 변경 없음, failures 없음. shield_stow_review.mp4는 실제 프레임의 정상 재생과 반복을 이용한 0.25배속 구간이다. 실제 OS 키 입력 주입 및 사용자의 기존 게임 창 재시작은 하지 않았다.

수정한 프로덕션/검증/기획 문서 사본과 해시를 final/ 및 source_hashes.json에 보존했다. 기존 Blender·모델 에셋과 발검 클립은 변경하지 않았다.
