# 나무 막대·붕대 부목

[사용자 참고 영상 31초 이후](https://www.youtube.com/watch?v=sjPpfdlupx4&t=31s)의 배치·감기·끝 눌러 고정을 기존 게임의 왼팔 치료에 맞춰 반전했다. 이전 버클형 부목 대신 단순 나무 막대 하나를 손목·전완 아래에 받치고 붕대를 세 번 감는다.

- `wood_support.blend`: 편집 가능한 Mac Blender 원본.
- `wood_support.glb`: 단일 나무 메시와 내장 나뭇결 텍스처.
- `splint_use_visuals.gd`: 현재 게임의 기존 손 리그·붕대 기반 클래스를 사용하는 7.2초 애니메이션. 독립 캐릭터 GLB 애니메이션이 아니라 실제 Godot 플레이어에서 재생되는 동작이다.
- `splint_wrap_preview.gif`: 실제 게임 렌더로 만든 미리보기.
- `splint_wrap_contact_sheet.png`: 주요 단계의 실제 화면.

실행: **F2 → 생존 → 부목 사용 · 왼팔 고정**. 본편 건강 화면에서도 왼팔에 나무 부목을 사용하면 재생된다. 7.2초가 끝나면 부목 1개 소비와 골절 해소가 적용되고 F로 취소하면 소비·치료하지 않는다. 붕대는 부목 구성품이며 별도 붕대 아이템을 소비하지 않는다.

기존 의상·손 모델을 유지하며 현재 모션은 왼팔용이다. 완료 후 영구 착용은 추가하지 않았다. 기존 버클형 산출물은 `../Splint_2026-09-15/`에 제작 이력으로 보존한다.

검증 근거: 프로젝트 `asset-staging/splint_wrap_20260915/output/validation_summary.json`. 전체 건강 시험의 은신처 전환 시간 초과와 부목 전용 검증 결과를 구분한다.
