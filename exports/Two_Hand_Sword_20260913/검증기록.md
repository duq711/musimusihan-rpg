# 방패 수납 후 검 양손 파지

사용자 요청: 방패를 넣은 왼손이 검을 잡도록 연결.

1번 입력으로 방패와 왼손을 함께 왼쪽으로 수납하는 기존 0.55초 동작 뒤, 같은 왼손 에셋으로 만든 독립 파지 리그가 0.48초 동안 돌아온다. 손잡이에 접근할 때 손가락을 펴고, 마지막 구간에서 닫는다. 검 로컬 좌표 (0, -0.235, 0.002)에 왼손 접촉점을 두어 오른손 아래를 잡는다. 검을 약간 중앙 위로 옮겨 양손이 보이게 했다. 원본 검·오른손 메시와 Blender 파일은 수정하지 않았다.

왼손의 팔꿈치는 몸 쪽을 향하도록 고정 길이 관절 계산을 사용한다. 최초 시험에서 검의 회전을 그대로 팔꿈치 방향에 사용하면 공격 시 팔이 카메라를 가로질렀으므로 이 방식을 교정했다. 기존 방패 모델의 실제 왼손·손가락 관절·재질을 재사용하며, 검 아래쪽 연장 손잡이에 맞는 접촉면을 왼손 인스턴스에만 적용한다.

주요 변경 파일:
- godot-game/scripts/player.gd: 수납 후 복귀/파지, 검 추종, 팔 관절 계산, 가시성 및 진단 상태.
- godot-game/scripts/sword_shield_arm_visual.gd: 긴 손잡이의 아래쪽 파지 접촉면. 기본 방패/오른손 설정은 유지.
- godot-game/scripts/test_room_catalog.gd, test_room.gd: 기존 `motion_shield_stow` 시험 설명 및 실제 양손 파지 연결.
- godot-game/tests/primary_shield_stow_test.gd: 실제 1키, 수납, 양손 접촉, 공격 중 추종, 장비 보존, 재장착, 일시정지, 세션/커서 보존 검사.
- godot-game/tests/reference_sword_motion_test_room_test.gd: 실제 시험에서 수납 후 양손 파지와 재시험 확인.
- godot-game/tests/reference_sword_motion_preview.gd: 창을 열지 않는 실제 Vulkan 렌더링에 양손 수납/달리기/점프/기본 베기 검수 추가.
- README.md, TEST_ROOM.md, design/GAME_DIRECTION.md: 새 동작과 사용자 후속 결정 반영.

자동 검사 기록:
- tests.log: primary_shield_stow, reference_sword_motion_test_room, shield_guard, reference_equipment_draw 4개 통과.
- tests_final_pose.log: 최종 손/팔 조정 후 primary_shield_stow 재검사 통과.
- 기존 테스트룸/방패 검사 종료 시 ObjectDB 2개 잔존 경고가 출력됨. 테스트 판정은 통과했으며 이번 작업에서 관련 원인은 수정하지 않음.

범위 및 한계:
- 공격력·기력 소모·방패 판정과 기존 공격 종류 제한은 변경하지 않았다. 기존 규칙에 따라 방패 수납 후에는 기본 베기를 사용한다.
- 시험용 바닥 위에서 실제 게임 플레이어·물리·재질·렌더러를 실행했다. 사용자가 켜 둔 게임 창을 재시작하거나 OS 키보드·마우스를 조작한 검증은 하지 않았다.
- 손가락마다 모든 표면의 관통을 수치로 전수 검사한 것은 아니다. 접촉점 추종/팔 길이 자동 검사와 실제 렌더링의 외관을 확인한다.
- 전체 주/부무장 슬롯 개편과 비무장 상태의 1번 발검은 이전과 같이 별도 후속 범위다.

실행: F2 → 기본 → 주무장 1번 · 방패 수납 → 1. 다시 시험을 선택하면 검·방패 상태로 복원된다.

최종 실제 렌더링: `godot-game/artifacts/visual_qa/reference_sword_motion/two_hand_sword_verified/`. 4개 동작, 총 344프레임. 실패 항목 없음. 원정·커서 보존 및 캡처 중 소스 무변경 확인. `two_hand_sword_review.mp4`는 실제 렌더링 프레임을 60fps로 연결한 영상이며, 생성 이미지나 합성 손으로 대체하지 않았다.
