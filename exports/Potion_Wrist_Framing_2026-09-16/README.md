# 물약 손목 중심 구도

마개를 여는 병 위치를 카메라 기준 `(0.10, -0.13, -0.42)`에서 `(0.06, -0.12, -0.25)`로 당겼다. 왼팔의 연결된 소매가 손목 방향을 따라 화면 밖까지 이어지도록 팔꿈치 목표 거리를 조정했다. 소매를 숨기거나 손을 분리하지 않는다. 손가락 파지·마개 회전·다시 잡기·6.6초 사용 시간·음용 시 입구 위치는 유지한다.

## 검증

- `potion_motion`: 실제 손가락-마개 접촉, 재파지, 병 파지, 음용 시 입구 위치, 액체 감소, 완료와 취소 검사 통과 (`tests_01.log`).
- `potion_test_room`: 카탈로그, 실제 실행, F/F2 취소, 반복, 회복, 초기화, 원정·가방·커서 복원 통과 (`test_room.log`).
- 창·포커스·입력·소리 없이 embedded Vulkan으로 본편 모션 219프레임 촬영 완료 (`capture_01.log`). 실행기는 자신이 시작한 프로세스 종료를 기다려 정상 종료했다.
- 실제 열기 주요 9개 시점과 회전 끝·음용·빈 병 프레임을 직접 확인했다. 왼팔꿈치는 화면 밖에 있고 소매 끝과 손목이 연결된다.
- `manifest.json`의 8개 제작 소스 해시가 최종 게임 파일과 일치하며, 촬영 중 원정 상태·소스 보존과 사용 완료 검사가 통과했다.

기존 모션을 가까이 배치한 16:9 시점 검증이다. OS 하드웨어 입력 검증이나 유체 시뮬레이션 검증을 의미하지 않는다.
