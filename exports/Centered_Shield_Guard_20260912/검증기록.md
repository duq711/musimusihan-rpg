# 중앙 방패 가드

기존 가드의 위치(-0.27, -0.12, -0.49)와 크게 돌아간 각도(24.62°, 66.04°, 20°)를 화면 아래 중앙의 위치(0, -0.52, -0.65), 정면에 가까운 각도(8°, 0°, 0°)로 수정했다. 검·방패 조합과 다른 방패 장착 경로가 공통 가드 자세를 사용한다. 기존 양손 낮은 대기 자세는 유지한다. Blender 원본, 재질, 방패 크기, 카메라 시야각은 수정하지 않았다.

- first_person_motion_test_room 통과: 실제 방패 장착·중앙 위치/정면 방향·공격·가드·피격·해제·재시험·F2·원정 복원.
- 실제 Vulkan 렌더 8장 통과: 대기, 걷기, 달리기, 올리기 중간, 완전 가드, 피격, 내리기 중간, 복귀. `godot-game/artifacts/visual_qa/centered_shield_guard/`에 보존. 가드·중간 전환·충격 화면 직접 검토.
- 실제 사용자 게임 창은 재시작하지 않았다. 게임 코드와 자산을 사용하는 독립 시험 화면으로 확인했다.
- 과거에 기록된 전체 검 모션의 기존 검사 오류까지 해결한 작업은 아니다.
