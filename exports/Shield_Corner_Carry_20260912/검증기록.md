# 방패 모서리 대기 자세

게임의 방패 기본 위치를 카메라 기준 왼쪽 23cm, 아래 40cm로 옮겼다. 투명도, 방패 크기, 카메라 시야각, 오른손 검, Blender 편집 파일은 변경하지 않았다. 방어 진행에 따라 위치 보정을 해제하며 완전 방어 자세는 원래 위치다. 영상 기반 공격은 기존 자세 전환으로 이어지고, 보행·달리기는 각 동작을 계산한 뒤 모서리 위치를 적용한다.

변경: `godot-game/scripts/player.gd`, 테스트룸의 기존 `motion_shield_raise` 설명·안내, 관련 검증과 문서. 현재 열려 있는 Blender 파일의 미저장 사용자 편집은 유지했다.

검증:
- first_person_motion_test_room: 통과. 실제 시험장 방패 장착, 낮은 대기 위치, 방어 시 보정 해제, 반복 방어/해제, F2·초기화·원정 복원 포함.
- 입력 없는 Vulkan 프리뷰: 대기·걷기·달리기·방어·방어 해제 이미지 및 원정/커서 복원. 실제 플레이어 코드와 게임 자산 사용.
- sword_shield_choreography: 기존 실패 남음. 수정 전 1955개, 최종 1947개 오류. 숫자를 제외한 오류 유형 비교에서 추가 유형 없음. 상단 내려베기 복귀·소매 연결 등의 기존 오류가 있어 전체 모션 검증 통과로 간주하지 않는다. 기존 방패 위팔 최대 길이 실패 수치 1.114651m는 최종에서도 동일.
- reference_sword_motion: 수정 전에도 timing 메타데이터 오류 및 자세 전환 검증 실패가 있었다. 전체 참고 모션 검증 완료로 보고하지 않는다.

실제 게임 플레이 창의 재시작이나 사용자 입력 조작은 하지 않았다. 검수 이미지는 게임의 실제 렌더러를 사용하는 독립 시험 화면이다.
