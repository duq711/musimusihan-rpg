# 화면 왼쪽 끝에서 발검

이전 경로는 왼쪽 끝에 닿기 전에 아래로 사라졌다. 좌측 이동 폭을 늘리고 초기 하강을 완만하게 만들어 손이 왼쪽 가장자리에 보인 채 도달하도록 수정했다. 좌우/상하 좌표는 중간 정지 및 역행 없이 진행한다. 검의 초기 그립과 출현 위치도 같은 왼쪽 가장자리로 연결했다. 이동 시간·손가락 동작·최종 대기, 다른 9클립과 방패 트랙은 보존했다.

Mac Blender 5.2.1 LTS 백그라운드 제작 완료. author_equip_left_edge.py / iteration_left_edge/에 별도 저장. 사용자가 연 수동 편집 Blender 파일은 건드리지 않았다.

실제 손바닥 화면 좌표가 화면 하단 아래로 사라지기 전에 좌측 10% 영역에 도달하는 검사 추가. 손목의 지속 좌하향 이동과 검의 왼쪽 출발 위치, 손가락 변화, 중단/정지/테스트룸/원정 복원 포함 자동 검사 3건 통과. 기존 테스트룸 종료 ObjectDB 2건 경고는 남아 있다.

실제 Mac Vulkan Forward+ 109프레임 캡처 통과. finger_sequence.jpg를 직접 열어 0.25초 왼쪽 접근, 0.30초 왼쪽 가장자리에서 손 일부가 잘리는 모습을 확인했다. draw_sequence.jpg에서 왼쪽 발검 후 대기로의 연결 확인. left_edge_draw.mp4 정상 속도+실제 프레임 반복 느린 검수 영상 285프레임 인코딩/디코딩 검증. 생성/보간 이미지 사용 없음. 캡처 소스 변경 없음, 원정/커서 보존, failures 없음.

F2 → 기본 → 영상 참고 검·방패 꺼내기에서 실제 플레이어 동작으로 연결된다. 기존 사용자 게임 창 재시작과 그 창에서의 수동 조작은 미실행이다.
