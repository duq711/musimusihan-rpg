# FP arms 교체 기록 — 2026-09-15

사용자가 제공한 `fp_arms.glb`로 1인칭 팔·손을 교체했다. 원본의 검은 소매, 반장갑, 피부, UV와 스킨 가중치를 사용한다. 3인칭 전신과 무기·UI 디자인은 이 작업의 변경 대상이 아니다.

## 원본과 원인

원본은 `../../asset-staging/fp_arms_20260915/fp_arms_original.glb`, 편집 가능한 결과는 `../../asset-staging/fp_arms_20260915/Game_Arms.blend`, 변환 코드는 같은 폴더의 `build.py`에 보존했다. 일반 Blender 가져오기는 이 파일의 뼈 계층과 inverse-bind의 차이로 뼈 위치가 메시에서 크게 벗어났다. 원본 inverse-bind에서 실제 변형 뼈를 복원하고 좌우를 각각 변환했다. 좌우를 뒤집어 대체하지 않았다. 각 팔은 원본 변형 뼈 20개와 손가락 관절 15개를 사용한다.

## 핵심 변경

- `godot-game/assets/3d/player/fp_arms/`: 좌우 GLB/SCN, 2K 텍스처, 뼈 정보, 출처. SCN에 리소스를 포함해 가져오기 캐시에 의존하지 않게 했다.
- `supplied_fp_arm.gd`: 새 스킨과 뼈대 제어, 팔꿈치·손목 피팅, 손가락 굽힘.
- `player_arm_visual.gd`, `sword_long_grip_visual.gd`, `player.gd`: 일반 손·발검·횃불·활·검·방패·검의 왼손 보조 파지에 새 모델 연결. 기존 검/방패/양손 모션 샘플러와 공격 타이밍은 유지.
- `bandage_use_visuals.gd`, `splint_use_visuals.gd`: 옛 메시 이름 대신 새 팔뚝 프레임 사용. 붕대가 새 소매 주름 바깥을 감싸도록 외곽 반경 보정.
- 테스트룸 기존 1인칭 팔·제공 모델·마디별 관절 항목을 실제 새 모델로 연결하고 관련 검사 갱신.
- 원본 에셋과 이전 코드 `baseline/` 보존. 사용자 원정·가방·커서 복원 검증.

## 확인 범위와 한계

실행 중인 사용자 게임/편집기는 재시작하지 않았다. 새로 실행하면 교체 모델이 로드된다. 게임 자체의 실제 모델·제어 코드로 숨김 렌더와 상태 입력을 검증했으며, OS 키보드/마우스로 조작한 실시간 플레이는 미확인이다. 기존 세부 손 전용 corrective morph는 제공 모델에 없어 옮기지 않았고 실제 뼈 굽힘으로 대체했다. 모든 장비의 손가락 접촉/관통을 전 각도에서 수치 검증하지는 않았다. 부목은 기존 길이와 치료 위치를 유지하며 팔 아래에서 보이는 형태이다. 제작 자료의 Blender 원본은 별도로 보존했다.
