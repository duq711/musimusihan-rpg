# 왼손 펼침 → 주먹

준비 동안 왼손은 자연스럽게 펼칩니다. 2초부터 0.85초 동안 네 손가락을 접고, 엄지는 0.18초 늦게 접어 2.95초에 주먹이 완성됩니다. 이후 마무리까지 유지합니다. 오른손의 재파지와 누르기는 유지합니다.

검증: splint_motion 통과. 235프레임 Vulkan/embedded 촬영, 원정·커서·소스 보존 확인.

- open_to_fist.png: 펼침·전환·주먹
- tests.log, capture.log, manifest.json: 검증 기록
