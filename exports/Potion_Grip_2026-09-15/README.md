# 물약 병 파지 수정

기존 파지는 병 중심을 중지/약지/엄지 관절의 평균에 일치시켜 손가락이 유리 안으로 들어갔습니다. 손가락 뿌리는 펴고 끝마디를 굽힌 전용 자세와 고정된 파지 오프셋을 적용했습니다. 병목을 옆에서 쥐는 방식이며 손목 방향에 팔꿈치를 연결하고 어깨는 몸에 고정합니다.

표면 좌표 2,031개와 병 외곽 반경을 추출하여 후보 파지를 비교했습니다. 계산은 축별 반경 근사이며 모든 삼각형의 충돌을 완전히 보장하지 않습니다. 여러 후보의 수면/병 가림 및 손목 연결을 실제 렌더로 확인했습니다. 최종 grip_08에서 준비·액체 있는 병·빈 병을 확인했습니다. 마시는 중 병 상부는 여전히 손에 가려집니다.

병은 원본 보존 상태에서 런타임 폭/깊이 0.60배, 길이 1.70배로 조정했습니다. 마시는 기울기·카메라 거리도 조정했고 액체 평면의 축별 변환을 반영했습니다. 원본 GLB, 원본 손/팔 에셋은 변경하지 않았습니다.

potion_motion 통과: 새 파지점 추종, 감소하는 액체/출렁임, 소비·회복/취소, 상태 복원. 실제 embedded Vulkan 195프레임 촬영과 상태·소스 보존 확인. 최종 tests_final.log/capture_final.log/manifest.json. 기존 테스트룸의 실제 동작에 함께 적용됩니다. 분석용 진단 스크립트는 테스트 자동 실행 대상에서 분리해 이 폴더에 보존했습니다.
