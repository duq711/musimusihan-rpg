# 사용자 지정 5cm 버전 복원 후 좌측 미세 조정

복원 기준: exports/Reference_Draw_Left_Adjust_20260912/final/ 및 draw_left_adjust_final 실제 렌더. 사용자가 인용한 “손의 이동 경로를 왼쪽으로 약 5cm 더 옮겼습니다” 응답에 해당한다.

player.gd를 해당 기준과 비교한 결과 차이는 준비 손 경로의 시작/끝 X 좌표를 각각 0.02m 왼쪽으로 옮긴 한 줄뿐이다. 이후의 가장자리 가로지르기/완만한 초기 하강을 제거하고 지정 버전의 연속 좌하향 경로와 타이밍을 복원했다. 검 초기/첫 출발 위치도 0.02m, 중간 위치는 0.015m 왼쪽으로 맞췄다. 검 트랙의 회전·Y/Z·시간이 지정 기준과 같은지 전 샘플 비교했다. 다른 9클립과 방패 트랙은 현재 데이터 보존을 검사했다.

Mac Blender 백그라운드 제작 완료. author_equip_rollback_adjust.py 및 iteration_rollback_adjust/ 별도 저장. 현재 상태를 baseline에 백업했으며 사용자 수동 편집 Blender 원본은 건드리지 않았다.

자동 검사 3건 통과: reference_equipment_draw, reference_sword_motion_test_room, reference_sword_motion_data. 실제 손목 연속 좌하향 이동, 손가락 준비, 검 그립, 공격/가드/정지, 테스트룸 반복 및 원정 복원 검사. 취소된 가장자리 도달 조건은 원래 좌하향 조건으로 복원했다. 기존 테스트룸 종료 ObjectDB 2건 경고는 남아 있다.

실제 Mac Vulkan Forward+ 109프레임 캡처 통과. rollback_comparison.jpg를 열어 지정 버전 대비 0.15/0.20/0.60초의 미세 좌측 이동 및 기존 하강 구도 복원을 확인했다. 실제 프레임으로 정상/느린 재생 영상 285프레임 인코딩/디코딩 확인. 캡처 중 소스 변경 없음, 원정/커서 보존, failures 없음. 사용자 게임 창 재시작과 해당 창의 수동 조작은 미실행이다.
