검·방패 양손 편집 파일입니다. N 패널 → 양손 편집에서 오른손/왼손을 선택하세요.
현재 검과 오른손의 동시 이동 연결은 해제되어 있습니다. '검만 선택' 또는 검 표면 더블클릭 후 G/R로 움직이면 손과 팔은 그대로 있고 검만 이동합니다.
검·방패: 장비 표면을 더블클릭하거나 패널에서 해당 장비를 선택하세요. G로 위치, R로 각도를 조절합니다. 선택한 장비만 움직입니다.
마우스 직접 조정: 손가락 표면을 더블클릭하면 해당 마디가 선택됩니다. 색 조절봉은 한 번 클릭해도 됩니다. 나타나는 회전 고리를 드래그하거나 R을 누르고 마우스를 움직이세요. 클릭으로 확정, Esc로 취소합니다.
손가락: 각 마디 회전을 드래그. 손등/손목: 손목 회전. 팔: 위팔과 팔뚝 회전 또는 팔 전체 선택 후 G/R.
손등 표면: 손등 형태 편집 버튼 → 정점 선택 → O 비례 편집 → G 이동, 휠로 범위 조절. Tab으로 마침.
장비는 기본적으로 손을 따라 움직입니다. 장비 고정 버튼으로 검/방패를 고정한 뒤 손만 맞출 수 있습니다.
Ctrl+Z 실행 취소, 시작 자세 복원, Ctrl+S 저장. 현재 게임 원본은 바뀌지 않습니다.
검 쪽은 기존 굳어진 파지에 편집용 관절을 새로 붙였으므로 과한 굽힘은 피하고 자루 관통을 확인하세요.
