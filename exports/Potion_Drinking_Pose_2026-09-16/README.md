# 물약을 입에 대고 마시는 동작 수정 · 2026-09-16

## 변경

- 기존에는 기울기가 90도에 못 미쳐, 병을 아래에 매단 상태로 흔들었다. 이제 2.0–4.65초 음용 중 병 입구를 카메라 아래의 입 위치에 고정하고 바닥이 입구보다 높게 올라가도록 기울인다.
- 병 몸통을 손바닥과 엄지·네 손가락으로 감싸는 전용 관절 자세를 적용했다. 검지는 병목 쪽에 놓이고, 손과 병의 상대 위치는 동작 내내 유지된다.
- 지나치게 가늘었던 병의 런타임 폭/깊이·길이 계수를 0.60/1.70에서 0.90/1.20으로 조정했다. 제공 GLB와 파생 GLB의 원본 형상은 수정하지 않았다.
- 오른손목을 따라 팔꿈치가 움직이며, 어깨는 몸 오른쪽에 유지된다. 왼손은 마개를 뽑은 뒤 화면 왼쪽 아래로 빠진다.
- 네 번의 삼킴에 맞춘 기울기 변화, 액체 표면의 출렁임·감소, 빈 병을 내리는 기존 흐름을 유지했다.

## 게임에서 확인

F2 → 생존 → **물약 마시기 · 액체 출렁임**. 기존 핏빛 회복약에 적용된다. 5.8초 완료 시 1개 소비·회복하며 F로 취소한다. 같은 항목을 다시 선택하면 재보급하고 재생한다.

## 검증과 산출물

- `tests_final.log`: `potion_motion`, `potion_test_room` 자동 검사. 입구 고정, 병 바닥 높이, 손 추종, 액체 감소, 완료·취소·반복·메뉴·초기화·원래 원정과 가방 복원.
- `capture_final.log`, `manifest.json`: 실제 게임 함수로 진행한 Mac embedded/Vulkan 195프레임, 소스 해시와 세션 보존 검사.
- `potion_drinking_pose.gif`: 위 프레임의 15fps 축소 미리보기. 별도 연출이나 합성 장면을 덧붙이지 않았다.
- `contact_sheet.jpg`: 준비·입으로 가져오기·음용·빈 병의 주요 화면.
- 원본 프레임: `godot-game/artifacts/visual_qa/potion_drink/mouth_body_final/`.

`fit_grip.py`, `fit_fingertips.py`, `rig.json`은 기존 손의 스킨과 관절 좌표를 이용한 파지 보조 계산이다. 병의 회전 대칭 외곽과 정점 접촉을 근사하며, 모든 메시 삼각형의 충돌 보증으로 간주하지 않는다. 실제 화면의 손 자세는 렌더를 따로 검토했다. 액체는 기울어진 절단면과 표면 메시로 표현하며 유체 시뮬레이션은 아니다.
