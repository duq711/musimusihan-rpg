# 플레이어 양손 — 마디별 관절 효과

양손의 30개 마디를 각각 굽히고, 굽힘에 따라 관절 바깥쪽 볼륨과 안쪽 피부 접힘이 변하도록 제작했다. 기존 상세 양손을 바탕으로 각 손에 15개 교정 형상을 추가했으며 손톱 아래 피부가 말단 관절을 함께 따르도록 보정했다.

## 파일과 사용

- `bilateral_hands_articulated.blend`: 좌우 손이 들어 있는 편집 원본. Blender 5.2.1 LTS에서 제작·검증했다.
- `left_hand_articulated.glb`, `right_hand_articulated.glb`: 게임용 개별 손. 각 57,346삼각형, 9개 메시, 손목 포함 16개 본, 15개 POSITION·NORMAL 교정 형상.
- `README_BLENDER.md`: Blender에서 마디 회전과 대응 Shape Key를 직접 조절하는 방법.
- `Game_Preview/finger_joint_sequence.gif`: 실제 게임 렌더러가 촬영한 15초 마디 순차 굽힘.
- `Game_Preview/`: 손등·손바닥·뿌리·가운데·끝·주먹·활·상자·조절 UI 9장, 순차 PNG 226장, 원본 해시 기록.
- `joints_*.png`: Blender에서 촬영한 열린 손·최대 굽힘·검지 가운데 마디 검토 이미지 5장.
- `validation_summary.json`, `verification_report.json`, `Validation_Logs/`: 모델·게임·화면 검증 근거.
- `tools/`: 제작, 독립 검증, 실제 순차 프레임 GIF 인코딩 도구.

게임 프로젝트에 이미 통합되어 있다. **테스트룸 → 기본 → 캐릭터 그래픽 · 손가락 마디별 관절**을 선택하면 실제 플레이어 양손과 15개 슬라이더가 열린다. 양손 함께·왼손·오른손, 손등·손바닥을 선택하고 펴기·주먹·마디 순차 버튼을 사용할 수 있다. F2·Esc·시험 메뉴 버튼으로 돌아가며 임시 자세와 외형을 복구한다. 이 화면 동안 적과 생존 시간은 멈춘다.

기존 `detailed` 프로파일에서 활과 상자 동작에도 같은 교정 형상을 구동한다. 게임의 기본 외형 및 검·방패 전용 모델은 기존 설정을 유지한다.

## 조작 범위

손가락마다 뿌리·가운데·끝을 0~1로 제어한다. 엄지는 밑관절을 포함한다. 일반 손가락은 90°·110°·80°, 엄지는 60°·70°·80°를 모델용 최대 굽힘으로 사용한다. Blender/Godot에서 대응 본의 로컬 X축 음수 방향이 굽힘이며 `Joint_<digit>_<joint>` 값은 실제 굽힘각 ÷ 최대각이다.

Blender 파일은 중립 자세로 저장했다. Blender 자동 드라이버와 베이크한 애니메이션 클립은 포함하지 않으며, 게임 런타임이 본과 교정 값을 함께 제어한다. 회색 재질은 형태 검토용이고 새로운 컬러 텍스처나 노멀맵 베이크는 포함하지 않는다.

## 검증과 보존

Blender 원본 및 좌우 GLB의 30개 관절·실제 피부 변형·다른 손가락과 손목 격리·손톱 추종·최대 굽힘의 손톱 간격을 독립적으로 검사했다. 원래 손목 좌표, 16개 본의 기준 자세, 중립 표면과 손톱 형상을 유지했다.

관련 Godot 자동 검증 7개를 통과했다: `player_finger_joints`, `player_hands_detailed`, `player_hands_greybox`, `player_arm`, `weapon_hand_contacts`, `chest_hands`, `test_room_session`. 마디별 실제 회전과 메시 변형, 15개 조절 UI, 마지막 줄 수치까지의 표시 영역, 활·상자 연결, 반복·F2·초기화·종료와 원정 복원을 포함한다.

실제 Vulkan Forward+ 렌더러의 창 없는 실행에서 235개 프레임을 저장했다. UI는 게임과 같은 CanvasLayer 70에 표시한다. 데스크톱 캡처·외부 입력을 사용하지 않았고 촬영 전후 원정·인벤토리·커서 상태 및 소스 해시가 유지됐다. GIF는 이 PNG를 크기 변경이나 합성 없이 256색으로 인코딩한 검토용이다.

기존 상세 모델 원본·렌더·납품 ZIP 등 44개 파일은 해시가 유지됐다. 이번 제작 원본은 모델 `iteration_02`, 최종 게임 화면은 `final_04`다. 최초 테스트의 엄지 국소 범위 기준을 실제 피부 단면으로 바로잡았고, 화면 검토에서 발견한 마지막 줄 수치 잘림과 촬영 UI 층 문제를 수정했다. 관련 최초 기록도 검증 로그에 보존했다.
