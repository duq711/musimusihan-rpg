# 플레이어 손가락 마디별 관절 효과

2026-09-10 사용자 요청: “손가락 마디마다 관절 효과를 구현해주세요.” 앞서 만든 양손 디테일 모델에 마디별 독립 굽힘과 굽힘에 따른 국소 피부 보정을 추가한다. 같은 양손 작업의 Mac 제작 지시를 이어서 적용하며, Blender 5.2.1 LTS를 별도 백그라운드 프로세스로 실행한다.

## 기능과 표현

한 손에 손가락 5개 × 관절 3개를 제어한다. 엄지는 밑관절을 포함한다. 손목을 포함한 기존 16개 본 구조는 유지하며 새로운 물리 충돌체를 추가하지 않는다.

- `set_joint_flexion(digit, joint, amount)`는 한 마디만 제어한다. 0은 펴기, 1은 해당 모델의 최대 굽힘이다.
- `set_digit_flexion(digit, Vector3)`는 한 손가락의 세 마디를 개별 값으로 설정한다.
- 일반 네 손가락의 모델용 최대 굽힘은 90°·110°·80°, 엄지는 60°·70°·80°다. 인체의 보편적 측정값을 주장하는 수치가 아니라 이 모델에 정한 조작 범위다.
- 손 메시의 `Joint_<digit>_<0|1|2>` 보정 형상 15개를 실제 관절 각도에 따라 구동한다. 관절 바깥쪽 볼륨과 안쪽의 얕은 접힘을 국소적으로 바꾸며 손톱은 말단 본을 따른다.
- 기존 그립·활 당김·상자 접촉의 포즈 호출은 기존 각도를 유지하면서 같은 관절 보정을 사용한다.

## 제작·보존

입력은 `../player_hands_detail_20260910/mac_output/iteration_03/`의 상세 모델이다. 새로운 모델은 `mac_output/`에 별도로 제작한다. 게임에는 최종 검증한 관절 모델을 기존 `hands_detailed/left_hand_detailed.glb`, `right_hand_detailed.glb` 경로로 갱신한다. 이전 게임 파일은 `baseline/`에 복사했으며, 이전 상세 모델의 원본·렌더·ZIP 등 44개 파일은 해시로 보존한다. 과거 납품 ZIP과 Blender 원본을 덮어쓰지 않는다.

`tools/build_finger_joints.py`는 새 Blender 파일과 좌우 GLB를 생성한다. GLB에는 실제 POSITION·NORMAL 보정 데이터가 들어가며 초기 보정 값은 모두 0이다. `tools/verify_finger_joints.py`는 원본 손목·16개 본 기준 행렬, 15개 각각의 실제 관절·피부 변형, 다른 손가락 격리, 손톱의 말단 본 추종 및 최대 굽힘에서 손톱과 피부의 간격을 독립적으로 검사한다.

## 시험과 화면 검증

테스트룸의 **손가락 마디 시험**은 실제 플레이어의 양손을 확대 배치하고, 적과 생존 시간을 멈춘 상태로 조작한다. 양손 함께·왼손·오른손을 선택하고 15개 슬라이더를 조절한다. 손등·손바닥 보기, 펴기·주먹·마디 순차 버튼을 제공한다. F2 또는 시험 메뉴 버튼으로 나가면 임시 손 자세와 제어 UI를 정리한다. 다른 시험·초기화·장면 이탈·종료에서도 같은 정리를 수행한다.

자동 검증은 `godot-game/tests/run_headless_tests.sh`를 사용한다. 실제 화면은 감사된 창 없는 `run_embedded_preview.sh`로 촬영하며, 데스크톱 화면 캡처나 외부 입력 주입을 사용하지 않는다. GIF는 실제 GPU 프리뷰가 저장한 순차 프레임을 시간 순서대로 인코딩한 검토용이다.

## 최종 결과

모델은 `mac_output/iteration_02/`이며 Blender 독립 검증을 통과했다. 손톱 아래 피부 웨이트를 왼손 1,134개·오른손 1,133개 정점에서 보정하고 4mm 전이 구간을 두었다. 중립 표면·손톱 형상·기존 본 기준은 유지한다. 최대 굽힘에서도 손톱 정점과 피부의 최대 간격은 약 0.320mm로 중립 수준을 유지했다.

관련 자동 검증 7개가 통과했다: `player_finger_joints`, `player_hands_detailed`, `player_hands_greybox`, `player_arm`, `weapon_hand_contacts`, `chest_hands`, `test_room_session`. 최종 관절 검증은 `godot_joint_final04.log`, 상세/그레이박스 결과는 `godot_hands_final02.log`, 공통 회귀 검증은 `godot_regressions_01.log`에 보존했다. 최초 관절 검사에서 원본 엄지 본과 실제 피부 단면의 위치 차이를 반영하지 않은 거리 기준을 수정했다. 마지막 줄 숫자의 가시 영역과 실제 CanvasLayer 70도 검증한다.

최종 실제 GPU 화면은 `../../godot-game/artifacts/visual_qa/player_finger_joints/final_04/`이다. 손등·손바닥·각 관절군·주먹·활·상자·실제 조절 UI 9장과 순차 굽힘 226프레임을 저장했다. 235개 캡처의 실제 상태, 소스 해시, 원정·인벤토리·커서 보존 검사는 모두 통과했다. 화면을 직접 검토해 손의 배치, 15개 수치 표시, UI가 팔 위에 표시되는 순서를 확인했다.

납품 폴더는 `../../exports/Player_Finger_Joints_2026-09-10/`이며 편집 원본, 개별 GLB, Blender/Godot 이미지, 실제 순차 GIF, 도구와 검증 근거를 포함한다. Blender에서는 `README_BLENDER.md`에 따라 본 회전과 보정 키를 수동 조절한다. 자동 드라이버·베이크 애니메이션은 포함하지 않고, 게임 런타임에서 실제 굽힘과 보정을 함께 구동한다.
